# 框架知识在测试中的应用

面测开，框架八股要能落回"我会怎么写测试/怎么排查"，别只背概念。

## 可测性设计

懂 IoC/DI 才知道为什么**构造器注入 + 面向接口**方便注入 mock、写单测；字段注入的类难测。

## 分层测试

单元测试用 Mockito/pytest-mock 隔离依赖；集成测试用 `@SpringBootTest`/`TestContainers` 起真实上下文测多组件协作。

## 接口自动化

用 pytest + requests（或 RestAssured）驱动接口，fixture 管理登录态/测试数据/环境切换，参数化覆盖边界（呼应 `iflytek/03-api-automation.md`）。

## SQL 注入测试

知道 `#{}` 预编译、`${}` 拼接，就能有针对性地测**注入点**（呼应 MyBatis核心概念 + `04-database.md`）。

## 事务/一致性测试

懂 `@Transactional` 失效场景，能设计"异常回滚了没""并发下脏读/丢更新"这类用例。

## UI 自动化稳定性

显式等待 + Page Object + 失败截图，把 flaky 用例压下去（呼应 UI自动化测试）。

## 一句话总结

> 框架知识在测试中的落地：构造器注入利 mock、分层测试隔离/集成各归其位、MyBatis `#{}` vs `${}` 指导注入测试、事务失效场景驱动回滚用例、显式等待治 flaky。
