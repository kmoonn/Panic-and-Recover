# 测试流程与缺陷生命周期

测试流程描述从需求到上线的完整测试活动链路；缺陷生命周期描述一个 Bug 从发现到关闭的状态流转。

## 测试流程

需求分析 → 测试计划 → 用例设计 → 环境准备 → 执行测试 → 缺陷跟踪 → 回归 → 测试报告 → 上线验证。

## 缺陷生命周期

New → Assigned → Open(修复中) → Fixed → **Reopen/Closed**（验证通过关闭，不通过打回）。

## 缺陷要素

标题、复现步骤、期望vs实际、环境、严重级别、优先级、截图/日志。

**⭐ 加分**：严重级别（Severity，缺陷本身影响）vs 优先级（Priority，修复紧急度）是两回事——低严重高优先（如首页错别字）也存在。

## 一句话总结
> 测试流程是"需求→计划→用例→执行→回归→报告"的闭环；缺陷生命周期核心是 New→Fixed→Reopen/Closed 的状态流转，Severity 与 Priority 是两回事。
