# 语言基础在测试中的应用

测开 = 测试 + 开发，语言是写测试工具/框架/自动化脚本的基本功。

## 写自动化/工具

Python（pytest、requests、Selenium/Appium）或 Java（JUnit、TestNG）写用例、造数脚本、测试平台（呼应三段实习的工具/Agent 开发）。

## 理解被测系统

懂语言并发/内存模型才能设计并发、内存泄漏、性能用例。

## Mock/桩

用语言特性 mock 上下游依赖（呼应字节 API Testing Agent 的 Mock）。

## 数据处理

生成器/流式处理大数据（呼应 SAX）、正则/字符串处理日志（呼应 Linux 日志排查）。

## CI 集成

脚本 + Shell 串进流水线，实现提测自动冒烟回归（呼应讯飞发布前自动化）。

## 一句话总结
> 测开的语言基本功服务于五大场景：写自动化/工具、理解被测系统、Mock/桩、数据处理、CI 集成。
