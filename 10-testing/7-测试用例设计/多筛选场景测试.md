# 多筛选场景测试用例

## 面试题：如何设计「多条件筛选」功能的测试用例

多筛选 = 列表页/搜索页上多个筛选条件（下拉、多选、区间、时间、关键词）**组合**过滤结果，常见于电商商品列表、后台管理、数据报表。核心难点是**条件的组合关系（AND/OR）、组合爆炸、与排序分页的联动**。核心方法：**先测单条件正确性，再测多条件组合逻辑，再测边界与联动，用等价类+正交实验裁剪组合**。

---

## 测试维度总览

```
单条件筛选 → 多条件组合 → 边界与清空 → 与排序/分页联动 → 性能 → 兼容/安全
   (基础)      (核心)       (异常)         (易漏)         (压力)    (加固)
```

---

## 一、单条件筛选（基础）

| 筛选类型 | 测试点 |
|---|---|
| 单选下拉 | 选某分类 → 结果都属于该分类 |
| 多选 | 勾选多个值 → 结果匹配任一值（OR）；数量正确 |
| 区间（价格/数值） | 最小~最大区间过滤；含边界值（等于上下界是否算入） |
| 时间范围 | 起止时间过滤；跨天/跨月/同一天 |
| 关键词搜索 | 与筛选并存时的交集 |
| 布尔/开关 | 有货/包邮等开关生效 |

**每个条件单独验证**：选中后结果是否精确匹配、结果数量对不对、不匹配的是否被排除。

---

## 二、多条件组合（核心）⭐

| 测试点 | 说明 |
|---|---|
| **组合逻辑 AND/OR** | 不同条件间是 AND（都满足）、同条件多选是 OR（满足其一）——是否符合产品定义 |
| 两两组合 | 分类+价格、品牌+时间、关键词+分类 结果都正确 |
| 多条件叠加 | 3~4 个条件同时生效，结果是所有条件的交集 |
| 条件互斥/冲突 | 相互矛盾的条件（如价格 100-50）→ 空结果或校验提示 |
| 增减条件联动 | 加一个条件结果变少、去一个条件结果变多 |
| 结果为空 | 组合后无数据 → 空状态提示，而非报错/白屏 |

> **组合爆炸怎么办**：不可能穷举所有组合，用**正交实验法**——每个条件取代表值（如价格取"低/中/高"），生成正交组合覆盖两两交互，用少量用例覆盖大部分组合缺陷。

---

## 三、边界、清空与默认

| 测试点 | 正常 | 异常/边界 |
|---|---|---|
| 默认状态 | 未筛选展示全部/默认排序 | 默认选中项是否符合预期？ |
| 单条件清空 | 移除某条件，其余保留生效 | 清空后结果正确回退？ |
| 一键重置 | 清空所有条件回到初始 | 重置后排序/分页是否也复位？ |
| 全不选 | 某多选组全不选 = 不过滤该维度 | 全不选被当成"筛空"了吗？ |
| 全选 | 某维度全选 = 等于不筛 | 结果与未筛一致？ |
| 非法输入 | 区间输入非数字/负数/超大值 | 前后端校验、提示 |

---

## 四、与排序、分页、URL 的联动（最易漏）⭐

| 测试点 | 说明 |
|---|---|
| 筛选 + 排序 | 先筛再按价格排序，结果既满足筛选又正确排序 |
| 筛选 + 分页 | 筛选后分页正确；翻页时筛选条件保持不变 |
| 改条件重置页码 | 改筛选条件后应回到第 1 页，而非停在原页码 |
| 状态保持 | 筛选条件与结果一致，来回切换不错乱 |
| URL 同步 | 条件写入 URL 参数，刷新/分享后筛选态还原 |
| 回退/前进 | 浏览器前进后退，筛选态正确恢复 |
| 计数联动 | 结果总数、各筛选项数量随条件实时更新 |

---

## 五、性能

| 测试点 | 说明 |
|---|---|
| 大数据量筛选 | 海量数据下多条件筛选响应时间（走索引？） |
| 高并发筛选 | 多用户同时筛选的吞吐与延迟 |
| 频繁切换 | 快速连续改条件，防抖/请求竞态（后发先至导致结果错乱） |
| 慢查询 | 多条件组合是否命中索引，避免全表扫描 |

---

## 六、兼容性与安全

| 维度 | 测试点 |
|---|---|
| 端兼容 | PC/移动端/不同浏览器筛选交互一致 |
| 请求竞态 | 快速切换条件，旧请求响应后到覆盖新结果（需按序丢弃） |
| SQL 注入 | 筛选参数拼 SQL 是否有注入风险 |
| 参数越权 | 篡改筛选参数查看无权限数据 |

---

## 用例设计方法总结

| 方法 | 应用 |
|---|---|
| **等价类划分** | 每个筛选条件取有效/无效/边界代表值 |
| **边界值分析** | 价格/数值区间上下界、时间范围端点 |
| **正交实验法** ⭐ | 多条件组合爆炸 → 正交裁剪，少量用例覆盖两两交互 |
| **判定表** | AND/OR 组合逻辑用判定表列清各条件真假下的预期结果 |
| **错误推测** | 冲突条件、全选全不选、请求竞态、改条件不重置页码 |

---

## 一句话总结

> 多筛选测试先验单条件精确匹配，再测多条件组合逻辑（同维 OR、跨维 AND）——组合爆炸用**正交实验法+判定表**裁剪；重点盯**与排序/分页/URL 的联动**（改条件重置页码、翻页保持条件、URL 还原）和**清空/全选/全不选**边界，辅以大数据量筛选性能、请求竞态防错乱与注入越权安全测试。
