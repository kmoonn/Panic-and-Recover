# 游戏聊天系统测试用例

## 面试题：如何测试游戏内的聊天系统

游戏聊天不同于普通 IM：它有**多频道**（世界/队伍/公会/私聊）、**实时性要求高**、**内容需强审核**（防外挂/引流/辱骂）、还要扛**高并发广播**（一个世界频道几千人同时收发）。核心方法：**按「频道维度 + 消息生命周期（发送→传输→接收→展示）」拆解，每段考虑正常+异常+边界+并发+安全**。

---

## 消息生命周期

```
输入消息 → 内容校验 → 发送 → 服务端审核/分发 → 广播/推送 → 接收展示 → 历史存储
   │          │          │          │              │           │           │
   ▼          ▼          ▼          ▼              ▼           ▼           ▼
 输入环节   前端校验   发送环节   审核分发环节    传输环节    展示环节    存储环节
```

---

## 一、频道功能

| 测试点 | 正常 | 异常/边界 |
|---|---|---|
| 世界频道 | 全服可见、正常收发 | 万人同频道并发刷屏？ |
| 队伍/组队频道 | 仅队内可见 | 退队后是否还能收发？队伍解散？ |
| 公会频道 | 仅公会成员可见 | 未入会能否看到？退会后？ |
| 私聊 | 一对一定向送达 | 私聊已拉黑对象？对方离线？对方不存在？ |
| 频道切换 | 切换后消息隔离正确 | 世界发的消息串到队伍频道？ |
| 系统/公告频道 | 只读、不可发言 | 玩家能否伪造系统消息？ |

---

## 二、消息发送环节

| 测试点 | 正常 | 异常/边界 |
|---|---|---|
| 文本长度 | 正常长度发送成功 | 空消息？纯空格？超长（如 500 字）截断？ |
| 内容类型 | 文本/表情/图片/语音/链接 | 特殊字符、emoji、超大图片、超长语音？ |
| 发送频率 | 正常间隔发送 | 快速连点刷屏？触发禁言/限流阈值？ |
| 频道权限 | 达到等级可发言 | 低于发言等级？新号防骚扰限制？ |
| 禁言状态 | 正常玩家可发 | 被禁言玩家发送被拦截并提示？ |
| 网络状态 | 在线正常发送 | 弱网延迟？发送中断网 → 重发/失败提示？ |

---

## 三、内容审核环节（游戏聊天重点）

| 测试点 | 正常 | 异常/边界 |
|---|---|---|
| 敏感词过滤 | 违规词被屏蔽/替换为 * | 变体绕过（拼音/谐音/空格/特殊符号分隔）？ |
| 广告/引流 | 正常聊天放行 | 微信号/QQ/网址/交易引流拦截？ |
| 辱骂/涉政 | 触发审核拦截 | 图片 OCR、语音转文字是否也审核？ |
| 刷屏检测 | 正常内容放行 | 重复消息、复制粘贴刷屏拦截？ |
| 审核时效 | 先发后审/边发边审 | 审核延迟时消息是否已扩散？能否撤回？ |
| 白名单 | GM/客服消息不误杀 | 正常词被误判（如「杀」在游戏语境）？ |

---

## 四、传输与广播环节

| 测试点 | 正常 | 异常/边界 |
|---|---|---|
| 实时性 | 消息秒级到达 | 高并发下延迟？消息积压？ |
| 消息顺序 | 按发送顺序展示 | 并发下乱序？先看到回复再看到原消息？ |
| 消息不丢 | 发出必达 | 弱网/切后台/重连后漏消息？ |
| 消息不重 | 一条只收一次 | 重连/重试导致重复推送？ |
| 离线消息 | 上线后收到私聊/公会离线消息 | 离线消息数量上限？世界频道离线是否推送？ |
| 广播性能 | 万人频道流畅 | 峰值广播是否打爆服务端/客户端？ |

> 呼应传输层：游戏实时消息常走 UDP + 应用层可靠（见[游戏为什么用UDP](../../04-network/2-传输层/7-游戏为什么用UDP.md)），需重点验证**丢包/乱序/重复**处理。

---

## 五、接收与展示环节

| 测试点 | 正常 | 异常/边界 |
|---|---|---|
| 消息展示 | 昵称/头像/内容/时间正确 | 超长昵称？特殊字符昵称？头像加载失败？ |
| 未读提醒 | 红点/数字正确 | 未读数超 99？清零时机？ |
| 消息渲染 | 表情/图片/链接正常显示 | 富文本注入（伪造颜色/超链接钓鱼）？ |
| 屏蔽/拉黑 | 屏蔽后不再收到对方消息 | 拉黑后历史消息是否保留？ |
| @提醒 | @我时高亮+提醒 | @全体频率限制？@不存在的人？ |
| 快捷/预设短语 | 快捷发送成功 | 预设短语含敏感词？ |

---

## 六、历史与存储环节

| 测试点 | 正常 | 异常/边界 |
|---|---|---|
| 历史记录 | 可翻阅历史消息 | 历史条数上限？跨天/跨登录是否保留？ |
| 消息漫游 | 换设备登录消息同步 | 多端同时在线消息一致性？ |
| 撤回 | 规定时间内可撤回 | 超时撤回？撤回已被举报的消息？ |
| 举报 | 举报后生成工单+证据 | 举报已撤回/已删除的消息？ |

---

## 七、安全测试

| 测试点 | 说明 |
|---|---|
| 越权发送 | 伪造协议往非所在频道/私聊发消息 |
| 伪造系统消息 | 客户端伪造「系统公告」诱导玩家 |
| 敏感词绕过 | 变体、编码、分隔符绕过审核 |
| XSS/富文本注入 | 消息含脚本/钓鱼超链接，客户端是否转义 |
| 刷屏/DDoS | 高频发送打爆聊天服务 |
| 隐私泄露 | 私聊内容是否加密、是否被第三方截获 |

---

## 八、兼容性与性能

| 维度 | 测试点 |
|---|---|
| 设备兼容 | iOS/Android/PC/主机各端聊天一致 |
| 多端同步 | 手机与 PC 同时在线消息一致 |
| 网络环境 | WiFi/4G/5G/弱网/断线重连 |
| 性能 | 万人世界频道并发收发延迟、丢包率 |
| 压力 | 大版本开服/大促峰值刷屏 |
| 稳定性 | 长时间挂机聊天不崩溃、无内存泄漏 |

## 用例设计方法总结

| 方法 | 应用 |
|---|---|
| **等价类划分** | 消息长度（空/正常/超长）、频道类型（世界/队伍/公会/私聊） |
| **边界值分析** | 文本长度上限、发送频率阈值、未读数 99、离线消息条数 |
| **状态迁移** | 玩家状态（正常→禁言→解禁）、消息状态（发送中→已发→撤回） |
| **错误推测** | 敏感词变体、弱网重连丢消息、伪造系统消息 |
| **正交实验** | 频道类型 × 消息类型 × 网络环境 |

---

## 一句话总结

> 游戏聊天测试按「频道维度 + 消息生命周期（发送→审核→传输→展示→存储）」分段覆盖，每段考虑正常+异常+边界+并发，重点关注**内容审核（敏感词/变体/引流）、实时广播（丢包/乱序/重复/延迟）、高并发刷屏、私聊隐私与越权**四大风险点，辅以安全测试（伪造系统消息/富文本注入/绕过审核）和万人频道的性能压测。
