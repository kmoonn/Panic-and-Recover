# 百度网盘视频播放测试用例设计

## 功能测试

### 播放控制

| 测试点 | 预期 |
|---|---|
| 点击视频文件 → 播放器打开 | 播放器正常启动，视频开始播放 |
| 播放/暂停切换 | 状态正确切换，画面暂停/继续 |
| 进度条拖动 | 跳转到指定位置，音画同步 |
| 快进/快退（±10s/±30s） | 跳转正确，无音画不同步 |
| 倍速切换（0.5x / 1x / 1.5x / 2x / 3x） | 速度切换正确，音调正常（不变速调） |
| 音量调节/静音 | 音量变化正确，静音图标状态正确 |
| 全屏/退出全屏 | 画面正确缩放，控件显示/隐藏 |
| 画中画模式 | 缩小浮窗播放，可同时操作网盘 |
| 上一集/下一集 | 正确切换到相邻集数 |
| 选集列表 | 展开选集面板，点击切换到对应集 |

### 播放状态

| 测试点 | 预期 |
|---|---|
| 播放结束 | 显示推荐/重播按钮，不自动跳转 |
| 断点续播 | 记住上次播放位置，下次打开从该位置继续 |
| 缓冲中 | 显示 loading 动画，不黑屏 |
| 首帧时间 | 点击后 ≤2s 出现画面 |

## 格式兼容性

| 测试点 | 预期 |
|---|---|
| MP4（H.264 / H.265） | 正常播放 |
| AVI / MKV / MOV / WMV / FLV | 正常播放或提示"不支持该格式" |
| 4K / 1080P / 720P / 480P | 各分辨率正常播放 |
| 超大文件（>10GB） | 可播放，不 OOM |
| 损坏/未下载完的文件 | 提示"文件损坏"而非崩溃 |
| 音频文件（MP3/FLAC） | 转码音频模式播放 |

## 字幕测试

| 测试点 | 预期 |
|---|---|
| 内嵌字幕 | 自动显示/可切换轨道 |
| 外挂字幕（SRT/ASS/VTT） | 加载并正确显示 |
| 字幕开关 | 开关状态正确，显示/隐藏 |
| 多字幕轨道切换 | 切换到正确语言 |
| 无字幕视频 | 不显示字幕区域，不报错 |

## 网络与弱网

| 测试点 | 预期 |
|---|---|
| WiFi → 4G 切换 | 播放不中断，自动降清晰度 |
| 4G → 无网络 | 缓冲提示，恢复网络后继续播放 |
| 极低带宽（<100kbps） | 降清晰度播放或提示"网络不畅" |
| 网络波动（间歇断连） | 不崩溃，恢复后自动续播 |
| 离线已下载视频 | 无网络下正常播放 |

## 清晰度与转码

| 测试点 | 预期 |
|---|---|
| 原画 / 高清 / 标清切换 | 画质变化正确 |
| 自动清晰度 | 根据网络带宽自动选清晰度 |
| 未转码文件选高清 | 提示"该清晰度尚未转码" |
| 转码中文件 | 提示"转码中"而非播放失败 |

## 权限与登录

| 测试点 | 预期 |
|---|---|
| 未登录点击播放 | 跳转登录页 |
| 非会员播放会员视频 | 提示"开通会员" |
| 分享链接播放 | 有权限可播放，无权限提示申请 |
| 链接过期 | 提示"链接已失效" |
| 多设备同时播放同一账号 | 是否限制并发数 |

## 并发与异常

| 测试点 | 预期 |
|---|---|
| 同一视频多标签页同时播放 | 各自独立播放不冲突 |
| 播放中删除源文件 | 提示"文件已删除"，播放器优雅退出 |
| 播放中文件被修改/覆盖 | 检测到变化后提示或继续用缓存 |
| 长时间播放（>2小时） | 无内存泄漏，不卡顿 |
| 快速连续切换视频 | 不崩溃，最终播放正确的视频 |

## 性能

| 测试点 | 指标 |
|---|---|
| 首帧时间 | ≤2s（WiFi 环境） |
| 进度条拖动响应 | ≤500ms |
| 内存占用 | 播放 1 小时内存增长 < 50MB |
| CPU 占用 | 1080P 播放 CPU < 30% |
| 多标签页播放 | 3 个同时播放不卡顿 |

## UI 与交互

| 测试点 | 预期 |
|---|---|
| 控件自动隐藏 | 播放 3s 无操作后控件渐隐 |
| 鼠标移动/触摸 | 控件重新显示 |
| 快捷键（空格暂停、左右快进退） | 响应正确 |
| 缩略图预览（进度条 hover） | 显示对应帧缩略图 |
| 深色/浅色模式 | 播放器主题跟随系统/应用设置 |
| 移动端手势（左滑快退、右滑快进） | 响应正确 |

## 安全

| 测试点 | 预期 |
|---|---|
| 视频流 URL 是否可被直接抓取播放 | 加密/鉴权，无法直接外链播放 |
| 会员视频缓存文件 | 本地缓存加密，无法直接提取 |
| DRM 保护内容 | 正常播放，无法录屏/截屏（如支持） |

## 一句话总结

> 覆盖播放控制、格式兼容、字幕、弱网、清晰度、权限、并发、性能、UI及安全全维度测试设计。
