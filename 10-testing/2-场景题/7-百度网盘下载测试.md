# 百度网盘下载功能测试用例（黑盒）

## Q: 针对百度网盘的下载功能，用黑盒测试思路设计功能测试用例？

### 解题思路

黑盒测试关注**输入与输出的对应关系**，不关心内部实现。从等价类划分、边界值分析、场景法三条主线展开，覆盖"能不能下""下得对不对""异常怎么办"三个层次。

---

## 一、下载前——权限与状态

| 测试点 | 操作 | 预期 |
|--------|------|------|
| 未登录点击下载 | 退出登录 → 点击文件下载 | 跳转登录页 |
| 普通用户下载单文件 | 选择文件 → 点击下载 | 正常下载（限速） |
| 普通用户下载文件夹 | 选择文件夹 → 点击下载 | 提示"开通会员加速"或按限速打包下载 |
| 会员用户下载 | 同上 | 走会员加速通道 |
| 分享链接中下载 | 打开他人分享链接 → 保存到网盘/直接下载 | 有权限可下载，无权限提示申请 |
| 分享链接过期 | 打开过期链接 → 点击下载 | 提示"链接已失效" |
| 提取码错误 | 输入错误提取码 | 提示"提取码错误" |
| 已删除文件下载 | 回收站中文件/已被彻底删除的文件 | 提示"文件不存在" |

## 二、下载触发——单文件 vs 批量

| 测试点 | 操作 | 预期 |
|--------|------|------|
| 单个文件下载 | 点击一个文件 → 下载 | 正确下载该文件 |
| 多选批量下载 | 勾选多个文件 → 下载 | 全部选中文件下载 |
| 全选下载 | 点击全选 → 下载 | 当前目录所有文件下载 |
| 文件夹下载 | 选择整个文件夹 → 下载 | 打包为 zip 下载 |
| 空文件夹下载 | 选择空文件夹 → 下载 | 提示"文件夹为空"或下载空 zip |
| 超大文件下载（>4GB） | 下载超过 4GB 的文件 | 客户端正常下载，文件完整 |
| 超大文件夹下载 | 文件夹内含数千文件 | 打包不超时，进度可查 |
| 重复点击下载 | 连续点击下载按钮多次 | 只触发一次下载，不重复下载 |

## 三、下载过程——状态与进度

| 测试点 | 操作 | 预期 |
|--------|------|------|
| 下载进度显示 | 下载中观察进度条 | 进度百分比实时更新，与实际一致 |
| 下载速度显示 | 下载中观察速度 | 显示实时速率（如 2.5MB/s） |
| 剩余时间预估 | 下载中观察剩余时间 | 合理预估，不出现负数或天文数字 |
| 暂停下载 | 点击暂停 | 下载暂停，进度保留 |
| 恢复下载 | 暂停后点击继续 | 从断点继续，不重新下载 |
| 取消下载 | 点击取消 | 停止下载，清理临时文件 |
| 同时多任务下载 | 同时下载多个文件 | 各任务独立进度，互不影响 |
| 下载队列满 | 超过最大并发数 | 新任务排队等待，提示"排队中" |

## 四、下载路径与存储

| 测试点 | 操作 | 预期 |
|--------|------|------|
| 默认路径下载 | 不修改路径直接下载 | 保存到默认下载目录 |
| 自定义路径下载 | 修改下载路径 → 下载 | 保存到指定路径 |
| 路径空间不足 | 选择磁盘空间不足的路径 | 提示"磁盘空间不足" |
| 路径不存在 | 设置已删除的路径 | 自动重建或提示选择新路径 |
| 路径含特殊字符 | 路径含中文/空格/特殊符号 | 正常下载，不报错 |
| 同名文件覆盖 | 下载已存在的同名文件 | 提示"文件已存在，是否覆盖/重命名" |
| 中文文件名下载 | 下载文件名含中文 | 文件名显示正确，不乱码 |

## 五、文件类型与大小

| 测试点 | 测试数据 | 预期 |
|--------|---------|------|
| 常见文档 | .docx / .xlsx / .pptx / .pdf | 正常下载，打开无损坏 |
| 常见图片 | .jpg / .png / .gif / .svg | 正常下载，图片可查看 |
| 常见视频 | .mp4 / .mkv / .avi | 正常下载，播放无损坏 |
| 压缩包 | .zip / .rar / .7z | 正常下载，解压无损坏 |
| 安装包 | .apk / .dmg / .exe | 正常下载，安装无问题 |
| 极小文件（0B/1B） | 空文件 | 下载完成，文件大小正确 |
| 边界文件（2GB/4GB） | 接近文件系统限制 | 正常下载 |

## 六、网络异常

| 测试点 | 操作 | 预期 |
|--------|------|------|
| WiFi → 4G 切换 | 下载中切换网络 | 断点续传，不重新下载 |
| 4G → 无网络 | 下载中断网 | 显示"网络异常"，可手动恢复 |
| 网络波动 | 间歇断连 | 自动重试，最终完成下载 |
| 下载中开启飞行模式 | 开启飞行模式 | 暂停下载，关闭飞行模式后可恢复 |
| 网络恢复后续传 | 断网重连后 | 自动/手动从断点继续 |

## 七、客户端异常

| 测试点 | 操作 | 预期 |
|--------|------|------|
| 下载中关闭客户端 | 强制关闭 | 重启后可继续未完成下载 |
| 下载中电脑休眠 | 合盖/休眠 | 唤醒后下载暂停，可恢复 |
| 下载中电脑重启 | 重启系统 | 重启后任务列表保留，可恢复 |
| 下载中磁盘被拔出 | U盘/外接硬盘被拔 | 提示"存储设备已移除" |
| 客户端崩溃 | 下载中崩溃 | 重启后任务保留，可恢复 |

## 八、Web 端特有

| 测试点 | 操作 | 预期 |
|--------|------|------|
| 浏览器下载 | Web 端点击下载 | 调用浏览器下载管理器 |
| 批量下载提示安装客户端 | Web 端批量下载 | 提示"请安装客户端以支持批量下载" |
| 不同浏览器兼容 | Chrome / Firefox / Safari / Edge | 下载功能正常 |

## 设计方法对照

| 黑盒方法 | 应用位置 |
|---------|---------|
| **等价类划分** | 文件类型（文档/图片/视频/压缩包）、用户身份（未登录/普通/会员）、网络状态（WiFi/4G/无网） |
| **边界值分析** | 文件大小（0B/1B/2GB/4GB/10GB+）、磁盘空间（满/将满/充足）、并发数（0/1/最大/超出） |
| **场景法** | 正常下载流程、网络中断恢复、客户端崩溃恢复、权限不足拒绝 |
| **错误推测** | 空文件夹、重复点击、同名文件、路径含特殊字符、飞行模式 |

## 一句话总结

> 黑盒测试从等价类、边界值、场景法三条主线展开，覆盖权限、触发、进度、存储、文件类型、网络异常、客户端异常及 Web 端兼容共 8 个维度。
