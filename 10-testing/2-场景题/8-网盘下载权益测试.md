# 网盘下载场景权益分层测试（普通用户 vs 会员）

## Q: 网盘下载场景中，普通用户和会员的用例怎么设计？

### 设计思路

先明确需求边界再动手——"普通用户 vs 会员"最核心的差异是**权益分层**：下载速度、并发下载数、单文件大小上限、每日下载量。先跟产品确认这几条权益规则，然后按维度铺用例。

**分层策略**：功能正确性 → 权益差异 → 异常容错 → 非功能

---

## 一、权益对比表（测试基线）

> 设计用例前先理清权益边界，这张表就是测试的"等价类划分基准"。

| 权益维度 | 普通用户 | 会员 | 测试关注点 |
|---------|---------|------|-----------|
| 下载速度 | 限速（如 100KB/s） | 不限速/满速 | 限速值是否生效，会员是否跑满 |
| 并发下载数 | 上限 N 个 | 上限 M 个（M > N） | 达上限后的行为 |
| 单文件大小上限 | 如 2GB | 如 20GB 或无限制 | 临界值 ±1 |
| 每日下载配额 | 如 5GB/天 | 不限或高配额 | 配额用满的临界点、跨天重置 |

---

## 二、功能正确性 — 先保证能下

> 不管哪种用户，下载功能本身必须是正常的。

### 2.1 基础下载流程

| 用户 | 测试点 | 预期 |
|------|--------|------|
| 普通 | 下载普通文件（<2GB） | 正常发起、下载完成、文件完整 |
| 会员 | 下载普通文件 | 同上 |
| 普通 | 暂停/恢复/取消 | 功能正常 |
| 会员 | 暂停/恢复/取消 | 功能正常 |

### 2.2 文件来源与类型

| 来源 | 测试点 | 预期 |
|------|--------|------|
| 自己上传的 | 下载自己网盘内文件 | 正常下载 |
| 他人分享的 | 通过分享链接保存后下载 | 正常下载 |
| 批量下载 | 多选文件批量下载 | 全部下载成功 |
| 文件夹下载 | 整个文件夹打包下载 | zip 正常解压，内容完整 |
| 各文件类型 | doc/pdf/mp4/zip/... | 文件完整不损坏 |

---

## 三、权益差异 — 等价类 + 边界值

> 这是核心测试层，用等价类划分（普通/会员）和边界值分析（各种上限的临界点）来设计。

### 3.1 下载速度

| 用户 | 测试点 | 预期 |
|------|--------|------|
| 普通 | 下载大文件观察速度 | 被限速在约定值附近（如 ~100KB/s） |
| 会员 | 下载大文件观察速度 | 跑满带宽，不限速 |
| 普通→会员 | 下载中升级为会员 | 速度实时切换到不限速 |
| 会员→普通 | 下载中会员过期 | 速度降级到限速值 |

### 3.2 并发下载数

| 用户 | 测试点 | 预期 |
|------|--------|------|
| 普通 | 同时发起 N 个下载（= 上限） | 全部正常下载 |
| 普通 | 同时发起 N+1 个下载 | 第 N+1 个排队 / 拒绝 / 提示升级会员 |
| 会员 | 同时发起 M 个下载（= 上限） | 全部正常下载 |
| 会员 | 同时发起 M+1 个下载 | 排队或提示 |

**边界值**：取上限值 N、N+1；会员上限 M、M+1

### 3.3 单文件大小上限

| 用户 | 测试点 | 预期 |
|------|--------|------|
| 普通 | 下载文件大小 = 上限-1 | 正常下载 |
| 普通 | 下载文件大小 = 上限 | 正常下载（含边界） |
| 普通 | 下载文件大小 = 上限+1 | 提示"该文件需会员下载" |
| 会员 | 下载超限大文件 | 正常下载 |

**边界值三点法**：上限-1、上限、上限+1

### 3.4 每日下载配额

| 用户 | 测试点 | 预期 |
|------|--------|------|
| 普通 | 当日累计下载 = 配额-1 | 正常下载 |
| 普通 | 当日累计下载 = 配额 | 正常下载（临界点） |
| 普通 | 当日累计下载 > 配额 | 拦截并提示"今日下载量已达上限" |
| 普通 | 跨天后下载 | 配额正确重置，可正常下载 |
| 会员 | 无配额限制 | 不受限制 |

**边界值**：配额-1、配额、配额+1；跨天重置验证

## 四、异常与容错

| 场景 | 测试点 | 预期 |
|------|--------|------|
| 网络中断 | 下载中途断网 | 支持断点续传 |
| 会员过期 | 下载中会员到期 | 降级限速 + 提示续费 |
| 配额耗尽 | 配额用满后点击下载 | 提示升级会员或等待次日 |
| 并发超限 | 超并发数后关闭一个任务 | 排队任务自动开始 |
| 服务端异常 | 下载服务不可用 | 提示"服务繁忙"，不崩溃 |
| 文件被删除 | 下载中源文件被删除 | 提示"文件不存在"，优雅退出 |

---

## 五、非功能

| 维度 | 测试点 | 预期 |
|------|--------|------|
| 性能 | 大量用户同时下载 | 限速策略正确生效，不因并发失效 |
| 安全 | 会员下载流是否可被抓包盗用 | 加密/鉴权，无法直接外链 |
| 兼容 | 各端（Web/iOS/Android/PC）权益表现一致 | 同一账号各端限速/配额行为一致 |

---

## 方法论对照

| 测试方法 | 应用位置 |
|---------|---------|
| **等价类划分** | 用户身份（普通/会员）、权益状态（限速/不限速、有配额/无配额） |
| **边界值分析** | 并发上限（N/N+1）、文件大小（上限±1）、日配额（满/满+1） |
| **场景法** | 升级/降级切换、断点续传、跨天重置 |
| **状态迁移** | 普通→会员、会员→普通（过期）、配额未满→已满 |

## 一句话总结

> 网盘下载权益测试先理清权益对比表作为基线，再按功能→权益差异→异常→非功能四层展开，权益层用等价类（普通/会员）+ 边界值（上限±1）+ 状态迁移（升级/降级/跨天）确保分层逻辑正确。
