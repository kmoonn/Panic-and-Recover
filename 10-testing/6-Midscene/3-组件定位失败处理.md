# Midscene.js 组件定位失败处理

## 定位为什么会失败

| 原因 | 说明 |
|---|---|
| 页面未加载完成 | 元素还没渲染出来，截图里找不到 |
| 描述不精确 | "点击按钮"但页面上有多个按钮，模型选错 |
| 视觉变化 | 样式/颜色/布局改了，模型不再匹配 |
| 模型能力不足 | 复杂界面元素密集，模型无法准确区分 |
| 缓存失效 | DOM 变更导致哈希 ID 失效，缓存命中失败 |

## 内置容错机制

Midscene 自身已有一层容错：

```
模型返回预测元素 ID
  → 查 ID 映射缓存
    → 命中：直接定位 DOM ✅
    → 未命中：自动降级二次视觉定位（重新截图 + 推理）
      → 定位成功 ✅
      → 定位失败 ❌ → 报告失败详情
```

## 实践处理策略

### 1. 等待页面就绪

最常见失败原因：**页面还没渲染完就操作了**。

```typescript
// 等待元素出现再操作
await aiAssert("页面中存在搜索按钮");  // 先断言元素存在
await aiAction("点击搜索按钮");        // 再操作

// 或用 Playwright 原生等待
await page.waitForLoadState("networkidle");
await aiAction("点击搜索按钮");
```

### 2. 精确化描述

模糊描述是定位失败的高频原因，增加上下文限定词：

```typescript
// ❌ 模糊：页面上可能有多个"提交"
await aiAction("点击提交按钮");

// ✅ 精确：加上位置/颜色/上下文
await aiAction("点击表单底部蓝色的提交按钮");
await aiAction("点击弹窗中的确认按钮");
```

### 3. 拆步降复杂度

一个指令做太多事，模型容易出错：

```typescript
// ❌ 一步到位，模型规划压力大
await aiAction("在搜索框输入关键词并选择筛选条件然后点击搜索");

// ✅ 拆成多步，每步简单明确
await aiAction("在搜索框输入'测试'");
await aiAction("点击状态筛选下拉框");
await aiAction("选择'进行中'");
await aiAction("点击搜索按钮");
```

### 4. 混合定位策略

传统选择器稳定时优先用，失效时 AI 兜底：

```typescript
// 优先用稳定 ID
try {
  await page.click("#submit-btn");
} catch {
  // 传统定位失败，AI 视觉兜底
  await aiAction("点击提交按钮");
}
```

推荐优先级：`id > name > type > 语义 class > 文案描述 > AI 视觉`

### 5. 特殊组件处理

#### v-select / 下拉框双 DOM 陷阱

下拉框组件通常有**两个 DOM 节点**（触发器 + 浮层选项），浮层可能标记为隐藏：

```typescript
// Midscene 内置过滤隐藏元素逻辑，但手动处理时需注意
await aiAction("点击状态下拉框");        // 点击触发器
await aiAction("选择'已完成'选项");       // 操作浮层
```

#### Canvas 内元素

Canvas 元素无 DOM 结构，只能靠视觉定位：

```typescript
// Canvas 内元素无法用选择器，必须视觉定位
await aiAction("点击画布中的红色圆形");
```

### 6. 利用可视化报告调试

每次运行生成报告，**定位失败时重点看**：
- 该步截图：模型看到了什么
- 推理详情：模型为什么选了这个元素
- 在线调整提示词：直接修改描述重新运行，快速迭代

### 7. 缓存复用

相同页面 + 相同指令可复用历史 AI 规划结果，减少不确定性：

```
首次运行：截图 → 模型推理 → 定位结果 → 缓存
再次运行：同页面 + 同指令 → 直接读缓存 → 跳过推理
```

批量执行时显著提升效率和稳定性。

## 处理流程总结

```
定位失败
  ├── 截图里没有？ → 等待页面就绪后重试
  ├── 描述不精确？ → 加限定词（位置/颜色/上下文）
  ├── 一步太复杂？ → 拆成多步简单操作
  ├── DOM 可选？   → 优先选择器，AI 兜底
  └── 仍失败？     → 看可视化报告 → 调整提示词 → 重跑
```

## 一句话总结

> 定位失败先等页面就绪、精确化描述、拆步降复杂度、传统选择器优先AI兜底、看报告调提示词。
