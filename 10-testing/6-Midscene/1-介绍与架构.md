# Midscene.js 介绍与架构

## 是什么

Midscene.js 是字节跳动 Web Infra 团队开源的 **AI 视觉驱动 UI 自动化测试框架**。核心特点：**摒弃传统 DOM 选择器，仅凭截图 + 多模态模型理解界面**，用自然语言描述操作意图即可完成自动化。

覆盖场景：Web、Android、iOS、桌面端、Canvas、跨域 iframe。

## 核心架构

```
┌─────────────┐     ┌──────────────┐     ┌──────────────┐     ┌─────────────┐
│  自然语言指令  │ ──→ │  截图 + 模型推理  │ ──→ │  ID 映射缓存定位  │ ──→ │  操作执行     │
│ (aiAct/Query) │     │ (多模态 LLM)   │     │ (hash → DOM)   │     │ (点击/输入等) │
└─────────────┘     └──────────────┘     └──────────────┘     └─────────────┘
```

### 三层核心机制

| 层 | 机制 | 说明 |
|---|---|---|
| **视觉理解层** | 纯截图驱动 | 不依赖 DOM / Accessibility 树，仅凭截图让模型理解界面 |
| **定位缓存层** | ID 映射缓存 | 为每个 DOM 元素生成基于内容和位置的稳定哈希 ID，AI 返回 ID → 缓存直接定位 DOM 节点 |
| **执行层** | 浏览器自动化 | 通过 Puppeteer / Playwright 驱动操作 |

### ID 映射缓存机制详解

1. 页面扫描阶段：为每个 DOM 元素生成 **基于内容和位置的稳定哈希 ID**
2. 在浏览器 `window` 对象中建立 **ID → DOM 节点**的映射缓存
3. AI 首次调用返回预测元素 ID，通过缓存**直接定位**，避免频繁 AI 调用
4. 容错：ID 查找失败时**自动降级为二次视觉定位**

## 输入输出

### 输入

| 输入 | 说明 | 示例 |
|---|---|---|
| 自然语言指令 | 通过 API 传入操作意图 | `"点击蓝色提交按钮"` |
| 界面截图 | 平台适配器自动捕获 | 无需手动提供 |

### 输出

| API | 返回 | 说明 |
|---|---|---|
| `aiAct` | void | 执行操作（点击/输入/滚动等） |
| `aiQuery` | 结构化数据 | 自定义 JSON 格式从页面提取数据 |
| `aiAssert` | 断言结果 | 自然语言断言 |
| `aiBoolean` | boolean | 布尔判定 |
| 可视化报告 | HTML 报告 | 含动画回放 + 步骤详情 |

## 支持的多模态模型

Qwen3.x、Doubao-Seed-2.1、GLM-4.6V、Gemini-3.5-flash、UI-TARS 等，含可自托管开源选项。

## 与传统方案的区别

| | 传统 UI 自动化 | Midscene.js |
|---|---|---|
| 定位方式 | CSS/XPath 选择器 | 自然语言 + 视觉理解 |
| 维护成本 | DOM 变更就挂 | 视觉不变就能定位 |
| Canvas 支持 | ❌ | ✅ |
| 跨域 iframe | ❌ | ✅ |
| 编写方式 | 写选择器代码 | 写自然语言描述 |

## 适用场景

- 页面频繁迭代、选择器维护成本高
- Canvas / WebView / 原生应用等传统工具难以覆盖
- 快速原型、验收测试、RPA 流程自动化
- 作为 AI Agent 的操作执行工具

## 一句话总结

> Midscene.js是AI视觉驱动UI自动化框架，摒弃选择器靠截图加多模态模型理解界面，自然语言即操作。
