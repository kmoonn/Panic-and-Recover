# SpringBoot 自动装配原理

@EnableAutoConfiguration 启用自动装配

所谓的”SpringBoot自动装配”就是指：通过注解和一些简单的配置就能将某些组件载入Spring容器环境中，便于使用。

## 八股速记

**Q: Spring Boot 自动装配**

- **核心**：`@SpringBootApplication` = `@Configuration` + `@EnableAutoConfiguration` + `@ComponentScan`。
- **自动装配原理**：`@EnableAutoConfiguration` 通过 `spring.factories`（新版 `AutoConfiguration.imports`）加载一堆自动配置类，配合 **`@Conditional`** 系列注解**按条件生效**（有某个类/某个 Bean/某个配置才装配）。
- **价值**：约定优于配置，starter 依赖一引入就自动配好，免去大量 XML。

**⭐ 加分/易错**：Boot"零配置"不是魔法，是**条件装配 + 默认值**；`@ConditionalOnMissingBean` 让用户能覆盖默认配置。

## 一句话总结

> @EnableAutoConfiguration通过注解和简单配置自动将组件载入Spring容器，实现约定优于配置
