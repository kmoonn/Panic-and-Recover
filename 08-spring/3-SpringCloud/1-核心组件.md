Nacos/Eureka：注册中心、服务注册与发现
Spring Cloud Gateway：网关，路由、限流、拦截、鉴权
Feign：声明式远程调用，简化 HTTP 请求
Ribbon / LoadBalancer：客户端负载均衡
Sentinel / Hystrix：熔断、降级、限流、容错
Seata：分布式事务
Sleuth+Zipkin：分布式链路追踪
Config/Nacos 配置中心：统一配置管理

## 一句话总结

> Spring Cloud核心组件：注册中心、网关、远程调用、负载均衡、熔断限流、分布式事务、链路追踪、配置中心
