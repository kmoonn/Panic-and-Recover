# 聚合函数

## 什么是聚合函数？

聚合函数对**一组值进行计算并返回单个值**，常与 GROUP BY 配合使用，用于数据统计和分析。

## 常用聚合函数

| 函数 | 作用 | 示例 | 结果 |
|---|---|---|---|
| COUNT() | 统计行数 | COUNT(*) | 表中总行数 |
| SUM() | 求和 | SUM(salary) | 薪资总和 |
| AVG() | 求平均值 | AVG(salary) | 平均薪资 |
| MAX() | 求最大值 | MAX(salary) | 最高薪资 |
| MIN() | 求最小值 | MIN(salary) | 最低薪资 |

```sql
-- 基本用法
SELECT
    COUNT(*) AS total,
    SUM(salary) AS total_salary,
    AVG(salary) AS avg_salary,
    MAX(salary) AS max_salary,
    MIN(salary) AS min_salary
FROM employee;

-- 配合 GROUP BY
SELECT department, COUNT(*) AS cnt, AVG(salary) AS avg_sal
FROM employee
GROUP BY department;
```

## COUNT 详解

### COUNT(*) vs COUNT(1) vs COUNT(列名)

| 写法 | 含义 | 是否忽略 NULL | 性能 |
|---|---|---|---|
| COUNT(*) | 统计总行数 | 不忽略（含 NULL 行） | InnoDB 中最优 |
| COUNT(1) | 统计总行数 | 不忽略（含 NULL 行） | 与 COUNT(*) 等价 |
| COUNT(列名) | 统计该列非 NULL 值的行数 | 忽略 NULL | 需要判断列是否为 NULL |

```sql
-- 示例数据：id=1 email='a@b.com', id=2 email=NULL, id=3 email='c@d.com'

SELECT COUNT(*) FROM user;      -- 结果：3（统计所有行）
SELECT COUNT(1) FROM user;      -- 结果：3（与 COUNT(*) 等价）
SELECT COUNT(email) FROM user;  -- 结果：2（忽略 NULL 行）
```

### 关键结论

1. **COUNT(*) 和 COUNT(1) 完全等价**，都是统计总行数，不存在 COUNT(1) 更快的说法
2. **COUNT(列名)** 只统计该列非 NULL 的行数
3. 在 InnoDB 中，COUNT(*) 会选择最小的索引来遍历（减少 I/O），不一定扫描全表

## 聚合函数与 NULL

| 函数 | 对 NULL 的处理 |
|---|---|
| COUNT(*) | 不忽略 NULL，统计所有行 |
| COUNT(列名) | 忽略 NULL |
| SUM() | 忽略 NULL |
| AVG() | 忽略 NULL（只计算非 NULL 值的平均） |
| MAX() | 忽略 NULL |
| MIN() | 忽略 NULL |

```sql
-- 示例：score 列有 NULL 值
-- 数据：80, 90, NULL, 70

SELECT COUNT(score) FROM t;   -- 3（忽略 NULL）
SELECT AVG(score) FROM t;     -- 80（(80+90+70)/3，不是 /4）
SELECT SUM(score) FROM t;     -- 240

-- 如果想把 NULL 当 0 处理
SELECT AVG(IFNULL(score, 0)) FROM t;  -- 60（(80+90+0+70)/4）
```

## 与 GROUP BY 配合

```sql
-- 每个部门的员工数和平均薪资
SELECT
    department,
    COUNT(*) AS emp_count,
    AVG(salary) AS avg_salary
FROM employee
GROUP BY department
HAVING COUNT(*) > 5;   -- 筛选人数大于 5 的部门
```

## 面试高频问题

### Q: COUNT(*) 和 COUNT(列名) 的区别？

- COUNT(*) 统计总行数，包含 NULL 值的行
- COUNT(列名) 统计该列非 NULL 值的行数，忽略 NULL
- COUNT(*) 和 COUNT(1) 完全等价

### Q: AVG 忽略 NULL 会影响结果吗？

会。AVG 只对非 NULL 值求平均。如果列中有 NULL 值，AVG 的分母是**非 NULL 值的个数**，而不是总行数。如需将 NULL 视为 0，使用 `AVG(IFNULL(col, 0))`。

### Q: 聚合函数能用在 WHERE 中吗？

不能。聚合函数只能用在 SELECT、HAVING 和 ORDER BY 中。WHERE 在分组前执行，此时还没有聚合结果。需要过滤聚合结果请使用 HAVING。

```sql
-- 错误
SELECT department, AVG(salary) FROM employee WHERE AVG(salary) > 10000 GROUP BY department;

-- 正确
SELECT department, AVG(salary) FROM employee GROUP BY department HAVING AVG(salary) > 10000;
```

## 一句话总结

聚合函数（COUNT/SUM/AVG/MAX/MIN）对一组值计算返回单值，COUNT(*) 统计所有行而 COUNT(列名) 忽略 NULL，聚合函数忽略 NULL（COUNT(*) 除外），不能在 WHERE 中使用，需配合 HAVING 过滤聚合结果。
