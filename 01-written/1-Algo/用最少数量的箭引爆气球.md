# 用最少数量的箭引爆气球（LeetCode 452）

> 一句话：**按右端点排序，一支箭尽量射当前右端点，下一个气球左端点超过箭位置才需要新箭**。

## 题目

气球在 x 轴上有横向区间 `[left, right]`，箭从某个 x 垂直射出，能引爆所有覆盖该 x 的气球。求引爆全部气球所需最少箭数。如 `[[10,16],[2,8],[1,6],[7,12]]` → 2 支。

## 为什么按"右端点"排序

一支箭应该尽量射得靠右（射在当前这批气球共同的右边界），这样能顺带引爆后面更多气球。按右端点从小到大排序后：

- 箭先射在第一个气球的右端点；
- 遍历后面的气球，只要它的**左端点 `<=` 当前箭位置**，说明这箭能扎到它，跳过；
- 一旦某个气球**左端点 `>` 当前箭位置**，说明射不到，需要**新箭**，箭位置更新为这个气球的右端点。

```python
def findMinArrowShots(points):
    points.sort(key=lambda x: x[1])      # 按右端点排序
    arrows = 1                           # 至少 1 支
    pos = points[0][1]                   # 当前箭射的位置 = 第一个气球右端点
    for l, r in points[1:]:
        if l > pos:                      # 当前箭扎不到 -> 加一支新箭
            arrows += 1
            pos = r                      # 新箭射在这个气球的右端点
    return arrows
```

> 注意边界：气球边界相接（如 `[2,8]` 和 `[8,10]`）也算能被同一箭引爆，所以用 `l > pos`（严格大于才加箭）。

## 记忆锚点

- 和"无重叠区间"是**同一招**：按右端点排序 + 贪心。这里数"需要几支箭"，那里数"能留几个不重叠区间"，其实统计的是同一个量。
- 箭位置只在"够不到"时更新，一直卡在最靠右能覆盖的位置。

## 复杂度

- 时间 O(n log n)（排序主导），空间 O(1)

## 一句话总结

> 按右端点排序，箭卡在当前右端点，下一个气球左端超过箭位置才加箭——与无重叠区间同源的贪心模板。
