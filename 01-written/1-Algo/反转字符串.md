# 反转字符串（LeetCode 344）

> 一句话：**左右双指针**向中间交换，原地反转。

## 题目

原地反转字符数组 `s`，空间 O(1)。

```python
def reverseString(s):
    left, right = 0, len(s) - 1
    while left < right:
        s[left], s[right] = s[right], s[left]   # Python 交换一行搞定
        left += 1
        right -= 1
```

> 面试若允许用库：`s.reverse()` 或 `s[:] = s[::-1]`，但手写双指针更能体现基本功。

## 复杂度

- 时间 O(n)，空间 O(1)

## 一句话总结

> 左右指针向中间走，交换后各进一步，相遇即停。
