# 笔试 Python 语法速查

> 笔试写算法时最常用的 Python 语法速查，不是入门教程——是"知道有这个东西但忘了怎么写"的备忘。

## 排序

| 方法 | 就地？ | 返回值 | 适用 |
|------|--------|--------|------|
| `list.sort(key=, reverse=)` | ✅ 就地排 | `None` | 只需排列表 |
| `sorted(iterable, key=, reverse=)` | ❌ 不动原 | 新列表 | 任何可迭代对象；需要保留原数据 |

```python
# 按 key 排序
sorted([3, 1, 2])                          # [1, 2, 3]
sorted([(-3, 1), (-1, 2), (-2, 3)], key=lambda x: x[0])  # 按元组第一个元素
sorted(dict.items(), key=lambda x: x[1])    # dict 按值排序

# 降序
sorted([3, 1, 2], reverse=True)             # [3, 2, 1]

# 多关键字排序：先按第二维升序，再按第一维降序
sorted(intervals, key=lambda x: (x[1], -x[0]))
```

## Lambda

笔试中 lambda 几乎只用在 `sorted(key=)` 和 `map/filter` 里：

```python
lambda x: x[1]           # 取元组第二个元素
lambda x: -x             # 取反（降序等价）
lambda x: (x[1], -x[0])  # 多关键字：第二维升序 + 第一维降序
lambda x, y: x + y       # 多参数
```

> 如果 lambda 超过一行，就写 `def`——笔试里可读性 > 炫技。

## 列表推导式

```python
[x * 2 for x in range(5)]               # [0, 2, 4, 6, 8]
[x for x in nums if x > 0]              # 过滤
[i for i, v in enumerate(nums) if v > 0] # 带索引过滤
[k for k, v in dict.items() if v > 0]   # dict 过滤

# 嵌套（矩阵展开等）
[x for row in matrix for x in row]

# 二维初始化（注意：别用 [[0]*n]*n，那是浅拷贝）
[[0] * n for _ in range(m)]
```

| 函数 | 作用 | 笔试常用场景 |

for i, v in enumerate(nums):

any(x > 0 for x in nums)   # 是否存在正数
all(x > 0 for x in nums)   # 是否全为正数

## 字典

| 操作 | 写法 |
|------|------|
| 计数 | `d[key] = d.get(key, 0) + 1` |
| 默认值 | `d = defaultdict(int)` |
| 按值排序 | `sorted(d.items(), key=lambda x: x[1])` |
| 取最大键 | `max(d, key=d.get)` |
| 安全取值 | `d.get(key, default)` |

```python
from collections import defaultdict

# 计数最简写法
d = defaultdict(int)
for c in s:
    d[c] += 1

# 普通 dict 计数
d = {}
for c in s:
    d[c] = d.get(c, 0) + 1
```

## collections 模块

| 类 | 作用 | 笔试场景 |
|----|------|---------|
| `Counter` | 计数器 | 统计频率、Top-K |
| `defaultdict` | 带默认值的 dict | 计数、分组 |
| `deque` | 双端队列 | BFS、滑动窗口 |
| `OrderedDict` | 有序字典 | LRU Cache（Python 3.7+ 普通 dict 已有序） |

```python
from collections import Counter, defaultdict, deque

# Counter
cnt = Counter('abracadabra')
cnt.most_common(2)     # [('a', 5), ('b', 2)]

# deque（BFS 用）
q = deque([start])
q.append(x)            # 右端入队
q.popleft()            # 左端出队（O(1)，list.pop(0) 是 O(n)）

# deque（滑动窗口最大值）
dq = deque()
dq.append(i)
while dq and nums[dq[0]] <= nums[i]:
    dq.popleft()
```

## 栈与队列

| 数据结构 | Python 实现 | 核心操作 | 笔试场景 |
|---------|------------|---------|---------|
| **栈** | `list` | `append()` 压栈 / `pop()` 弹栈（均 O(1)） | 括号匹配、单调栈、DFS |
| **队列** | `collections.deque` | `append()` 入队 / `popleft()` 出队（均 O(1)） | BFS、滑动窗口 |
| **双端队列** | `collections.deque` | `appendleft()` / `pop()` / `popleft()` / `append()` | 滑动窗口最大值 |
| **优先队列** | `heapq` | `heappush()` / `heappop()`（最小堆） | Top-K、Dijkstra、合并 K 链表 |

```python
# 栈：用 list 即可
stack = []
stack.append(x)       # 压栈
stack.pop()            # 弹栈
stack[-1]              # 栈顶（peek）

# 队列：必须用 deque，别用 list.pop(0)（O(n)）
from collections import deque
q = deque()
q.append(x)           # 入队（右端）
q.popleft()           # 出队（左端，O(1)）
q[0]                  # 队首（peek）

# 单调栈（递减栈：找下一个更大元素）
stack = []
for i, v in enumerate(nums):
    while stack and nums[stack[-1]] < v:
        idx = stack.pop()
        res[idx] = v    # v 是 nums[idx] 的下一个更大元素
    stack.append(i)

# 单调队列（递减：滑动窗口最大值）
from collections import deque
dq = deque()           # 存下标
for i, v in enumerate(nums):
    while dq and nums[dq[-1]] <= v:
        dq.pop()       # 比当前小的全踢掉
    dq.append(i)
    if dq[0] <= i - k:  # 过期出队
        dq.popleft()
    if i >= k - 1:
        res.append(nums[dq[0]])  # 队首就是窗口最大值
```

> **笔试易错**：队列用 `list.pop(0)` 是 O(n)，必须用 `deque.popleft()`；栈用 `list` 就够了，不需要 `deque`。

## 极值初始化与常用常量

笔试中经常需要初始化一个"极大/极小值"用来比较更新：

```python
# 正无穷 / 负无穷
float('inf')       # 正无穷，任何数都比它小
float('-inf')      # 负无穷，任何数都比它大

# 用法：求最小值时初始化为正无穷
ans = float('inf')
for x in nums:
    ans = min(ans, x)    # 第一个 x 一定比 inf 小，更新成功

# 求最大值时初始化为负无穷
ans = float('-inf')
for x in nums:
    ans = max(ans, x)    # 第一个 x 一定比 -inf 大，更新成功
```

| 场景 | 初始化 | 说明 |
|------|--------|------|
| 求最小值 | `float('inf')` | 保证第一次比较就被覆盖 |
| 求最大值 | `float('-inf')` | 保证第一次比较就被覆盖 |
| 求最短路径 | `dist = [float('inf')] * n` | Dijkstra 初始距离 |
| DP 初始化 | `dp = [float('inf')] * (n+1)` | 表示"不可达" |
| 求最长长度 | `ans = 0` | 长度最小就是 0，不需要负无穷 |

### 替代写法对比

| 写法 | 优点 | 缺点 |
|------|------|------|
| `float('inf')` | 语义清晰，支持浮点运算 | 是浮点数，跟整数比较有时坑 |
| `10**18` / `0x3f3f3f3f` | 纯整数，无类型问题 | 需要确保不会溢出；`0x3f` 是 C 习惯 |
| `nums[0]` | 不用记特殊值 | 需要确保数组非空 |
| `math.inf` | 标准库写法 | 等价于 `float('inf')`，要 import |

```python
# 笔试推荐：直接用第一个元素
ans = nums[0]          # 不用记 inf，也不会有类型问题
for x in nums[1:]:
    ans = min(ans, x)

# DP 场景必须用 inf（初始状态没有第一个元素可取）
dp = [float('inf')] * (n + 1)
dp[0] = 0

# 整数场景的极大值（避免浮点）
INF = 10**18           # 笔试数据范围一般 ≤ 10^9，10^18 安全
```

> **笔试注意**：`float('inf') + 1 == float('inf')`（无穷加有限还是无穷）；`float('inf') > 10**18` 为 True。但 `int(float('inf'))` 会报错——不要把 inf 转整数。

## heapq（优先队列 / 最小堆）

```python
import heapq

# 建堆
heapq.heapify(nums)          # 原地建最小堆

# 压入/弹出
heapq.heappush(heap, x)      # 压入
heapq.heappop(heap)          # 弹出最小值

# Top-K 最大：用负数模拟最大堆
heap = []
for x in nums:
    heapq.heappush(heap, -x)  # 取负 → 最小堆变最大堆

# Top-K 最小：nsmallest
heapq.nsmallest(k, nums)

# 合并 k 个有序列表
heapq.merge(list1, list2, list3)  # 惰性迭代器
```

## 数值取整与格式化

| 需求 | 写法 | 结果示例 |
|------|------|---------|
| 向下取整（地板除） | `a // b` | `7 // 2` → `3` |
| 向上取整 | `(a + b - 1) // b` | `7 // 3` → `3`，但 `(7+3-1)//3` → `3`；`(8+3-1)//3` → `3` |
| 向上取整（通用） | `-(-a // b)` | `-(-7//3)` → `3` |
| 四舍五入 | `round(x, ndigits)` | `round(3.456, 2)` → `3.46` |
| 向零取整 | `int(x)` | `int(-3.7)` → `-3`；`int(3.7)` → `3` |
| 保留 N 位小数（字符串） | `f"{x:.2f}"` | `f"{3.1:.2f}"` → `"3.10"` |
| 保留 N 位小数（数值） | `round(x, N)` | `round(3.14159, 3)` → `3.142` |
| 绝对值 | `abs(x)` | `abs(-5)` → `5` |
| 商 + 余数 | `divmod(a, b)` | `divmod(7, 3)` → `(2, 1)` |
| 幂运算 | `x ** n` 或 `pow(x, n)` | `2 ** 10` → `1024` |
| 取模 | `a % b` | `7 % 3` → `1`；`-7 % 3` → `2`（Python 模非负） |

```python
# 向上取整：两种写法等价
import math
math.ceil(7 / 3)       # 3（浮点除法 + ceil，可能有浮点误差）
(7 + 3 - 1) // 3       # 3（纯整数，笔试推荐）
-(-7 // 3)             # 3（纯整数，更简洁）

# round 的银行家舍入（偶数舍入）
round(2.5)    # 2（不是 3！向偶数靠拢）
round(3.5)    # 4
round(2.6)    # 3

# 保留小数位输出
pi = 3.14159265
f"{pi:.2f}"               # "3.14"
f"{pi:.4f}"               # "3.1416"（自动四舍五入）
round(pi, 2)               # 3.14（float，尾部 0 不保留）

# 大数取模（笔试求余数）
(10**9 + 7)               # 常见模数
ans = (ans * x) % MOD     # 边乘边取模防爆
```

> **笔试注意**：`round()` 使用银行家舍入（0.5 向偶数靠），不是数学四舍五入。需要严格四舍五入时用 `int(x + 0.5)` 或 `math.floor(x + 0.5)`。

## 常见笔试陷阱

| 陷阱 | 说明 |
|------|------|
| `[[0]*n]*n` | 浅拷贝，改一行全变；用 `[[0]*n for _ in range(n)]` |
| `list.pop(0)` | O(n)；用 `deque.popleft()` |
| `x is y` vs `x == y` | `is` 比身份，`==` 比值；小整数缓存可能误导 |
| 可变默认参数 | `def f(a=[]):` 只创建一次列表；用 `def f(a=None): a = a or []` |
| 字典遍历中修改 | 遍历时不能增删 key；先 `list(d.items())` 再改 |
| 除法 | Python 3 `/` 是浮点；整除用 `//`，向上取整用 `(a + b - 1) // b` |
