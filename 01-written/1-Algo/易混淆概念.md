# 笔试易混淆概念辨析

> 笔试题里经常出现"子序列""子数组""连续"等限定词，读错题意直接全错。这张表把最常见的易混淆概念一次理清。

---

## 子序列 vs 子数组 vs 子串

| 概念 | 是否连续 | 元素顺序 | 示例（`[1,2,3,4]`） | 典型题型 |
|------|---------|---------|---------------------|---------|
| **子序列**（subsequence） | ❌ 不连续 | ✅ 保持原序 | `[1,3]`、`[2,4]`、`[1,2,4]` | 最长递增子序列、编辑距离 |
| **子数组**（subarray） | ✅ 连续 | ✅ 保持原序 | `[1,2]`、`[2,3,4]` | 最大子数组和、滑动窗口 |
| **子串**（substring） | ✅ 连续 | ✅ 保持原序 | 字符串专属术语 | 最长无重复子串、回文子串 |

```
原数组：[1, 2, 3, 4]

子序列（不连续）：  [1,3] ✓   [1,4] ✓   [2,4] ✓
子数组（连续）：    [1,3] ✗   [1,4] ✗   [2,3] ✓   [3,4] ✓
```

> **口诀**：子序列可以跳着选，子数组必须挨着切。

---

## 连续 vs 非连续

笔试题里"连续"二字是关键分水岭：

| 题目限定 | 解法倾向 | 示例 |
|---------|---------|------|
| **连续**子数组和 | 前缀和 / 滑动窗口 | "和为 K 的连续子数组个数" |
| **不要求连续**的子序列 | DP | "最长递增子序列" |
| **连续**子串 | 滑动窗口 / 双指针 | "最长无重复字符子串" |
| **不要求连续**的子序列 | DP / 贪心 | "两个字符串的最长公共子序列" |

## 递增 vs 严格递增 vs 非递减

| 概念 | 含义 | 相邻元素关系 | 示例 |
|------|------|------------|------|
| **严格递增** | 每步必须变大 | `a[i] < a[i+1]` | `[1,3,5]` ✓；`[1,3,3]` ✗ |
| **递增**（笔试默认） | 同"严格递增" | `a[i] < a[i+1]` | 视题意，多数等价严格递增 |
| **非递减** | 允许相等 | `a[i] <= a[i+1]` | `[1,3,3,5]` ✓ |
| **严格递减** | 每步必须变小 | `a[i] > a[i+1]` | `[5,3,1]` ✓ |
| **非递增** | 允许相等 | `a[i] >= a[i+1]` | `[5,3,3,1]` ✓ |

> **笔试注意**：题目写"递增"通常指严格递增，但要看清——写"非递减"的一定允许相等。拿不准时看示例。

## 子集 vs 子序列 vs 排列

| 概念 | 顺序是否重要 | 元素是否可重复选 | 示例（`[1,2,3]`） |
|------|------------|---------------|---------------------|
| **子集** | 不重要（集合视角） | 每个元素选或不选 | `{1,3}`、`{2}` |
| **子序列** | 重要（保持原序） | 每个元素选或不选 | `[1,3]` ≠ `[3,1]`（后者不是子序列） |
| **排列** | 重要（任意序） | 每个元素恰好用一次 | `[3,1,2]`、`[2,3,1]` |
| **组合** | 不重要 | 从 n 中选 k 个 | C(3,2) = `{1,2},{1,3},{2,3}` |

## 数组 vs 链表 vs 矩阵

| 概念 | 存储特点 | 随机访问 | 插入/删除 | 笔试常见操作 |
|------|---------|---------|----------|------------|
| **数组** | 连续内存 | O(1) | O(n) | 双指针、前缀和、滑动窗口 |
| **链表** | 离散节点+指针 | O(n) | O(1)（已知位置时） | 反转、快慢指针、合并 |
| **矩阵** | 二维数组 | O(1) | — | 螺旋遍历、岛屿计数、DP |

## 前缀和 vs 差分

| 概念 | 解决什么 | 构建方式 | 笔试场景 |
|------|---------|---------|---------|
| **前缀和** | 区间求和 | `pre[i+1] = pre[i] + a[i]` | "区间 [l,r] 的和" → `pre[r+1] - pre[l]` |
| **差分** | 区间修改 | `d[l] += v; d[r+1] -= v` | "把 [l,r] 都加 v" → 两次操作 O(1) |

```python
# 前缀和：求任意区间和 O(1)
pre = [0]
for x in nums:
    pre.append(pre[-1] + x)
# sum(l, r) = pre[r+1] - pre[l]

# 差分：区间加值 O(1)，最后还原
diff = [0] * (n + 1)
diff[l] += v
diff[r + 1] -= v
# 还原：对 diff 求前缀和得到修改后的数组
```

> **关系**：差分是前缀和的逆运算。前缀和的差分 = 原数组，差分的前缀和 = 修改后数组。

## 回溯 vs DFS vs BFS

| 方法 | 遍历方式 | 数据结构 | 适用场景 |
|------|---------|---------|---------|
| **DFS** | 深度优先，一条路走到底 | 栈 / 递归 | 树的遍历、图的连通性、拓扑排序 |
| **BFS** | 广度优先，逐层扩展 | 队列 | 最短路径、层序遍历、岛屿最小步数 |
| **回溯** | 试探 + 撤销 | 递归 + 状态恢复 | 全排列、组合、子集、N 皇后 |

> **区别**：回溯 = DFS + 剪枝 + 撤销。DFS 是遍历策略，回溯是解题框架。

---

## 动态规划 vs 贪心 vs 分治

| 方法 | 核心思想 | 最优子结构 | 笔试标志词 |
|------|---------|-----------|-----------|
| **动态规划** | 记录子问题解，避免重复计算 | ✅ 必须 | "最大/最小/方案数"、"可以重复选" |
| **贪心** | 每步选局部最优，期望全局最优 | ❌ 不一定 | "每次选最大的"、"跳跃游戏" |
| **分治** | 拆成独立子问题，合并结果 | ✅ 必须 | 归并排序、快速排序、大整数乘法 |

> **判断**：能用贪心的不用 DP（更简单）；子问题有重叠用 DP，无重叠用分治。

---

## 一句话总结

> 笔试读题第一关：子序列可以跳（不连续），子数组必须挨（连续）；"递增"默认严格，"非递减"允许等；前缀和管区间求和，差分管区间修改；回溯 = DFS + 撤销。
