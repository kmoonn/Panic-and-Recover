# 打家劫舍（LeetCode 198）

> 一句话：偷不偷当前家 → `dp[i] = max(不偷=dp[i-1], 偷=dp[i-2]+nums[i])`。不能偷相邻两家。

## 题目

数组 `nums` 表示每家的钱，不能偷相邻两家，求最多偷多少。

## DP 定义

`dp[i]` = 偷到第 i 家为止能获得的最大金额。对第 i 家只有两种选择：

- **不偷 i**：金额 = `dp[i-1]`；
- **偷 i**：不能偷 i-1，金额 = `dp[i-2] + nums[i]`。

取两者最大即可。

```python
def rob(nums):
    prev, cur = 0, 0          # prev=dp[i-2], cur=dp[i-1]
    for x in nums:
        prev, cur = cur, max(cur, prev + x)   # 滚动更新
    return cur
```

> 用两个变量滚动即可，不必开数组，空间 O(1)。`prev+x` 是偷当前、`cur` 是不偷。

## 变体提醒

- **环形（213）**：首尾相邻 → 分"偷第一家不偷最后一家"和"不偷第一家"两种，各跑一次取 max。
- **树形（337）**：换成树上 DFS，每个节点返回偷/不偷两个值。

## 复杂度

- 时间 O(n)，空间 O(1)

## 一句话总结

> `dp[i]=max(dp[i-1], dp[i-2]+nums[i])`——偷不偷当前家取最优，两个变量滚动省空间。
