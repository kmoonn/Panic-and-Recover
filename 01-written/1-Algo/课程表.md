# 课程表（LeetCode 207）

> 一句话：**把课程依赖建成有向图，问题等价于判断图中是否有环；可用拓扑排序或 DFS 三色标记解决**。

## 题目

若学习课程 `a` 前必须先完成课程 `b`，则存在有向边 `b → a`。判断是否能完成所有课程。

## 方法一：拓扑排序（BFS）

1. 建邻接表并统计每门课的入度。
2. 将所有入度为 `0` 的课程入队。
3. 每学完一门课，就把后续课程的入度减一；减到 `0` 时入队。
4. 最终处理课程数等于课程总数，说明无环；否则存在环。

```text
先修课完成 → 删除对应依赖边 → 新的入度 0 课程入队
```

## 方法二：DFS 三色标记

| 状态 | 含义 |
|---|---|
| `0` | 未访问 |
| `1` | 当前 DFS 路径中 |
| `2` | 已完成搜索，确认无环 |

搜索时再次遇到状态 `1` 的结点，说明沿当前路径回到了祖先结点，存在有向环；遇到状态 `2` 的结点可以直接跳过。

## 为什么普通 visited 不够

普通布尔标记只能说明“访问过”，无法区分结点仍在当前递归路径中，还是已经完成搜索。环检测必须区分这两种状态，因此需要三色标记或额外递归栈。

## 易错点

- 建边方向要统一：`先修课 → 后续课程`。
- DFS 退出当前结点前，应将状态从 `1` 改为 `2`。
- 本题是有向图环检测，不是网格连通块问题，只是同样使用 DFS 访问状态。

## 复杂度

- 时间 O(V + E)。
- 空间 O(V + E)。

## 一句话总结

> 课程能否全部完成取决于依赖图是否有环：BFS 看能否完成拓扑排序，DFS 看是否遇到当前路径中的灰色结点。
