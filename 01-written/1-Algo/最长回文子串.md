# 最长回文子串（LeetCode 5）

> 一句话：**中心扩散**——枚举每个中心，向两边扩，最好理解也最好写。

## 题目

给字符串 `s`，返回最长回文子串。

## 中心扩散（面试首选）

回文一定关于中心对称。中心有两种：单字符（奇数长，如 `aba`）和双字符间隙（偶数长，如 `abba`）。枚举每个中心，向两边扩。

```python
def longestPalindrome(s):
    def expand(l, r):
        while l >= 0 and r < len(s) and s[l] == s[r]:
            l -= 1
            r += 1
        return s[l + 1:r]        # 退出时 l、r 已越界一步，取中间

    res = ''
    for i in range(len(s)):
        odd = expand(i, i)       # 奇数中心：以 i 为中心
        even = expand(i, i + 1)  # 偶数中心：以 i、i+1 之间为中心
        res = max(res, odd, even, key=len)
    return res
```

## 为什么好记

- 只需一个 `expand` 辅助函数，思路直白：**从中心往两边扩，只要对称就继续**。
- 每个位置试两种中心（奇/偶），取最长。
- 比动态规划（二维 dp 表）更省空间、更少边界坑。

## 复杂度

- 时间 O(n²)（n 个中心 × 每次最多扩 n），空间 O(1)

## 一句话总结

> 枚举中心向两边扩，奇偶各试一次，取最长——`expand` 退出时取 `s[l+1:r]` 是唯一要记的边界。
