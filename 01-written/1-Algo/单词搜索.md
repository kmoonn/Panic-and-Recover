# 单词搜索（LeetCode 79）

> 一句话：**从每个可能的首字母出发进行四方向 DFS，当前路径临时标记已用格子，搜索失败返回时恢复现场**。

## 题目

给定字符网格和目标单词，判断能否通过上下左右相邻格子依次拼出单词；同一个格子在一条路径中只能使用一次。

## DFS + 回溯

搜索状态为 `(行, 列, 当前匹配下标)`：

1. 越界、字符不匹配或当前格子已被使用，返回失败。
2. 已匹配到单词最后一个字符，返回成功。
3. 临时标记当前格子已使用。
4. 向四个方向尝试匹配下一个字符。
5. 返回上一层前恢复当前格子。

```text
选择当前格子 → 临时标记 → 搜索下一字符 → 恢复现场
```

## 与普通连通块 DFS 的区别

| 连通块题 | 单词搜索 |
|---|---|
| 格子全局访问一次即可 | 同一格子可被不同搜索路径使用 |
| 标记后通常不恢复 | 当前路径结束后必须恢复 |
| 目标是遍历完整区域 | 目标是找到满足字符顺序的一条路径 |

## 剪枝

- 当前字符不匹配时立即返回。
- 任一方向成功即可短路，不必继续搜索。
- 若单词长度大于格子总数，可直接返回失败。

## 易错点

- 只能上下左右移动，不能走对角线。
- “不能重复使用”限制的是当前路径，不是所有起点共享一个永久访问集合。
- 即使已经找到成功路径，也要注意恢复现场后再返回，保持状态完整。

## 复杂度

- 时间最坏 O(mn · 4^L)，`L` 为单词长度；实际会因字符匹配和访问限制大量剪枝。
- 空间 O(L)，主要是递归深度。

## 一句话总结

> 单词搜索是网格 DFS 加回溯：标记只对当前路径有效，返回时必须撤销，才能让其他路径继续尝试。
