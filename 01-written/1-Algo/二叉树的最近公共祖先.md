# 二叉树的最近公共祖先（LeetCode 236）

> 一句话：**后序递归，若左右子树各找到一个目标，当前结点就是 LCA；否则把非空那侧往上传**。

## 题目

给定二叉树和两个结点 `p`、`q`，找它们的最近公共祖先（一个结点也可是自己的祖先）。

## 后序递归

递归含义：在以 `root` 为根的子树里找 `p`/`q`，找到就返回找到的那个结点，找不到返回 `None`。

- 递归到 `None` 或命中 `p`/`q`，直接返回 `root`；
- 分别在左右子树递归；
- 若**左右都非空**，说明 `p`、`q` 分居两侧，当前 `root` 就是 LCA；
- 否则返回非空的那一侧（目标都在那边）。

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

def lowestCommonAncestor(root, p, q):
    if root is None or root == p or root == q:
        return root                    # 命中目标或到底，返回
    left = lowestCommonAncestor(root.left, p, q)
    right = lowestCommonAncestor(root.right, p, q)
    if left and right:                 # 两侧各找到一个 -> 当前是 LCA
        return root
    return left if left else right     # 否则把非空侧上传
```

## 记忆锚点

- 三种情况：**两侧都非空** → root 是答案；**只有一侧非空** → 返回那侧；**都空** → None。
- 命中 `p` 或 `q` 就返回，不必继续深挖（包含"一个是另一个祖先"的情形）。

## 复杂度

- 时间 O(n)，空间 O(树高)（递归栈）

## 一句话总结

> 后序递归，命中即返回；左右都找到则当前结点是 LCA，否则上传非空的一侧——树上找公共祖先的经典写法。
