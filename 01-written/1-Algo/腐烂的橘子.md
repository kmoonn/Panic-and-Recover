# 腐烂的橘子（LeetCode 994）

> 一句话：**把所有初始腐烂橘子同时入队做多源 BFS，每扩展一层代表一分钟，最后检查是否仍有新鲜橘子**。

## 题目

腐烂橘子每分钟会使上下左右相邻的新鲜橘子腐烂，求没有新鲜橘子所需的最少分钟数；若无法全部腐烂则返回 `-1`。

## 多源 BFS

1. 首次扫描网格：
   - 所有腐烂橘子同时入队；
   - 统计新鲜橘子数量。
2. 按层执行 BFS，每层表示同一分钟发生的传播。
3. 新鲜橘子第一次被感染时立刻标记、入队，并将新鲜数量减一。
4. BFS 结束后：
   - 新鲜数量为 `0`，返回经过的分钟数；
   - 否则存在无法到达的橘子，返回 `-1`。

```text
第 0 分钟：所有初始腐烂橘子
第 1 分钟：它们共同感染的相邻橘子
第 2 分钟：上一层继续向外感染
```

## 为什么所有起点必须同时入队

腐烂过程是同步发生的。若逐个起点分别 BFS，会把同时传播错误地计算成先后传播；多源 BFS 相当于添加一个虚拟超级起点，能保证每个格子的首次到达时间最短。

## 时间统计

只有当前层确实感染了新橘子时，时间才向后推进。也可以记录层数，但要正确处理“初始就没有新鲜橘子”的情况，此时答案为 `0`。

## 易错点

- 新鲜橘子入队时就要标记腐烂，避免被多个邻居重复入队。
- 空格子 `0` 会阻断传播。
- BFS 结束不代表成功，还必须检查剩余新鲜橘子数量。
- 本题求最短传播时间，DFS 无法自然表达同步的分钟层级。

## 复杂度

- 时间 O(mn)。
- 空间 O(mn)，最坏情况下队列包含大量格子。

## 一句话总结

> 多源 BFS 的关键是“所有源点同时入队、按层扩散、层数代表时间”，最后用剩余新鲜数量判断是否可达。
