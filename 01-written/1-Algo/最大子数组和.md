# 最大子数组和（LeetCode 53）

> 一句话：**遍历时维护"以当前元素结尾的最大和"，负了就丢掉重开**。

## 题目

找一个连续子数组，使其和最大，返回该最大和。如 `[-2,1,-3,4,-1,2,1,-5,4]` → `6`（`[4,-1,2,1]`）。

## 动态规划（Kadane 算法）

设 `cur` 为"以当前元素结尾的最大子数组和"。到新元素时有两个选择：**接在前面**（`cur + x`）或**自己重新开头**（`x`）。前面的和若是负的，只会拖累，果断丢掉。

```python
def maxSubArray(nums):
    cur = nums[0]        # 以当前元素结尾的最大和
    ans = nums[0]        # 全局最大和
    for x in nums[1:]:
        cur = max(x, cur + x)   # 接着前面 or 从自己重开
        ans = max(ans, cur)
    return ans
```

## 记忆锚点

- 核心一行：`cur = max(x, cur + x)`——`cur` 一旦为负，加上 `x` 不如只要 `x`。
- `ans` 单独记录，因为最大和不一定在结尾处取得。

## 复杂度

- 时间 O(n)，空间 O(1)

## 一句话总结

> 维护以当前元素结尾的最大和，前缀为负就重开，全程记全局最大——Kadane 算法一行核心。
