# 三数之和（LeetCode 15）

> 一句话：**先排序，再固定一个数 + 左右双指针**找另外两个，靠"跳过重复"去重。

## 题目

数组 `nums`，找出所有和为 0 且**不重复**的三元组。

## 排序 + 双指针（面试标准解）

排序后，固定第 i 个数，在 `i+1 ~ n-1` 区间用左右指针找 `nums[i] + nums[l] + nums[r] == 0`：

- 和太小 → `l` 右移（找更大的）；
- 和太大 → `r` 左移（找更小的）；
- 正好 → 记录，然后**双指针都跳过重复值**。

```python
def threeSum(nums):
    nums.sort()                       # 关键：先排序
    n = len(nums)
    res = []
    for i in range(n - 2):
        if nums[i] > 0:               # 最小的已 > 0，不可能凑成 0
            break
        if i > 0 and nums[i] == nums[i - 1]:
            continue                  # 跳过重复的固定值（去重）
        l, r = i + 1, n - 1
        while l < r:
            s = nums[i] + nums[l] + nums[r]
            if s < 0:
                l += 1
            elif s > 0:
                r -= 1
            else:
                res.append([nums[i], nums[l], nums[r]])
                l += 1
                r -= 1
                while l < r and nums[l] == nums[l - 1]:   # 跳过重复左值
                    l += 1
                while l < r and nums[r] == nums[r + 1]:   # 跳过重复右值
                    r -= 1
    return res
```

## 三个去重点（易错，背下来）

- 固定值：`i>0 and nums[i]==nums[i-1]` 跳过；
- 命中后左指针：`nums[l]==nums[l-1]` 跳过；
- 命中后右指针：`nums[r]==nums[r+1]` 跳过。

> 排序是双指针能用的前提，也是去重的前提。

## 复杂度

- 时间 O(n²)（排序 O(n log n) + 双指针 O(n²)），空间 O(1)（不计结果）

## 一句话总结

> 排序后固定一个数、左右双指针夹逼；命中后三处跳重去重——两数之和的进阶版。
