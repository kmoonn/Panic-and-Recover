# 无重叠区间（LeetCode 435）

> 一句话：**按右端点排序，贪心保留尽量多的不重叠区间，删除数 = 总数 - 保留数**。

## 题目

给若干区间，求最少删除多少个，使剩下的区间互不重叠。如 `[[1,2],[2,3],[3,4],[1,3]]` → 删 1 个。

## 为什么按"右端点"排序

要保留尽量多的区间，就该每次都留下**右端点最小**的那个——它给后面留的空间最大。所以按右端点从小到大排序后，从左往右扫：

- 当前区间左端点 `>= 上一个保留区间的右端点` → 不重叠，**保留**，更新右端界；
- 否则重叠，**丢弃**（相当于要删掉它）。

```python
def eraseOverlapIntervals(intervals):
    intervals.sort(key=lambda x: x[1])   # 按右端点排序
    count = 1                            # 至少保留 1 个
    last_end = intervals[0][1]           # 上一个保留区间的右端点
    for l, r in intervals[1:]:
        if l >= last_end:                # 不重叠 -> 保留
            count += 1
            last_end = r
    return len(intervals) - count        # 删除数 = 总数 - 保留数
```

> 注意边界：题目里 `[1,2]` 和 `[2,3]` 不算重叠，所以用 `l >= last_end`（带等号）。

## 记忆锚点

- **按右端点排序**是这类"选最多不重叠区间"贪心的核心，和"用最少箭引爆气球"是同一招。
- 求的是"删除数"，别忘了最后 `len - count` 反过来算。

## 复杂度

- 时间 O(n log n)（排序主导），空间 O(1)

## 一句话总结

> 按右端点排序，能不重叠就保留、更新右端界，答案 = 总数 - 保留数——贪心选区间的经典模板。
