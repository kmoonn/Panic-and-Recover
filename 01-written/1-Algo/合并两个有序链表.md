# 合并两个有序链表（LeetCode 21）

> 一句话：**造一个哑结点，双指针比大小接较小的，最后接上剩余部分**。

## 题目

合并两个升序链表为一个新的升序链表。如 `1→2→4` 与 `1→3→4` → `1→1→2→3→4→4`。

## 哑结点 + 双指针

设一个虚拟头 `dummy`，用 `cur` 拼接。每次比较两条链表当前结点，把较小的接到 `cur` 后面并前进。有一条走完后，另一条剩下的直接整段接上。

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

def mergeTwoLists(l1, l2):
    dummy = ListNode()       # 哑结点，简化头部处理
    cur = dummy
    while l1 and l2:
        if l1.val <= l2.val:
            cur.next = l1
            l1 = l1.next
        else:
            cur.next = l2
            l2 = l2.next
        cur = cur.next
    cur.next = l1 if l1 else l2   # 接上剩余部分
    return dummy.next
```

## 记忆锚点

- **哑结点**免去"第一个结点谁当头"的判断，链表题万金油。
- 循环退出后别忘了把还没走完的那条**整段接上**。

## 复杂度

- 时间 O(m + n)，空间 O(1)

## 一句话总结

> 哑结点起手，双指针挑小的接、走完把剩余整段接上——链表合并的标准写法。
