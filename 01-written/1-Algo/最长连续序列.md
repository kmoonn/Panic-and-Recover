# 最长连续序列（LeetCode 128）

> 一句话：**全放进 set，只从"某段的起点"（前一个数不存在）开始往上数长度**。

## 题目

无序数组，求最长连续元素序列的长度，要求 O(n)。如 `[100,4,200,1,3,2]` → `4`（`1,2,3,4`）。

## 哈希集合 + 只从起点扩展

把所有数放进 `set`（去重 + O(1) 查找）。遍历时只对**序列起点**动手：如果 `x-1` 不在 set 里，说明 `x` 是某段连续序列的开头，从它开始一直找 `x+1, x+2...`，数出长度。

```python
def longestConsecutive(nums):
    num_set = set(nums)
    ans = 0
    for x in num_set:
        if x - 1 not in num_set:      # x 是某段连续序列的起点
            cur = x
            length = 1
            while cur + 1 in num_set:  # 往上数
                cur += 1
                length += 1
            ans = max(ans, length)
    return ans
```

## 记忆锚点

- **只从起点扩展**是保证 O(n) 的关键：`if x-1 not in set` 过滤掉中间点，每个数最多被访问两次。
- 不要排序（那是 O(n log n)），用 set 才能做到 O(n)。

## 复杂度

- 时间 O(n)，空间 O(n)

## 一句话总结

> 全塞进 set，只从"前驱不存在"的起点向上数连续长度——避免重复扫描，整体 O(n)。
