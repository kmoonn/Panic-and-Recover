# 手撕快速排序（补充题4 / LeetCode 912）

> 一句话：**选基准 → partition 把小的放左、大的放右 → 递归排左右两段**。

## 题目

实现快速排序，把数组升序排列。

## 分治 + partition

核心是 `partition`：选一个基准值，一趟扫描后让基准落到它的最终位置，左边都比它小、右边都比它大，然后递归处理左右两段。**随机选基准**能避免有序数组退化成 O(n²)。

```python
import random

def sortArray(nums):
    quick_sort(nums, 0, len(nums) - 1)
    return nums

def quick_sort(nums, lo, hi):
    if lo >= hi:                       # 只剩 0 或 1 个元素
        return
    p = partition(nums, lo, hi)
    quick_sort(nums, lo, p - 1)        # 递归左段
    quick_sort(nums, p + 1, hi)        # 递归右段

def partition(nums, lo, hi):
    r = random.randint(lo, hi)         # 随机基准，防止退化
    nums[r], nums[hi] = nums[hi], nums[r]
    pivot = nums[hi]                   # 用末尾作基准
    i = lo                             # i 指向"下一个小于基准的落点"
    for j in range(lo, hi):
        if nums[j] < pivot:
            nums[i], nums[j] = nums[j], nums[i]
            i += 1
    nums[i], nums[hi] = nums[hi], nums[i]   # 基准归位
    return i
```

## 记忆锚点

- `partition` 用双指针：`j` 扫描，`i` 标记小于基准区的边界，遇到小的就换到 `i` 并 `i++`，最后基准换到 `i`。
- **随机基准**是防退化的关键，面试务必写上。
- 递归边界 `lo >= hi` 直接返回。

## 复杂度

- 平均时间 O(n log n)，最坏 O(n²)（基准每次极端），空间 O(log n)（递归栈）
- 不稳定排序。

## 一句话总结

> 随机选基准 partition 归位，再递归左右两段——快排就是「划分 + 分治」，随机基准防退化。
