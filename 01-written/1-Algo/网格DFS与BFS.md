# 网格 DFS 与 BFS

> 一句话：**遍历二维矩阵，遇到未访问的有效起点就启动 DFS/BFS，将同一连通块全部标记，并在搜索过程中计数、求面积或按层扩散**。

## 通用套路

1. 遍历矩阵中的每个格子。
2. 找到满足条件且未访问的格子，触发一次 DFS/BFS。
3. 搜索时依次处理：**越界判断 → 条件判断 → 标记访问 → 向四个方向扩展**。
4. 根据题意统计连通块数量、面积、周长或扩散时间。

```text
for 每个格子 (i, j):
    if 是未访问的有效起点:
        启动 DFS/BFS
        更新答案

search(i, j):
    if 越界或不满足条件: return
    标记 (i, j) 已访问
    搜索上、下、左、右
```

## DFS、BFS 怎么选

| 场景 | 更自然的方式 | 原因 |
|---|---|---|
| 连通块计数、面积统计 | DFS | 写法直接，递归返回值方便累加 |
| 最短步数、每轮扩散 | BFS | 按层遍历，层数天然表示距离或时间 |
| 多个起点同时扩散 | 多源 BFS | 所有起点先入队，保证同步向外扩展 |
| 路径不能重复使用格子 | DFS + 回溯 | 搜索后恢复现场，供其他路径继续尝试 |

## 标记访问的三种方式

- **原地修改**：把陆地改成水，空间小，但会破坏输入；适合岛屿数量、最大面积。
- **额外 `visited`**：保留原矩阵，语义清楚，但需要 O(mn) 空间。
- **临时标记后恢复**：适合单词搜索；当前路径用完后必须撤销标记。

## 高频变形

- **数连通块**：每启动一次搜索，答案加一。
- **求最大面积**：搜索返回当前块面积，维护最大值。
- **求周长**：从陆地走向越界或水域时贡献一条边。
- **边界保护**：先从边界搜索并标记，剩余区域才是被包围区域。
- **传播时间**：多源 BFS，每扩展一层表示经过一分钟。

## 易错点

- 先标记再递归，否则相邻格子会互相重复访问。
- 空矩阵、单行单列需要正常处理。
- DFS 递归深度可能过大，数据规模大时可改为显式栈或 BFS。
- BFS 的时间通常按“层”统计，不是每弹出一个结点就加一。
- 回溯题只能临时修改，返回上一层前必须恢复现场。

## 一句话总结

> 网格题先识别“连通块、最短距离、同步扩散还是路径回溯”，再套遍历矩阵 + 四方向搜索 + 访问标记的骨架。
