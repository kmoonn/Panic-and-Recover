# 全排列（LeetCode 46）

> 一句话：**回溯：每层从"没用过的数"里选一个，选满 n 个就记录，回来时撤销选择**。

## 题目

给不含重复数字的数组，返回所有全排列。如 `[1,2,3]` → 6 种排列。

## 回溯模板

用 `path` 记录当前路径，`used` 标记哪些数已用。每层遍历所有数，跳过用过的，选一个 → 递归 → 撤销（回溯三部曲）。

```python
def permute(nums):
    res = []
    n = len(nums)
    used = [False] * n
    path = []

    def backtrack():
        if len(path) == n:            # 选满了，记录一个排列
            res.append(path[:])       # 注意拷贝，不能直接放 path
            return
        for i in range(n):
            if used[i]:               # 用过的跳过
                continue
            used[i] = True            # 选择
            path.append(nums[i])
            backtrack()               # 递归下一层
            path.pop()                # 撤销
            used[i] = False
    backtrack()
    return res
```

## 记忆锚点

- 回溯三部曲：**做选择（used/append）→ 递归 → 撤销选择（pop/used=False）**，成对出现。
- 记录答案要 `path[:]` **拷贝**，否则存的是同一个引用，最后全被清空。
- 排列 vs 组合：排列用 `used` 数组从头遍历；组合用 `start` 下标避免回头。

## 复杂度

- 时间 O(n · n!)，空间 O(n)（递归深度）

## 一句话总结

> 回溯：每层选一个没用过的数、选满就拷贝进结果、返回时撤销——排列问题用 used 标记的经典模板。
