# 岛屿的周长（LeetCode 463）

> 一句话：**从陆地向四周检查，每遇到一次越界或水域就贡献一条边，所有贡献之和就是岛屿周长**。

## 题目

二维网格中 `1` 表示陆地、`0` 表示水域，且只有一个岛屿，求岛屿周长。

## 核心思路

DFS 遍历整块陆地。对于当前陆地格子：

- 相邻位置越界：贡献 `1` 条边；
- 相邻位置是水域：贡献 `1` 条边；
- 相邻位置是未访问陆地：继续 DFS；
- 相邻位置是已访问陆地：贡献 `0`。

```text
dfs(i, j):
    if 越界或是水域: return 1
    if 已访问: return 0
    标记已访问
    return 四个方向返回值之和
```

## 为什么不能用“陆地格子数 × 4”

相邻的两个陆地格子共享一条边，这条边不属于外部周长。DFS 的边界/水域计数法只统计真正暴露在外的边。

## 易错点

- 判断顺序应先处理越界，再访问网格。
- 已访问陆地必须返回 `0`，否则共享边会被重复计算。
- 本题只有一个岛屿，找到首个陆地后即可启动一次 DFS。

## 复杂度

- 时间 O(mn)，每个格子最多访问一次。
- 空间 O(mn)，最坏情况下为递归栈或访问标记。

## 一句话总结

> 岛屿周长不是数连通块，而是统计陆地四周有多少次“碰到水或边界”。
