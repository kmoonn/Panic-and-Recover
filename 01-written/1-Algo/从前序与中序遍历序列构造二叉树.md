# 从前序与中序遍历序列构造二叉树（LeetCode 105）

> 一句话：**前序第一个是根，用它在中序里切成左右两部分，递归建左右子树**。

## 题目

给前序遍历 `preorder` 和中序遍历 `inorder`（无重复值），还原二叉树。如 `preorder=[3,9,20,15,7], inorder=[9,3,15,20,7]`。

## 分治递归

- **前序**：`[根, 左子树前序, 右子树前序]`，所以前序第一个必是根；
- **中序**：`[左子树中序, 根, 右子树中序]`，在中序里找到根的位置，左边是左子树、右边是右子树；
- 拿到根在中序的位置后，就能把两个序列都切成左、右两段，分别递归。

### 写法一：切片递归（面试首选，最好写最好记）

直接按上面的定义切数组，几乎照着口诀就能默写出来。缺点是切片和 `index` 有额外开销（O(n²)），但面试通常够用，写对最重要。

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

def buildTree(preorder, inorder):
    if not preorder:                 # 空 -> 空树
        return None
    root_val = preorder[0]           # 前序第一个是根
    root = TreeNode(root_val)
    mid = inorder.index(root_val)    # 根在中序里的位置
    # 左子树：前序取接下来 mid 个，中序取根左边的 mid 个
    root.left = buildTree(preorder[1:mid + 1], inorder[:mid])
    # 右子树：剩下的部分
    root.right = buildTree(preorder[mid + 1:], inorder[mid + 1:])
    return root
```

> 记牢切片长度：中序里根左边有 `mid` 个结点，所以前序的左子树就是紧跟根后面的 `mid` 个（`preorder[1:mid+1]`）。

### 写法二：哈希表 + 下标（进阶 O(n)）

嫌切片慢，就用哈希表存中序下标 O(1) 定位根，并用一个指针在前序里从左往右推进（前序顺序天然是「根→左→右」）。

```python
def buildTree(preorder, inorder):
    idx = {v: i for i, v in enumerate(inorder)}  # 中序值 -> 下标
    pre_idx = 0                                  # 前序指针，先定义

    def build(in_left, in_right):
        nonlocal pre_idx
        if in_left > in_right:                   # 空区间
            return None
        root_val = preorder[pre_idx]             # 前序当前值就是根
        pre_idx += 1
        root = TreeNode(root_val)
        mid = idx[root_val]                      # 根在中序里的位置
        root.left = build(in_left, mid - 1)      # 必须先建左（前序左在右之前）
        root.right = build(mid + 1, in_right)
        return root

    return build(0, len(inorder) - 1)
```

## 记忆锚点

- **前序取根、中序切左右**是核心口诀，两种写法都围绕它。
- 切片版最好写：左子树 = `preorder[1:mid+1]` + `inorder[:mid]`，右子树 = 各自剩余。
- 下标版要点：`pre_idx` 先定义再用 `nonlocal`，且**先建左子树再建右子树**（前序里左在右之前）。

## 复杂度

- 切片版：时间 O(n²)（切片 + index），空间 O(n²)
- 下标版：时间 O(n)，空间 O(n)（哈希表 + 递归栈）

## 一句话总结

> 前序第一个是根、在中序里切出左右区间递归——面试先写切片版（照口诀默写），要 O(n) 再换哈希表 + 前序指针。
