# 合并两个有序数组（LeetCode 88）

> 一句话：**从后往前**填，谁大填谁——因为 nums1 尾部是空的，倒着放不会覆盖还没处理的数。

## 题目

`nums1` 长度 m+n（后 n 位是 0 占位），`nums2` 长度 n，把两个有序数组合并到 nums1 里（原地）。

## 为什么从后往前

从前往后填会覆盖 nums1 里还没比较的元素；从后往前填到尾部空位，绝不会踩到未处理的数。**这是本题唯一的记忆点。**

```python
def merge(nums1, m, nums2, n):
    i, j, k = m - 1, n - 1, m + n - 1   # 两个数组的有效尾 + 总尾
    while j >= 0:                        # nums2 还没放完
        if i >= 0 and nums1[i] > nums2[j]:
            nums1[k] = nums1[i]
            i -= 1
        else:
            nums1[k] = nums2[j]
            j -= 1
        k -= 1
```

> 循环条件用 `while j >= 0`：nums2 放完就结束（nums1 剩下的本来就在原位，不用动）。

## 复杂度

- 时间 O(m+n)，空间 O(1)（原地）

## 一句话总结

> 三指针从后往前，谁大填谁，nums2 放完即止——倒着填是为了不覆盖 nums1 未处理的元素。
