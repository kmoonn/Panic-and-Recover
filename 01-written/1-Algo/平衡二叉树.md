# 平衡二叉树（LeetCode 110）

> 一句话：**自底向上**求高度，顺便判断——用 -1 当"已经不平衡"的信号，一路往上短路。

## 题目

判断二叉树是否平衡：每个节点的左右子树高度差 ≤ 1。

## 自底向上（最优，只遍历一次）

递归返回高度；一旦发现某棵子树不平衡，返回 **-1** 作为"失败标记"，让上层直接短路。

```python
def isBalanced(root):
    def height(node):
        if not node:
            return 0
        lh = height(node.left)
        if lh == -1:                  # 左子树已不平衡，短路
            return -1
        rh = height(node.right)
        if rh == -1:                  # 右子树已不平衡，短路
            return -1
        if abs(lh - rh) > 1:          # 当前节点不平衡
            return -1
        return max(lh, rh) + 1        # 平衡则返回真实高度

    return height(root) != -1
```

## 为什么用 -1 短路

- 朴素做法：对每个节点单独算高度判断，会重复算高度 → O(n²)。
- 用 -1 标记：**一次后序遍历**边算高度边判断，发现不平衡立刻往上传 -1 → O(n)。

## 复杂度

- 时间 O(n)，空间 O(h) 递归栈（h 为树高）

## 一句话总结

> 后序求高度，`abs(左-右)>1` 就返回 -1 短路上传，最终看根是否为 -1——一次遍历 O(n)。
