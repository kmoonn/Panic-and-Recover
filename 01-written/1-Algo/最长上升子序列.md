# 最长上升子序列（LeetCode 300）

> 一句话：**DP 法 `dp[i]` 表示以 i 结尾的最长长度；进阶用"贪心 + 二分"维护一个最小结尾数组**。

## 题目

求最长严格递增子序列的长度。如 `[10,9,2,5,3,7,101,18]` → `4`（`[2,3,7,101]`）。

## 解法一：动态规划 O(n²)（好理解）

`dp[i]` = 以 `nums[i]` 结尾的最长上升子序列长度。对每个 `i`，看它前面所有比它小的 `j`，从中挑最长的接上。

```python
def lengthOfLIS(nums):
    n = len(nums)
    dp = [1] * n                 # 每个数自身长度至少为 1
    for i in range(n):
        for j in range(i):
            if nums[j] < nums[i]:            # 能接在 j 后面
                dp[i] = max(dp[i], dp[j] + 1)
    return max(dp)
```

## 解法二：贪心 + 二分 O(n log n)（进阶）

维护数组 `tails`，`tails[k]` = 长度为 `k+1` 的上升子序列的**最小结尾值**。遍历每个数，用二分找到第一个 `>=` 它的位置替换；若比所有都大就追加。`tails` 长度即答案（注意它不是真正的子序列，但长度对）。

```python
import bisect

def lengthOfLIS(nums):
    tails = []
    for x in nums:
        i = bisect.bisect_left(tails, x)   # 第一个 >= x 的位置
        if i == len(tails):
            tails.append(x)                # x 最大，接到末尾
        else:
            tails[i] = x                   # 替换，保持结尾尽量小
    return len(tails)
```

## 记忆锚点

- DP：`dp[i] = max(dp[j]+1)`，条件 `nums[j] < nums[i]`，答案是 `max(dp)` 不是 `dp[-1]`。
- 二分：`tails` 结尾越小越有利于后面接更多，用 `bisect_left` 找替换位（严格递增用 left）。

## 复杂度

- DP：时间 O(n²)，空间 O(n)
- 贪心+二分：时间 O(n log n)，空间 O(n)

## 一句话总结

> 好写用 O(n²) DP（以 i 结尾的最长长度）；要快用 tails 数组 + 二分替换，长度即答案。
