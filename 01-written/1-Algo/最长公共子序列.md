# 最长公共子序列（LeetCode 1143）

> 一句话：二维 DP，**字符相等就 +1（取左上角），不等就取上或左的最大值**。子序列不要求连续。

## 题目

求两个字符串 `text1`、`text2` 的最长公共子序列长度。（子序列 = 保持相对顺序、可不连续地删字符得到）

## DP 定义（最关键）

`dp[i][j]` = `text1` 前 i 个字符与 `text2` 前 j 个字符的 LCS 长度。

**状态转移：**

```
若 text1[i-1] == text2[j-1]:  dp[i][j] = dp[i-1][j-1] + 1   # 都要这个字符
否则:                          dp[i][j] = max(dp[i-1][j], dp[i][j-1])  # 各退一个取最优
```

```python
def longestCommonSubsequence(text1, text2):
    m, n = len(text1), len(text2)
    dp = [[0] * (n + 1) for _ in range(m + 1)]   # 多一行一列存空串边界
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if text1[i - 1] == text2[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
    return dp[m][n]
```

## 记忆技巧

- 下标：`dp[i][j]` 用的是 `text1[i-1]`（dp 多开一行一列表示"空串"，下标错开 1）。
- 相等 → 看**左上角** `dp[i-1][j-1]`（对角线）再 +1；
- 不等 → 看**上、左**取大（`dp[i-1][j]` / `dp[i][j-1]`）。

> 对比：**最长公共子串**（要求连续）不等时是 0，不是取 max；别混。

## 复杂度

- 时间 O(m×n)，空间 O(m×n)（可滚动数组优化到 O(n)）

## 一句话总结

> 二维 dp：相等取左上角 +1，不等取上/左的最大值；子序列可不连续，子串要连续（不等归零）。
