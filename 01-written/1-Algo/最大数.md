# 最大数（LeetCode 179）

> 一句话：**自定义排序——两个数拼起来谁在前大就谁排前面（比较 `a+b` 与 `b+a`）**。

## 题目

给一组非负整数，重新排列拼成最大的整数（返回字符串）。如 `[3,30,34,5,9]` → `"9534330"`。

## 自定义排序

不能只按数值大小排（`3` 和 `30`：`3` 该在前，因为 `330 > 303`）。规则是：比较两个数字符串拼接后的结果 `a+b` 和 `b+a`，谁拼出来更大谁排前面。

```python
from functools import cmp_to_key

def largestNumber(nums):
    strs = list(map(str, nums))
    # a 排在 b 前面的条件：a+b > b+a
    def cmp(a, b):
        if a + b > b + a:
            return -1        # a 在前
        elif a + b < b + a:
            return 1         # b 在前
        else:
            return 0
    strs.sort(key=cmp_to_key(cmp))
    res = "".join(strs)
    return "0" if res[0] == "0" else res   # 全是 0 的特判
```

## 记忆锚点

- 比较核心：`a + b` 与 `b + a` 的**字符串拼接**大小，而非数值。
- **全 0 特判**：如 `[0,0]` 拼出 `"00"`，要返回 `"0"`。
- Python3 用 `functools.cmp_to_key` 把比较函数转成排序 key。

## 复杂度

- 时间 O(n log n · L)（L 为数字位数），空间 O(n)

## 一句话总结

> 按 `a+b` 与 `b+a` 拼接结果排序，大的在前，再拼起来并特判全 0——自定义比较的经典题。
