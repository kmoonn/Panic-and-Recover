# 反转链表（LeetCode 206）

> 一句话：**三个指针 prev/cur/next，逐个把箭头掉头**。

## 题目

反转单链表并返回新头。如 `1→2→3→4→5` → `5→4→3→2→1`。

## 迭代（推荐面试写）

`prev` 初始为 `None`，`cur` 从头开始。每一步：先存好 `cur.next`，再把 `cur.next` 指向 `prev`（掉头），然后 `prev` 和 `cur` 一起前进。

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

def reverseList(head):
    prev = None
    cur = head
    while cur:
        nxt = cur.next   # 1. 暂存下一个
        cur.next = prev  # 2. 掉头
        prev = cur       # 3. prev 前进
        cur = nxt        # 4. cur 前进
    return prev          # prev 就是新头
```

## 递归（可选）

```python
def reverseList(head):
    if not head or not head.next:
        return head
    new_head = reverseList(head.next)
    head.next.next = head   # 让后一个指回自己
    head.next = None
    return new_head
```

## 记忆锚点

- 迭代四步口诀：**暂存 next → 掉头 → prev 走 → cur 走**，返回 `prev`。
- 一定先 `nxt = cur.next` 再改指针，否则链表就断了找不回来。

## 复杂度

- 时间 O(n)，空间 O(1)（迭代）/ O(n)（递归栈）

## 一句话总结

> prev/cur 双指针，逐个把 next 指向前驱，最后 prev 是新头——链表反转必背模板。
