# 括号匹配问题

> 笔试高频题型，核心就一句话：**用栈**。

---

## 一、有效括号判断

**题目**：给定只含 `()[]{}` 的字符串，判断是否有效。

**思路**：左括号入栈，右括号看栈顶是否匹配。

```python
def isValid(s: str) -> bool:
    pair = {')': '(', ']': '[', '}': '{'}
    stack = []
    for c in s:
        if c in pair.values():       # 左括号
            stack.append(c)
        elif c in pair:              # 右括号
            if not stack or stack[-1] != pair[c]:
                return False
            stack.pop()
    return not stack                 # 栈空才有效
```

| 情况 | 判断 |
|------|------|
| `([{}])` | ✅ 栈最终为空 |
| `([)]` | ❌ 右括号和栈顶不匹配 |
| `([` | ❌ 栈非空（左括号多余） |
| `)]` | ❌ 栈空时遇到右括号 |

**复杂度**：O(n) 时间，O(n) 空间

## 二、最长有效括号

**题目**：给定只含 `(` 和 `)` 的字符串，求最长有效括号子串长度。

**思路**：栈存**下标**（不是字符），栈底永远是一个"无效分界点"。

```python
def longestValidParentheses(s: str) -> int:
    stack = [-1]           # 初始分界点
    ans = 0
    for i, c in enumerate(s):
        if c == '(':
            stack.append(i)
        else:              # c == ')'
            stack.pop()    # 弹出匹配的左括号或分界点
            if not stack:
                stack.append(i)   # 栈空 → 当前位置是新分界点
            else:
                ans = max(ans, i - stack[-1])  # 当前有效长度
    return ans
```

| 步骤 | `s = ")()())"` | 栈 | ans |
|------|---------------|-----|-----|
| i=0 `)` | 栈[-1]弹出，栈空→压0作分界 | [0] | 0 |
| i=1 `(` | 压入 | [0,1] | 0 |
| i=2 `)` | 弹出1，栈顶0 | [0] | 2 |
| i=3 `(` | 压入 | [0,3] | 2 |
| i=4 `)` | 弹出3，栈顶0 | [0] | 4 |
| i=5 `)` | 弹出0，栈空→压5 | [5] | 4 |

**复杂度**：O(n) 时间，O(n) 空间

## 三、括号生成

**题目**：给定 n，生成所有合法的 n 对括号组合。

**思路**：回溯，左括号数量 < n 可以放左，右括号数量 < 左括号数量可以放右。

```python
def generateParenthesis(n: int) -> list:
    res = []

    def backtrack(cur, left, right):
        if len(cur) == 2 * n:
            res.append(cur)
            return
        if left < n:                        # 还能放左括号
            backtrack(cur + '(', left + 1, right)
        if right < left:                    # 右括号不能比左多
            backtrack(cur + ')', left, right + 1)

    backtrack('', 0, 0)
    return res

# n=3 → ["((()))","(()())","(())()","()(())","()()()"]
```

**剪枝关键**：`right < left` 保证任意前缀右括号不超过左括号。

**复杂度**：时间 O(C_n)（卡特兰数），空间 O(n) 递归深度

## 四、删除无效括号

**题目**：给定含括号的字符串，删除最少数量的括号使结果有效，返回所有可能结果。

**思路**：BFS 逐层删除，第一次出现有效串时就是最少删除。

```python
def removeInvalidParentheses(s: str) -> list:
    def isValid(t):
        cnt = 0
        for c in t:
            if c == '(': cnt += 1
            elif c == ')': cnt -= 1
            if cnt < 0: return False
        return cnt == 0

    # BFS：逐层删一个字符
    queue = {s}
    while queue:
        valid = [t for t in queue if isValid(t)]
        if valid:
            return valid              # 第一次出现有效串就是答案
        next_level = set()
        for t in queue:
            for i in range(len(t)):
                if t[i] in '()':     # 只删括号
                    next_level.add(t[:i] + t[i+1:])
        queue = next_level
```

**复杂度**：最坏 O(2^n)，但 BFS 保证找到最短删除

## 五、笔试变体速查

| 变体 | 题目特征 | 解法 |
|------|---------|------|
| **最少添加** | 添加几个括号使字符串有效 | 统计不匹配的左/右括号数 |
| **得分计算** | `()` 得 1 分，`AB` 得 `A+B`，`(A)` 得 `2*A` | 栈存分数，遇 `()` 弹栈加倍 |
| **带其他字符** | 字符串含字母+括号，只看括号 | 跳过非括号字符，其余同有效判断 |
| **多种括号** | `()[]{}` 混合 | 栈存左括号，右括号看栈顶匹配 |
| **最长有效** | 只含 `()` | 栈存下标，栈底是分界点 |

### 最少添加括号

```python
def minAdd(s: str) -> int:
    left_need = 0   # 需要的左括号数
    right_need = 0  # 需要的右括号数
    for c in s:
        if c == '(':
            right_need += 1     # 期待一个右括号
        elif c == ')':
            right_need -= 1     # 消耗一个右括号
            if right_need < 0:  # 右括号多了，需要补左括号
                left_need += 1
                right_need = 0
    return left_need + right_need
```

## 六、字符串解码

**题目**：`3[a2[c]]` → `accaccacc`，数字表示重复次数，括号内为重复内容。

**思路**：两个栈——数字栈存倍数，字符串栈存外层前缀。

```python
def decodeString(s: str) -> str:
    num_stack = []
    str_stack = []
    cur_num = 0
    cur_str = ''

    for c in s:
        if c.isdigit():
            cur_num = cur_num * 10 + int(c)   # 处理多位数
        elif c == '[':
            num_stack.append(cur_num)           # 保存当前倍数
            str_stack.append(cur_str)           # 保存外层前缀
            cur_num = 0
            cur_str = ''                        # 开始收集括号内内容
        elif c == ']':
            repeat = num_stack.pop()            # 取出倍数
            prev = str_stack.pop()              # 取出外层前缀
            cur_str = prev + cur_str * repeat   # 拼接
        else:
            cur_str += c                        # 普通字符直接拼接

    return cur_str

# "3[a2[c]]"  →  "a" + "c"*2 = "acc"  →  "acc"*3 = "accaccacc"
# "2[abc]3[cd]ef"  →  "abcabc" + "cdcdcd" + "ef" = "abcabccdcdcdef"
```

## 七、括号得分

**题目**：`()` 得 1 分，`AB` 得 `A+B`，`(A)` 得 `2×A`，求总分。

**思路**：栈存分数，遇到 `()` 得 1，遇到外层括号则内部翻倍。

```python
def scoreOfParentheses(s: str) -> int:
    stack = [0]           # 栈底存当前层的分数

    for c in s:
        if c == '(':
            stack.append(0)          # 新的一层，分数初始 0
        else:                        # c == ')'
            top = stack.pop()
            if top == 0:             # 紧挨着的前一个是 '(' → 基础分 1
                stack[-1] += 1
            else:                    # 内层有分数 → 翻倍
                stack[-1] += top * 2

    return stack[0]

# "()"       → 1
# "(())"     → 2   (1×2)
# "()()"     → 2   (1+1)
# "(()(()))" → 6   (1 + 1×2)×2 = 6
```

## 八、反转括号间子串

**题目**：`(abcd)` → `dcba`，括号可以嵌套，去掉括号输出结果。如 `(u(love)i)` → `iloveu`。

**思路**：遇到 `)` 时把栈中到最近 `(` 之间的字符反转再压回。

```python
def reverseParentheses(s: str) -> str:
    stack = []
    for c in s:
        if c == ')':
            # 弹出到 '(' 之间的所有字符
            tmp = []
            while stack[-1] != '(':
                tmp.append(stack.pop())
            stack.pop()              # 弹出 '('
            stack.extend(tmp)        # 反转后的字符压回（tmp 本身就是反序）
        else:
            stack.append(c)
    return ''.join(stack)

# "(abcd)"       → "dcba"
# "(u(love)i)"   → "i" + "evol" + "u" → "iloveu"
```

## 九、带星号的有效括号

**题目**：字符串含 `(`、`)` 和 `*`，`*` 可以当 `(` 或 `)` 或空，判断能否变有效。

**思路**：贪心，维护左括号的**可能数量范围** `[lo, hi]`。

```python
def checkValidString(s: str) -> bool:
    lo = 0   # 左括号最少可能数量
    hi = 0   # 左括号最多可能数量

    for c in s:
        if c == '(':
            lo += 1; hi += 1
        elif c == ')':
            lo -= 1; hi -= 1
        else:              # c == '*'，可当 ( 或 ) 或空
            lo -= 1        # 当 ) 时左括号少一个
            hi += 1        # 当 ( 时左括号多一个

        if hi < 0:         # 右括号太多，怎么分配 * 都救不回来
            return False
        lo = max(lo, 0)    # lo 不能为负（* 当空即可）

    return lo == 0         # 最终左括号最少可能为 0

# "(*)"  → True  (* 当空)
# "(*))" → True  (* 当 ()
# "(()"  → False (缺右括号)
```

## 一句话总结

> 括号题的核心是栈：左括号入栈、右括号匹配栈顶；求长度时栈存下标、栈底做分界点；生成/删除用回溯/BFS；解码用双栈；带星号用贪心范围——口诀：**左入右出看栈顶，下标分界求长度，双栈解码贪心范围**。
