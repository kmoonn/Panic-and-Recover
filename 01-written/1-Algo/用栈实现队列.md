# 用栈实现队列（LeetCode 232）

> 一句话：**两个栈，一个进（in）一个出（out），out 空了才把 in 全倒过来**。

## 题目

用两个栈实现队列的 `push / pop / peek / empty`（先进先出）。

## 双栈：入栈 + 出栈

- `push`：直接压入 `in` 栈；
- `pop / peek`：如果 `out` 栈空了，就把 `in` 栈的元素**全部倒进** `out`（顺序刚好反转，变成先进先出），然后从 `out` 弹出。

```python
class MyQueue:
    def __init__(self):
        self.in_stack = []
        self.out_stack = []

    def push(self, x):
        self.in_stack.append(x)

    def _transfer(self):
        if not self.out_stack:                 # out 空了才倒
            while self.in_stack:
                self.out_stack.append(self.in_stack.pop())

    def pop(self):
        self._transfer()
        return self.out_stack.pop()

    def peek(self):
        self._transfer()
        return self.out_stack[-1]

    def empty(self):
        return not self.in_stack and not self.out_stack
```

## 记忆锚点

- **out 空了才倒**是关键：不能每次都倒，否则顺序乱。倒一次后 out 里已是队列顺序。
- 两个栈各司其职：`in` 只管进，`out` 只管出。

## 复杂度

- 均摊 O(1)（每个元素最多被搬运一次），空间 O(n)

## 一句话总结

> 入栈 in、出栈 out，取数时若 out 空就把 in 整个倒过来——两栈方向相反正好实现 FIFO。
