# 比较版本号（LeetCode 165）

> 一句话：**按 `.` 切分，逐段转成整数比较**——`1.01` 和 `1.001` 都等于 1，前导零不影响。

## 题目

比较两个版本号 `version1`、`version2`（形如 `1.01`、`1.0.0`）。前者大返回 1，小返回 -1，相等返回 0。

## 切分补零法（最好写）

关键点：`01` 要按整数比（=1，前导零无意义）；长度不等时，**短的缺失段按 0 处理**（`1.0` == `1`）。

```python
def compareVersion(version1, version2):
    v1 = version1.split('.')
    v2 = version2.split('.')
    for i in range(max(len(v1), len(v2))):
        x = int(v1[i]) if i < len(v1) else 0   # 缺失段补 0
        y = int(v2[i]) if i < len(v2) else 0
        if x != y:
            return 1 if x > y else -1
    return 0
```

## 两个坑（背下来）

- **前导零**：`int('01') == 1`，用 `int()` 转换自动去掉，别按字符串比。
- **长度不等补零**：`1.0.0` vs `1` → 后面缺的段当 0，所以相等。

## 复杂度

- 时间 O(n+m)，空间 O(n+m)（split 产生的列表）

## 一句话总结

> 按 `.` split，逐段 int 化比较，短的缺段补 0——前导零和长度差都靠 int() + 补 0 化解。
