# 无重复字符的最长子串（LeetCode 3）

> 一句话：**滑动窗口 + 哈希表记录每个字符上次出现的位置，右指针遍历，左指针跳过重复**。

## 题目

找出字符串中不含重复字符的最长子串长度。如 `"abcabcbb"` → `3`（`"abc"`）。

## 滑动窗口

右指针 `right` 逐个吃字符；用字典 `last` 记录每个字符**最后一次出现的下标**。当遇到重复字符且它在窗口内时，把左边界 `left` 跳到"重复字符上次位置 + 1"。

```python
def lengthOfLongestSubstring(s):
    last = {}          # 字符 -> 上次出现的下标
    left = 0           # 窗口左边界
    ans = 0
    for right, ch in enumerate(s):
        # 若 ch 出现过且在当前窗口内，收缩左边界
        if ch in last and last[ch] >= left:
            left = last[ch] + 1
        last[ch] = right
        ans = max(ans, right - left + 1)
    return ans
```

## 记忆锚点

- 关键是 `last[ch] >= left`：只有重复字符**在窗口内**才收缩，否则旧记录不影响当前窗口。
- 窗口长度 = `right - left + 1`，每步更新最大值。

## 复杂度

- 时间 O(n)（每个字符最多进出一次），空间 O(字符集大小)

## 一句话总结

> 右指针扩窗、遇窗口内重复就把左指针跳到重复位置右侧，全程记最大窗口长——滑动窗口入门模板。
