# 买卖股票的最佳时机 III（LeetCode 123）

> 一句话：**最多两笔交易，维护 4 个状态：买1、卖1、买2、卖2，一次遍历顺序更新**。

## 题目

给每天股价，最多完成 **两笔** 交易（买了必须先卖再买），求最大利润。如 `[3,3,5,0,0,3,1,4]` → `6`。

## 四状态 DP

把过程拆成 4 个状态，记录到当前为止各状态的最大收益：

- `buy1`：第一次买入后手里的钱（花掉 price，故为负或较小）；
- `sell1`：第一次卖出后的利润；
- `buy2`：第二次买入后（在 sell1 基础上再花 price）；
- `sell2`：第二次卖出后的最终利润。

每天按 `buy1 → sell1 → buy2 → sell2` 顺序更新即可。

```python
def maxProfit(prices):
    buy1 = float('-inf')   # 第一次买入后的收益
    sell1 = 0              # 第一次卖出后的收益
    buy2 = float('-inf')   # 第二次买入后的收益
    sell2 = 0              # 第二次卖出后的收益
    for p in prices:
        buy1 = max(buy1, -p)          # 要么保持，要么今天买入
        sell1 = max(sell1, buy1 + p)  # 要么保持，要么今天卖出第一笔
        buy2 = max(buy2, sell1 - p)   # 用第一笔利润再买
        sell2 = max(sell2, buy2 + p)  # 卖出第二笔
    return sell2
```

## 记忆锚点

- 四状态**顺序更新**：`buy1, sell1, buy2, sell2`，同一轮里后者可用到前者刚更新的值（允许当天买卖衔接，不影响正确性）。
- 买入是"减 price"，卖出是"加 price"；`buy` 初始负无穷，`sell` 初始 0。
- 推广到"最多 k 笔"就用 `dp[k][2]` 循环，本题是 k=2 的展开写法。

## 复杂度

- 时间 O(n)，空间 O(1)

## 一句话总结

> 拆成买1/卖1/买2/卖2 四状态，每天顺序取 max 更新，最终 sell2 即答案——限次交易 DP 的展开模板。
