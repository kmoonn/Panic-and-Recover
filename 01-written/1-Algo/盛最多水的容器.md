# 盛最多水的容器（LeetCode 11）

> 一句话：**左右双指针向中间收缩，每次移动较矮的那根柱子**。

## 题目

数组每个数是一根竖线高度，选两根线与 x 轴围成容器，求最大盛水量。如 `[1,8,6,2,5,4,8,3,7]` → `49`。

## 左右双指针

容量 = `min(左高, 右高) × 宽度`。一开始取最宽（左右两端），之后想变大只能靠增高——所以**移动较矮的一根**，才有机会遇到更高的线（移动较高的那根，短板不变、宽度还变小，一定不划算）。

```python
def maxArea(height):
    left, right = 0, len(height) - 1
    ans = 0
    while left < right:
        area = min(height[left], height[right]) * (right - left)
        ans = max(ans, area)
        if height[left] < height[right]:  # 移动较矮的一边
            left += 1
        else:
            right -= 1
    return ans
```

## 记忆锚点

- **移矮不移高**是核心：短板决定水面高度，只有换掉短板才可能变大。
- 面积由 `min(两边高) × 宽` 决定，宽度只会越缩越小。

## 复杂度

- 时间 O(n)，空间 O(1)

## 一句话总结

> 左右双指针夹逼，每次丢掉较矮的柱子——因为短板决定容量，只有换短板才有希望更大。
