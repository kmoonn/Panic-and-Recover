# 二叉树中的最大路径和（LeetCode 124）

> 一句话：**后序递归，每个结点算"经过它并向下延伸一条边的最大贡献"，同时用左+根+右更新全局答案**。

## 题目

路径指任意结点出发沿父子连接到达任意结点的序列（不必过根）。求所有路径中的最大路径和。如 `[-10,9,20,null,null,15,7]` → `42`（`15→20→7`）。

## 后序递归

对每个结点，递归求左右子树的**最大向下贡献**（负贡献就当 0，不要）。

- **更新答案**：以当前结点为"拐点"的路径 = `左贡献 + 根值 + 右贡献`，用它刷新全局最大。
- **返回给父亲**：只能选左或右**一条边**继续向上，即 `根值 + max(左贡献, 右贡献)`。

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

def maxPathSum(root):
    ans = float('-inf')

    def gain(node):
        nonlocal ans
        if not node:
            return 0
        left = max(gain(node.left), 0)    # 负贡献不要
        right = max(gain(node.right), 0)
        ans = max(ans, node.val + left + right)  # 拐点路径刷新答案
        return node.val + max(left, right)       # 只能带一条边上交
    gain(root)
    return ans
```

## 记忆锚点

- 分清两件事：**更新答案用"左+根+右"**（拐点），**返回父亲只带一条边**（`根+max(左,右)`）。
- 子树贡献为负就取 0 丢弃；`ans` 初始化为负无穷（结点值可能全负）。

## 复杂度

- 时间 O(n)，空间 O(树高)（递归栈）

## 一句话总结

> 后序求每个结点向下的最大贡献（负则舍），答案用左+根+右刷新、返回父亲只带一条边——树形 DP 经典。
