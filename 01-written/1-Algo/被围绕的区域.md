# 被围绕的区域（LeetCode 130）

> 一句话：**不要判断哪些 `O` 被包围，而要先从四条边界出发标记所有不能被包围的 `O`，最后翻转剩余 `O`**。

## 题目

把完全被 `X` 包围的 `O` 改成 `X`；位于边界或与边界 `O` 连通的区域不能修改。

## 逆向 DFS

直接判断内部区域是否连接边界较麻烦，可以反过来寻找“安全区域”：

1. 遍历首行、末行、首列、末列。
2. 从每个边界 `O` 启动 DFS，将与它连通的 `O` 临时标记为 `#`。
3. 再遍历整个矩阵：
   - 剩余 `O` 无法连接边界，改为 `X`；
   - 临时标记 `#` 属于安全区域，恢复为 `O`。

```text
边界 O --DFS--> 标记为 #
全局扫描:
    O -> X
    # -> O
```

## 为什么从边界开始

不能被翻转的区域都有同一个充分必要条件：**与边界上的 `O` 连通**。从边界反向搜索，一次就能找出所有例外，避免对每个内部连通块重复判断。

## 易错点

- 四条边界的角落会重复访问，但访问标记可自然去重。
- 必须先标记所有安全区域，再统一翻转，不能边搜索边翻转。
- 临时字符不能与原矩阵中的 `X`、`O` 冲突。

## 复杂度

- 时间 O(mn)。
- 空间 O(mn)，最坏情况下为递归栈。

## 一句话总结

> 被围绕区域的关键是逆向思维：从边界找安全 `O`，剩下的 `O` 才是真正被包围的区域。
