# 二叉树的层序遍历（LeetCode 102）

> 一句话：**用队列做 BFS，每轮先记住当前层结点个数，一次性处理完一层**。

## 题目

按层从左到右返回二叉树每层的结点值。如 `[3,9,20,null,null,15,7]` → `[[3],[9,20],[15,7]]`。

## BFS + 按层切分

用队列 `deque`。关键技巧：进入循环时先记下**当前队列长度 `size`**，它就是这一层的结点数，循环 `size` 次刚好把这一层处理完并把下一层子结点入队。

```python
from collections import deque

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

def levelOrder(root):
    if not root:
        return []
    res = []
    q = deque([root])
    while q:
        size = len(q)            # 当前层结点数
        level = []
        for _ in range(size):    # 只处理这一层
            node = q.popleft()
            level.append(node.val)
            if node.left:
                q.append(node.left)
            if node.right:
                q.append(node.right)
        res.append(level)
    return res
```

## 记忆锚点

- 核心是**循环开始先取 `size = len(q)`**，用它切分层，不然新入队的下层会混进来。
- 空树要先特判返回 `[]`。

## 复杂度

- 时间 O(n)，空间 O(n)（队列最多存一层）

## 一句话总结

> 队列 BFS，每轮固定处理 `len(q)` 个结点即一层，子结点入队留给下一轮——层序遍历标准写法。
