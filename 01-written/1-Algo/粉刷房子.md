# 粉刷房子（LeetCode 256）

> 一句话：**DP：粉刷到第 i 家某颜色的最小花费 = 自身花费 + 前一家「另外两种颜色」里的较小值**。

## 题目

一排房子，每家可刷红/蓝/绿三色，相邻不能同色。`costs[i]` 是第 i 家刷三色的花费，求刷完所有房子的最小总花费。

## 动态规划

`dp[i][c]` = 把第 i 家刷成颜色 c 时，前 i 家的最小总花费。因为相邻不同色，第 i 家刷 c 时，第 i-1 家只能刷**另外两种颜色**，取其较小者。

```python
def minCost(costs):
    if not costs:
        return 0
    # dp 初始为第 0 家的三色花费
    r, b, g = costs[0]
    for i in range(1, len(costs)):
        cr, cb, cg = costs[i]
        # 刷当前色 = 当前花费 + 上一家另两色的较小值
        r, b, g = (cr + min(b, g),
                   cb + min(r, g),
                   cg + min(r, b))
    return min(r, b, g)
```

## 记忆锚点

- 递推核心：`当前色花费 + min(上一家另外两色)`，三色对称写三行。
- 用三个滚动变量 `r/b/g` 代替二维数组，空间降到 O(1)。
- 最后答案是**三色的最小值**，不是某个固定颜色。

## 复杂度

- 时间 O(n)，空间 O(1)

## 一句话总结

> 刷到某色的最小花费 = 自身花费 + 上一家另两色的较小值，滚动三个变量、最后取最小——相邻约束 DP 模板。
