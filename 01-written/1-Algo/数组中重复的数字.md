# 数组中重复的数字（剑指 Offer 03）

> 一句话：**数值范围是 0~n-1，用「原地交换，把数字 x 放到下标 x」，发现目标位置已是 x 就找到重复**。

## 题目

长度为 n 的数组，所有数字都在 `0 ~ n-1` 范围内，找出任意一个重复的数字。如 `[2,3,1,0,2,5,3]` → `2` 或 `3`。

## 解法一：原地交换（O(1) 空间）

因为数值范围恰好是下标范围，正常情况下"下标 i 应放数字 i"。遍历时若 `nums[i] != i`，就尝试把它换回它该在的位置 `nums[i]`；如果那个位置**已经是这个数**，说明重复。

```python
def findRepeatNumber(nums):
    i = 0
    while i < len(nums):
        if nums[i] == i:              # 已归位，看下一个
            i += 1
            continue
        target = nums[i]              # 这个数该去的位置
        if nums[target] == target:    # 那个位置已经是它 -> 重复
            return target
        nums[i], nums[target] = nums[target], nums[i]  # 交换归位
    return -1
```

## 解法二：哈希集合（O(n) 空间，更好写）

```python
def findRepeatNumber(nums):
    seen = set()
    for x in nums:
        if x in seen:
            return x
        seen.add(x)
    return -1
```

## 记忆锚点

- 原地法的前提：**值域 = 下标域（0~n-1）**，才能"数字 x 归位到下标 x"。
- `nums[i]==i` 跳过，否则交换；换之前先看目标位是否已是该值 → 重复。
- 时间紧或没说空间限制，直接写哈希集合版更保险。

## 复杂度

- 原地交换：时间 O(n)，空间 O(1)
- 哈希集合：时间 O(n)，空间 O(n)

## 一句话总结

> 值域等于下标域，就原地把数字 x 换到下标 x，目标位已是 x 即重复；没空间要求就用 set。
