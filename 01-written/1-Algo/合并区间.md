# 合并区间（LeetCode 56）

> 一句话：**按左端点排序，能重叠就合并（更新右端点取 max），不重叠就新开一段**。

## 题目

给若干区间，合并所有重叠的区间。如 `[[1,3],[2,6],[8,10]]` → `[[1,6],[8,10]]`。

## 排序 + 一次扫描

排序后，只需比较"当前区间左端点"和"结果里最后一段的右端点"：

- **能接上**（`当前左 <= 上段右`）→ 合并，右端点取 `max`；
- **接不上** → 当前区间作为新的一段。

```python
def merge(intervals):
    intervals.sort(key=lambda x: x[0])   # 按左端点排序
    res = [intervals[0]]
    for l, r in intervals[1:]:
        if l <= res[-1][1]:              # 与上一段重叠
            res[-1][1] = max(res[-1][1], r)   # 合并，右端取 max
        else:
            res.append([l, r])           # 不重叠，新开一段
    return res
```

## 记忆锚点

- **必须按左端点排序**——排序后重叠区间一定相邻，才能一次扫描。
- 右端点更新要 `max`：可能出现 `[1,6]` 后接 `[2,3]`（被包含），不能直接用后者覆盖。

## 复杂度

- 时间 O(n log n)（排序主导），空间 O(n)（结果）

## 一句话总结

> 按左端点排序，`当前左 <= 上段右` 就合并、右端取 max，否则新开一段——区间题的地基模板。
