# 最小高度树（LeetCode 310）

> 一句话：**从外向内一层层剥叶子，最后剩下的 1~2 个结点就是最小高度树的根**。

## 题目

n 个结点的树（无向），以哪个结点为根时树高最小，返回所有这样的根。答案至多 2 个。如 `n=6, edges=[[3,0],[3,1],[3,2],[3,4],[5,4]]` → `[3,4]`。

## 拓扑式剥叶子

最小高度树的根一定在树的"中心"。做法类似拓扑排序：每轮把所有**度为 1 的叶子**同时删掉，一层层向内收缩，直到剩 ≤ 2 个结点——它们就是中心（答案）。

```python
from collections import deque

def findMinHeightTrees(n, edges):
    if n == 1:
        return [0]                      # 单结点特判
    graph = [set() for _ in range(n)]
    degree = [0] * n
    for a, b in edges:
        graph[a].add(b)
        graph[b].add(a)
        degree[a] += 1
        degree[b] += 1

    leaves = deque(i for i in range(n) if degree[i] == 1)  # 初始叶子
    remaining = n
    while remaining > 2:                # 剥到剩 <= 2 个
        size = len(leaves)
        remaining -= size
        for _ in range(size):
            leaf = leaves.popleft()
            for nb in graph[leaf]:      # 删叶子，邻居度 -1
                degree[nb] -= 1
                graph[nb].discard(leaf)
                if degree[nb] == 1:
                    leaves.append(nb)   # 邻居变新叶子
    return list(leaves)                 # 剩下的即答案
```

## 记忆锚点

- 核心思想：**从外往里剥叶子**，中心（最后剩的 1~2 个）就是最优根，不要逐个结点算高度。
- 每轮**成层地**删叶子（先记 `size`），`remaining` 减到 ≤ 2 停止。
- 特判 `n == 1` 直接返回 `[0]`。

## 复杂度

- 时间 O(n)，空间 O(n)

## 一句话总结

> 像拓扑排序一样一层层剥掉叶子，剩下的 1~2 个中心结点就是最小高度树的根——避免对每个结点算高度。
