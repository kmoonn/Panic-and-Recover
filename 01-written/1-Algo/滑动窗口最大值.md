# 滑动窗口最大值（LeetCode 239）

> 一句话：**单调递减双端队列存下标，队头永远是窗口最大值**。

## 题目

数组上有大小为 `k` 的窗口从左滑到右，返回每个窗口的最大值。如 `nums=[1,3,-1,-3,5,3,6,7], k=3` → `[3,3,5,5,6,7]`。

## 单调队列

维护一个**存下标**的双端队列，保证对应的值**从大到小**：

- 新元素进来前，把队尾所有比它小的下标弹掉（它们不可能再当最大值）；
- 新下标入队尾；
- 队头若已滑出窗口（下标 `<= i - k`）则从队头弹出；
- 当窗口形成（`i >= k-1`），队头下标对应的值就是当前窗口最大值。

```python
from collections import deque

def maxSlidingWindow(nums, k):
    dq = deque()      # 存下标，对应值单调递减
    res = []
    for i, x in enumerate(nums):
        while dq and nums[dq[-1]] <= x:   # 队尾比新值小，弹掉
            dq.pop()
        dq.append(i)
        if dq[0] <= i - k:                # 队头滑出窗口
            dq.popleft()
        if i >= k - 1:                    # 窗口已成形
            res.append(nums[dq[0]])       # 队头即最大值
    return res
```

## 记忆锚点

- 队列**存下标**不存值，方便判断是否滑出窗口。
- 两个 while/if：**入队前清小队尾**（保持递减）、**取值前清过期队头**。
- 队头始终是当前窗口最大值，均摊每个元素进出一次。

## 复杂度

- 时间 O(n)，空间 O(k)

## 一句话总结

> 单调递减队列存下标：进队前弹掉更小的队尾、取值前弹掉过期队头，队头即窗口最大值——单调队列经典应用。
