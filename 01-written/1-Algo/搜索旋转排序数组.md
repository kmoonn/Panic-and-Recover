# 搜索旋转排序数组（LeetCode 33）

> 一句话：**二分时先判断哪半边是有序的，再看 target 落不落在有序那半，据此收缩**。

## 题目

升序数组被旋转过（如 `[4,5,6,7,0,1,2]`），无重复元素，找 `target` 的下标，没有返回 `-1`，要求 O(log n)。

## 二分：一半必有序

旋转后从中点切开，**至少有一半是有序的**。判断哪半有序，再看 `target` 是否落在这半有序区间内：在就往这半找，不在就去另一半。

```python
def search(nums, target):
    lo, hi = 0, len(nums) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if nums[mid] == target:
            return mid
        if nums[lo] <= nums[mid]:              # 左半 [lo, mid] 有序
            if nums[lo] <= target < nums[mid]: # target 在左半有序区
                hi = mid - 1
            else:
                lo = mid + 1
        else:                                  # 右半 [mid, hi] 有序
            if nums[mid] < target <= nums[hi]: # target 在右半有序区
                lo = mid + 1
            else:
                hi = mid - 1
    return -1
```

## 记忆锚点

- 判有序：`nums[lo] <= nums[mid]` 成立则**左半有序**，否则右半有序。
- 落区间判断要用**有序那半的闭区间边界**（带等号处理边界），落在里面就收缩到那半。
- 判断用 `<=` 处理 `lo == mid` 的单元素情况。

## 复杂度

- 时间 O(log n)，空间 O(1)

## 一句话总结

> 二分先看哪半有序，target 在有序半的区间内就去那半、否则去另一半——旋转数组二分的核心套路。
