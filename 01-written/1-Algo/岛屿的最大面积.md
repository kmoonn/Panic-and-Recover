# 岛屿的最大面积（LeetCode 695）

> 一句话：**遍历网格，每遇到一块未访问陆地就 DFS 计算当前连通块面积，并维护最大值**。

## 题目

二维网格中 `1` 表示陆地、`0` 表示水域，求所有岛屿中的最大面积；没有岛屿则返回 `0`。

## DFS 返回面积

当前格子越界或不是陆地时返回 `0`；否则先将它标记为已访问，再返回自身面积 `1` 加上四个方向的面积。

```text
dfs(i, j):
    if 越界或不是陆地: return 0
    将当前陆地标记为已访问
    return 1 + 上 + 下 + 左 + 右

遍历每个格子:
    if 是未访问陆地:
        maxArea = max(maxArea, dfs(i, j))
```

## 与岛屿数量的区别

| 题目 | 每次启动 DFS 后做什么 |
|---|---|
| 岛屿数量（LC200） | 连通块计数加一 |
| 岛屿的最大面积（LC695） | 接收 DFS 返回的面积并更新最大值 |

两题的遍历、边界判断和访问标记完全相同，只是搜索结果的统计方式不同。

## 易错点

- 必须在递归四个方向之前标记访问，避免重复计算。
- 若原地把 `1` 改为 `0`，会修改输入；题目不允许修改时应使用 `visited`。
- 最大值在每块岛屿搜索完成后更新，而不是每访问一个格子就更新。

## 复杂度

- 时间 O(mn)。
- 空间 O(mn)，最坏情况下为递归栈。

## 一句话总结

> LC200 数“有几块”，LC695 算“每块多大并取最大”，底层都是同一个网格连通块 DFS。
