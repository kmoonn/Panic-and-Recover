# Nginx 核心概念

Nginx 是高性能的反向代理与负载均衡服务器，事件驱动架构支撑高并发。

## 核心角色

**反向代理**、**负载均衡**、静态资源服务、SSL 卸载、限流。

## 负载均衡策略

轮询（默认）、加权轮询、**IP Hash**（同一 IP 固定后端，解决会话保持）、最少连接。

## 正向 vs 反向代理

正向代理**替客户端**发请求（翻墙/客户端隐身）；反向代理**替服务端**收请求（客户端不知真实后端）。

## ⭐ 加分/易错

Nginx 抗高并发靠**事件驱动 + 异步非阻塞（epoll）**，和 Redis 的 IO 多路复用是同一思想。

## 一句话总结

> Nginx 核心角色是反向代理和负载均衡，抗高并发靠事件驱动+异步非阻塞（epoll），与 Redis IO多路复用同一思想。
