# Panic-and-Recover 🚑➡️💪

"**From panic to recovery**"

记录开发中的崩溃瞬间与优雅解决方案

整理 Java 面试拷打过程中的常见问与答

总结看过或用过就忘的各种技术知识点

仓库名称灵感来源于 **Go** 语言经典梗，指**从崩溃中恢复**。

在 Go 语言中，**recover** 是一个内置函数，它用于从由 **panic** 引发的程序崩溃中恢复。
