# 最长回文子串

## Q: 如何求一个字符串中的最长回文子串？

回文串指的是：**正着读和反着读都一样**的字符串。

例如：
- `aba` 是回文串
- `abba` 是回文串
- `abc` 不是回文串

“最长回文子串”这题的关键点在于：
- 结果要求是**子串**，必须连续
- 要找的是**最长**
- 面试里最常见、最好讲的解法是**中心扩展法**

---

## 一、为什么中心扩展法最适合面试

每个回文串都有一个“中心”。

- 奇数长度回文：中心是一个字符
  - 例如 `aba` 的中心是 `b`
- 偶数长度回文：中心是两个字符之间
  - 例如 `abba` 的中心在两个 `b` 中间

所以可以枚举每个可能的中心，然后向两边扩展：
- 左右字符相同，就继续扩
- 不同就停止
- 记录当前最长回文区间

这个思路的优点：
- 容易想到
- 代码不复杂
- 时间复杂度可接受
- 面试里容易讲清楚

---

## 二、中心扩展法

### 思路

对每个位置 `i`，做两次扩展：

1. 以 `i` 为中心，处理奇数长度回文
2. 以 `i` 和 `i+1` 之间为中心，处理偶数长度回文

然后取两者中的最大值。

### Python 实现

```python
def longest_palindrome(s: str) -> str:
    if not s:
        return ""

    start, end = 0, 0

    def expand(left: int, right: int):
        while left >= 0 and right < len(s) and s[left] == s[right]:
            left -= 1
            right += 1
        return left + 1, right - 1

    for i in range(len(s)):
        l1, r1 = expand(i, i)       # 奇数长度
        l2, r2 = expand(i, i + 1)   # 偶数长度

        if r1 - l1 > end - start:
            start, end = l1, r1
        if r2 - l2 > end - start:
            start, end = l2, r2

    return s[start:end + 1]
```

### Java 实现

```java
public class Solution {
    public String longestPalindrome(String s) {
        if (s == null || s.length() == 0) {
            return "";
        }

        int start = 0;
        int end = 0;

        for (int i = 0; i < s.length(); i++) {
            int len1 = expand(s, i, i);      // 奇数长度
            int len2 = expand(s, i, i + 1);  // 偶数长度
            int len = Math.max(len1, len2);

            if (len > end - start + 1) {
                start = i - (len - 1) / 2;
                end = i + len / 2;
            }
        }

        return s.substring(start, end + 1);
    }

    private int expand(String s, int left, int right) {
        while (left >= 0 && right < s.length() && s.charAt(left) == s.charAt(right)) {
            left--;
            right++;
        }
        return right - left - 1;
    }
}
```

## 三、复杂度分析

### 时间复杂度

- 一共有 `n` 个字符
- 每个字符最多向两边扩展 `O(n)` 次

所以总时间复杂度是：

```text
O(n^2)
```

### 空间复杂度

只用了常数额外变量：

```text
O(1)
```

## 四、动态规划解法

### 状态定义

设：

```text
dp[i][j] 表示 s[i...j] 是否是回文串
```

### 状态转移

如果 `s[i] == s[j]`，则：

- 当 `j - i <= 2` 时，`dp[i][j] = true`
- 否则要看 `dp[i+1][j-1]`

即：

```text
if s[i] == s[j]:
    dp[i][j] = (j - i <= 2) or dp[i+1][j-1]
```

### Python 示例

```python
def longest_palindrome_dp(s: str) -> str:
    n = len(s)
    if n == 0:
        return ""

    dp = [[False] * n for _ in range(n)]
    start = 0
    max_len = 1

    for i in range(n):
        dp[i][i] = True

    for length in range(2, n + 1):
        for i in range(n - length + 1):
            j = i + length - 1
            if s[i] == s[j]:
                if length <= 3:
                    dp[i][j] = True
                else:
                    dp[i][j] = dp[i + 1][j - 1]

            if dp[i][j] and length > max_len:
                start = i
                max_len = length

    return s[start:start + max_len]
```

### DP 的特点

优点：
- 状态定义清晰
- 适合推导“回文相关”问题

缺点：
- 空间复杂度高，为 `O(n^2)`
- 面试现场代码量更大，边界更容易写错

## 五、为什么面试里优先讲中心扩展法

| 方案 | 时间复杂度 | 空间复杂度 | 面试友好度 |
|------|------------|------------|------------|
| 中心扩展 | `O(n^2)` | `O(1)` | 高 |
| 动态规划 | `O(n^2)` | `O(n^2)` | 中 |
| Manacher | `O(n)` | `O(n)` | 低 |

### 面试建议

如果面试官没要求最优复杂度，通常这样回答最稳：

1. 先说暴力思路不够好
2. 主讲中心扩展法
3. 再补一句：如果追求线性时间，可以用 Manacher，但实现复杂，面试里一般不优先写

| 输入 | 结果 | 说明 |

| `""` | `""` | 空串 |
| `"a"` | `"a"` | 单字符 |

| `"aa"` | `"aa"` | 偶数长度回文 |

## 七、面试高频追问

### 1. 子串和子序列有什么区别？

- **子串**：连续
- **子序列**：可以不连续

本题是最长回文**子串**，所以字符必须连续。

### 2. 为什么要分奇数中心和偶数中心？

因为回文串既可能是：
- `aba` 这种奇数长度
- 也可能是 `abba` 这种偶数长度

如果只考虑一种中心，会漏答案。

### 3. 有没有更优解？

有，**Manacher 算法** 可以做到 `O(n)`，但实现复杂。面试里如果没明确要求线性时间，一般中心扩展法就足够了。

---

## 八、面试回答模板

> 这题我会优先用中心扩展法。因为每个回文串都可以看成从某个中心向两边扩展得到，而中心有两类：一种是单个字符，对应奇数长度回文；另一种是两个字符之间，对应偶数长度回文。所以我会枚举每个位置，分别做奇数扩展和偶数扩展，记录最长区间。这样时间复杂度是 O(n^2)，空间复杂度是 O(1)，实现简单而且面试里很好讲。如果面试官追求更优复杂度，我再补充 Manacher 算法能做到 O(n)。

## 一句话总结

> 最长回文子串面试首选中心扩展法：枚举每个字符及相邻空隙作为中心向两边扩展，时间复杂度 O(n^2)，空间复杂度 O(1)，实现简单且不容易写错。
