# 冒泡排序

## Q: 冒泡排序的原理是什么？

重复遍历数组，相邻两个元素比较，如果顺序错误就交换；每一轮遍历会把当前未排序部分最大的元素"冒泡"到末尾。

> 口诀：大数往后飘，每轮少比较末尾已排好的部分；检测无交换可提前结束。

---

## 算法过程

```
初始: [5, 3, 8, 1, 2]

第1轮: 比较范围 [0, 4]
  [5,3,8,1,2] → 5>3 交换 → [3,5,8,1,2]
  [3,5,8,1,2] → 5<8 不换
  [3,5,8,1,2] → 8>1 交换 → [3,5,1,8,2]
  [3,5,1,8,2] → 8>2 交换 → [3,5,1,2, 8]  ← 8 冒泡到位

第2轮: 比较范围 [0, 3]
  [3,5,1,2,8] → 3<5 不换
  [3,5,1,2,8] → 5>1 交换 → [3,1,5,2,8]
  [3,1,5,2,8] → 5>2 交换 → [3,1,2, 5,8]  ← 5 冒泡到位

第3轮: 比较范围 [0, 2]
  [3,1,2,5,8] → 3>1 交换 → [1,3,2,5,8]
  [3,1,2,5,8] → 3>2 交换 → [1,2, 3,5,8]  ← 3 冒泡到位

第4轮: 比较范围 [0, 1]
  [1,2,3,5,8] → 1<2 不换 → 无交换，提前结束 ✓
```

## 代码实现

```java
public static void bubbleSort(int[] arr) {
    int n = arr.length;
    for (int i = 0; i < n - 1; i++) {
        boolean swapped = false;  // 优化：检测是否发生交换
        for (int j = 0; j < n - 1 - i; j++) {  // 每轮少比较末尾 i 个
            if (arr[j] > arr[j + 1]) {
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
                swapped = true;
            }
        }
        if (!swapped) break;  // 无交换说明已有序，提前结束
    }
}
```

```python
def bubble_sort(arr):
    n = len(arr)
    for i in range(n - 1):
        swapped = False
        for j in range(n - 1 - i):
            if arr[j] > arr[j + 1]:
                arr[j], arr[j + 1] = arr[j + 1], arr[j]
                swapped = True
        if not swapped:
            break
    return arr
```

## 复杂度

| 情况 | 时间复杂度 | 说明 |
|------|-----------|------|
| 最好 | O(n) | 数组已有序，一轮无交换即退出 |
| 平均 | O(n²) | 随机数据 |
| 最坏 | O(n²) | 逆序数组 |

| 维度 | 值 |
|------|---|
| 空间复杂度 | O(1) |
| 稳定性 | ✅ 稳定（相等元素不交换，相对顺序不变） |
| 原地排序 | ✅ 是 |

## 与其他排序对比

| 排序 | 平均 | 最坏 | 稳定 | 特点 |
|------|------|------|------|------|
| **冒泡** | O(n²) | O(n²) | ✅ | 最简单，可提前终止 |
| 选择 | O(n²) | O(n²) | ❌ | 每轮选最小，交换次数少 |
| 插入 | O(n²) | O(n²) | ✅ | 近乎有序时最快 |
| 快排 | O(nlogn) | O(n²) | ❌ | 实践中最快 |

## 一句话总结

> 冒泡排序每轮将最大元素交换到末尾，O(n²) 时间、O(1) 空间、稳定排序；加 `swapped` 标志可提前终止，最好 O(n)。
