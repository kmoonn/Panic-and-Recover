# SQL 实战：学生平均成绩排名倒数第五

## Q: 一张学生成绩表，有学号、姓名、科目、成绩字段，求学生平均成绩排名倒数第五的那个学生的成绩？

### 表结构

```sql
CREATE TABLE scores (
    id       INT,
    name     VARCHAR(50),
    subject  VARCHAR(50),
    score    INT
);
```

### 示例数据

| id | name | subject | score |
|----|------|---------|-------|
| 1  | 张三 | 语文 | 80 |
| 1  | 张三 | 数学 | 90 |
| 2  | 李四 | 语文 | 70 |
| 2  | 李四 | 数学 | 60 |
| ... | ... | ... | ... |

---

### 解题步骤

```
① 按学生分组求平均成绩
② 按平均成绩升序排列（倒数 = 升序）
③ 取第 5 名
```

### 方法一：LIMIT + OFFSET

```sql
SELECT id, name, AVG(score) AS avg_score
FROM scores
GROUP BY id, name
ORDER BY avg_score ASC
LIMIT 1 OFFSET 4;   -- 跳过前4名，取第5名
```

> `LIMIT 1 OFFSET 4` = 跳过 4 条，取 1 条 = 第 5 条

### 方法二：窗口函数 ROW_NUMBER()

```sql
SELECT id, name, avg_score
FROM (
    SELECT id, name, AVG(score) AS avg_score,
           ROW_NUMBER() OVER (ORDER BY AVG(score) ASC) AS rn
    FROM scores
    GROUP BY id, name
) t
WHERE rn = 5;
```

### 方法三：处理并列情况（同一平均成绩多人）

> 如果倒数第五名有多个学生平均成绩相同，应该全部返回。

```sql
SELECT id, name, avg_score
FROM (
    SELECT id, name, AVG(score) AS avg_score,
           DENSE_RANK() OVER (ORDER BY AVG(score) ASC) AS dr
    FROM scores
    GROUP BY id, name
) t
WHERE dr = 5;
```

| 函数 | 并列处理 | 示例（成绩 60,70,70,80,90） |
|------|---------|---------------------------|
| `ROW_NUMBER()` | 不并列，强制 1,2,3,4,5 | 第5名 = 90 |
| `RANK()` | 并列跳号，1,2,2,4,5 | 第5名 = 90 |
| `DENSE_RANK()` | 并列不跳号，1,2,2,3,4 | 第5名可能不存在 |

---

### 易错点

| 易错 | 正确 |
|------|------|
| `ORDER BY score ASC` | `ORDER BY AVG(score) ASC` — 排的是平均成绩，不是单科成绩 |
| `LIMIT 5` | `LIMIT 1 OFFSET 4` — LIMIT 5 取前 5 条，不是第 5 条 |
| 忽略并列 | 面试中应主动讨论并列场景，用 DENSE_RANK / RANK |

## 一句话总结

> 先 GROUP BY 求平均成绩，再 ORDER BY ASC 排升序（倒数=升序），最后 LIMIT 1 OFFSET 4 取第 5 条；并列场景用 DENSE_RANK 窗口函数。
