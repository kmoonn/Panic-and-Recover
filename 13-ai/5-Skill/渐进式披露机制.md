# 渐进式加载

> 一句话总结：先全量加载 Skill 索引（name+description），匹配选中后才展开参数和步骤细节，避免 40+ Skill 撑爆上下文窗口。

---

```
① 全量加载：agent 读所有 Skill 的 name + description（轻量，只加载索引）
      │
      ▼
② 匹配：agent 按 prompt 选出要用的 Skill
      │
      ▼
③ 渐进展开：选中后才读参数/步骤细节（按需加载，避免上下文爆炸）
```

**为什么不全量展开？** 40+ Skill 全部展开参数和步骤会撑爆上下文窗口。只加载索引，选中后再展开细节，是**上下文管理的关键设计**。

---

## 一句话总结

全量加载索引→匹配→按需展开细节，避免 40+ Skill 撑爆上下文窗口。
