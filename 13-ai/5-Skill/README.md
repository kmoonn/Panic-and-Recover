# Skill

**Skill** 是可复用、可组合的**提示+工具**打包单元，赋予 AI 特定的能力。

> 类比：如果 MCP 是 "USB-C 接口"，那 Skill 就是 "USB-C 设备" —— 每个 Skill 是一个即插即用的能力模块。

| 特性 | 说明 |
|------|------|
| 本质 | Prompt Template + Tool Bindings + I/O Schema |
| 目标 | 让 AI 获得某个特定领域的完整能力 |
| 特点 | 结构化、可复用、可组合、可校验 |
| 与 MCP 关系 | Skill 使用 MCP Tools 作为构建块，MCP 是 Skill 的基础设施 |

```
┌──────────────────────────────────────┐
│             Skill 层                  │
│  定义"做什么"：审查代码 / 部署服务     │
│  Prompt + 工具选择 + I/O 约束         │
├──────────────────────────────────────┤
│           MCP 层                      │
│  提供"怎么做"：read_file / kubectl    │
│  原子级工具 + 通信协议                 │
└──────────────────────────────────────┘
```
