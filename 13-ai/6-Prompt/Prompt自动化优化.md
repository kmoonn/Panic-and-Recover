# Prompt自动化优化

> 一句话总结：Prompt 优化从人工调试走向自动化——APE/OPRO/DSPy 将 Prompt 视为可优化参数或编译产物，推理模型时代重心从"教推理"转向"定义任务"。

---

## 自动化方法

| 方法 | 思路 | 特点 |
|------|------|------|
| **APE** | 自动搜索最优 Prompt，将 Prompt 视为可优化参数 | 通用但搜索空间大 |
| **OPRO** | 用 LLM 优化 LLM 的 Prompt，迭代改进 | 元优化，成本较高 |
| **DSPy** | 将 Prompt 编程化，声明式定义任务，编译器自动优化 Prompt | 当前主流，可复现 |

---

## System Prompt 设计原则

| 原则 | 说明 |
|------|------|
| 角色明确 | "你是一个…"比无角色指令输出更稳定 |
| 约束前置 | 先说"不要做什么"，再说"要做什么" |
| 格式指定 | 明确要求输出格式（JSON、表格、步骤编号） |
| 示例辅助 | 复杂任务用 Few-shot 示例比文字描述更有效 |

---

## 推理模型时代的变化

o1/DeepSeek-R1 等推理模型将 CoT 内化为原生能力：
- 模型自动生成隐藏推理 token，不再需要手动加"一步步思考"
- Prompt 工程重心从**"教模型怎么推理"**转向**"定义清楚任务目标和约束"**
- DSPy 等自动化框架成为新趋势
