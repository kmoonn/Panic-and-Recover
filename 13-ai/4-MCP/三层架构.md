# MCP 三层架构

> 一句话总结：MCP 采用 Host→Client→Server 三层架构，一个 Host 可同时连接多个 Server 实现工具组合。

---

## 三层架构

```
┌─────────────────────────────────────────────────┐
│                   Host (宿主)                     │
│         Claude Desktop / IDE / AI 应用            │
│                                                   │
│  ┌──────────┐    ┌──────────┐    ┌──────────┐   │
│  │MCP Client│    │MCP Client│    │MCP Client│   │
│  └────┬─────┘    └────┬─────┘    └────┬─────┘   │
└───────┼───────────────┼───────────────┼─────────┘
        │               │               │
        ▼               ▼               ▼
  ┌──────────┐   ┌──────────┐   ┌──────────┐
  │MCP Server│   │MCP Server│   │MCP Server│
  │ (文件系统) │   │ (数据库)  │   │ (Git)    │
  └──────────┘   └──────────┘   └──────────┘
```

| 角色 | 职责 | 类比 |
|------|------|------|
| **Host** | 运行 AI 模型的应用程序 | 操作系统 |
| **MCP Client** | Host 内部的协议客户端，与 Server 建立连接 | 设备驱动 |
| **MCP Server** | 提供具体工具/资源/提示的轻量级服务 | 外设 |

---

## 面试高频问题

**Q：MCP 的架构是什么？**
A：Host→Client→Server 三层。Host 运行 AI 模型，Client 是协议客户端，Server 提供工具/资源/提示。一个 Host 可连多个 Server 实现工具组合，Client 与 Server 通过 JSON-RPC 2.0 通信。

---

## 一句话总结

MCP 三层架构（Host→Client→Server），一个 Host 可同时连接多个 Server 实现工具组合，Client 控制能力暴露。
