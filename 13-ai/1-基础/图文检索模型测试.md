# 图文检索模型测试用例设计

## Q: 怎么对图文检索模型设计测试用例？要考虑哪些方面？

图文检索模型的核心任务：给定 query（文本/图片），从库中检索语义相关的另一种模态数据。测试需要从**检索质量、模态理解、鲁棒性、边界场景**四个层面展开。

---

## 一、检索质量 — 模型好不好使

> 最核心的指标：相关内容能不能排到前面。

### 1.1 量化指标

| 指标 | 含义 | 关注点 |
|------|------|--------|
| Recall@K | 前 K 个结果中命中相关项的比例 | K=1/5/10，K 越小要求越严 |
| MRR | 第一个正确结果的排名倒数 | 关注"第一个对的结果排第几" |
| nDCG | 考虑位置权重的排序质量 | 相关的排前面得分更高 |
| Hit Rate | 查询中至少有一个命中的比例 | 最低线：能不能找到 |

### 1.2 评测数据集构建

| 数据类型 | 说明 | 示例 |
|---------|------|------|
| 正样本对 | 语义相关的图文对 | "一只橘猫" ↔ 橘猫图片 |
| 负样本对 | 语义不相关的图文对 | "一只橘猫" ↔ 汽车图片 |
| 困难负样本 | 字面相似但语义不同 | "橘猫" ↔ 老虎图片（都是猫科） |

> 困难负样本最能区分模型好坏——简单负样本谁都能排对。

---

## 二、模态理解 — 两种方向都测

图文检索是**双向**的，两个方向都要验证：

### 2.1 文搜图（Text-to-Image）

| 测试维度 | 测试点 | 示例 query |
|---------|--------|----------|
| 精确描述 | 具体物体+属性 | "一只白色的柯基犬在草地上跑" |
| 抽象描述 | 风格/氛围/情感 | "温馨的家庭聚餐场景" |
| 动作/状态 | 动词+状态 | "正在打哈欠的猫" |
| 数量 | 具体数量词 | "三只小狗" |
| 否定 | 否定语义 | "没有人的风景照" |

### 2.2 图搜文（Image-to-Text）

| 测试维度 | 测试点 | 示例 |
|---------|--------|------|
| 场景描述 | 图中场景的文字 | 给一张海滩图 → 检索到"海边度假"相关文本 |
| 细节属性 | 图中细节属性 | 给一张红裙子图 → 检索到"红色连衣裙"而非"蓝色" |
| 多物体 | 图中多个物体 | 给一张猫和狗的图 → 检索到同时提及两者的文本 |

---

## 三、鲁棒性 — 输入不完美时还能不能用

### 3.1 文本侧鲁棒性

| 场景 | 测试点 | 示例 |
|------|--------|------|
| 同义词/近义词 | 不同表达能否检索到同一图片 | "小狗" vs "幼犬" → 应返回相似结果 |
| 错别字 | 少量错字不影响语义 | "小枸在草地上" → 仍能检索到狗 |
| 中英混合 | 混合语言输入 | "iPhone 手机" |
| 超长/超短 | 极端长度输入 | 单字"猫" vs 一整段描述 |
| 多语言 | 跨语言检索 | 中文 query 检索英文描述的图片 |

### 3.2 图片侧鲁棒性

| 场景 | 测试点 | 示例 |
|------|--------|------|
| 模糊/低分辨率 | 低画质是否影响检索 | 模糊图片仍能正确检索 |
| 光照变化 | 过曝/欠曝 | 暗光下的猫 vs 正常光照 |
| 遮挡 | 物体部分被遮挡 | 半个猫头露出 |
| 旋转/裁剪 | 几何变换 | 旋转 90° 的图片 |
| 水印/文字覆盖 | 图片上有覆盖物 | 带水印的产品图 |
| 多主体 | 图中多个物体 | 猫和狗同框 → 检索哪个？ |

---

## 四、边界与异常场景

| 场景 | 测试点 | 预期 |
|------|--------|------|
| 空查询 | 空文本/空图片 | 返回错误提示，不崩溃 |
| 无关查询 | 与图库完全不相关的 query | 返回低分结果，不硬塞 |
| 跨域查询 | 训练域外的内容 | "显微镜下的细胞"（如模型未见过） |
| 对抗样本 | 被刻意扰动的图片 | 不被误导 |
| 文化差异 | 不同文化背景的同一概念 | "婚礼"在中西方场景差异 |
| 歧义/多义 | 一个 query 多种理解 | "苹果"→ 水果还是公司？应两个方向都有结果 |

---

## 五、性能与工程

| 维度 | 测试点 |
|------|--------|
| 延迟 | 单次检索 P99 < 100ms |
| 吞吐 | 并发检索 QPS |
| 索引更新 | 新图片入库后多久可被检索到 |
| 大规模 | 千万级图片库的检索精度是否下降 |
| 内存占用 | 向量索引的内存消耗 |

---

## 测试分层总览

```
                    ┌─────────────────┐
                    │  检索质量（核心）  │  Recall@K / MRR / nDCG
                    │  正样本 + 困难负样本 │
                    ├─────────────────┤
                    │  模态理解（双向）  │  文搜图 + 图搜文
                    │  精确/抽象/动作/否定 │
                    ├─────────────────┤
                    │  鲁棒性（输入不完美）│  错字/模糊/遮挡/多语言
                    │  文本侧 + 图片侧   │
                    ├─────────────────┤
                    │  边界异常          │  空查询/对抗样本/文化差异
                    ├─────────────────┤
                    │  性能工程          │  延迟/吞吐/大规模
                    └─────────────────┘
```

## 一句话总结

> 图文检索模型测试分五层：检索质量（Recall@K + 困难负样本）→ 模态理解（文搜图/图搜文双向）→ 鲁棒性（错字/模糊/遮挡）→ 边界异常（空查询/对抗样本/文化差异）→ 性能工程（延迟/吞吐/大规模）。
