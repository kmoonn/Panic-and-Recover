# LLM基本原理

> 一句话总结：LLM 的核心就是"根据前文预测下一个 token"，所有智能表现都从这个简单目标在足够规模下涌现而来。

---

## 核心原理：下一个 token 预测

```
输入：今天天气真____
模型预测：好（概率最高）

输入：WAL即预写日志，它的核心____
模型预测：原理
```

模型并不知道"天气真好"是常识——它只是在海量文本中学会了**统计规律**：当出现"天气真"时，后面最常跟"好"。

### 为什么预测下一个词能产生智能？

**规模涌现**（Emergence）：当模型够大、数据够多时，为了预测更准，模型**被迫**学会了更高层的能力：

| 预测目标 | 被迫学会的能力 |
|---------|---------------|
| "如果下雨，地面会____" → 湿 | 因果推理 |
| "2+3=" → 5 | 数学计算 |
| "下面翻译成英文：谢谢" → Thank you | 翻译 |
| "代码有bug，因为空指针____" → 异常 | 代码理解 |
| "用户很生气，客服应该____" → 先道歉 | 社交理解 |

**模型不是在"理解"，而是在"预测"。但为了预测得准，它不得不学会理解。**

## LLM 完整生命周期

```
海量文本 → Pretrain（预训练）→ 基座模型（只会续写）
                                  ↓
指令数据 → SFT（监督微调）→ 能听指令的模型
                                  ↓
人类偏好 → RLHF/DPO（对齐）→ 安全、有用的助手
                                  ↓
用户输入 → 推理（逐词生成）→ 输出回答
```

### 阶段一：Pretrain（预训练）

- **数据**：互联网海量文本（TB 级），书籍、代码、百科、对话等
- **目标**：下一个 token 预测（自回归语言建模）
- **产出**：基座模型（Base Model），如 LLaMA-7B、Qwen-72B
- **能力**：会续写，但不会对话——给它"你好"可能续写成"你好世界"而非回答问题
- **类比**：读万卷书，什么都知道一点，但不懂考试规则

### 阶段二：SFT（监督微调，Supervised Fine-Tuning）

- **数据**：人工构造的指令-回答对（几万~几十万条）
- **目标**：让模型学会"提问→作答"的格式
- **产出**：指令模型（Instruct Model），如 LLaMA-2-Chat
- **类比**：学会考试——看到问题知道要回答，而不是续写

### 阶段三：RLHF / DPO（对齐人类偏好）

- **问题**：SFT 后模型能回答，但回答可能有害、冗长、不符合人类偏好
- **RLHF**：训练奖励模型打分 → 用 PPO 强化学习优化生成策略
- **DPO**：直接用偏好数据优化，跳过奖励模型，更简单稳定
- **产出**：安全、有用、符合人类偏好的助手模型
- **类比**：学会做人——回答不仅对，还要有用、安全、礼貌

### 三阶段对比

| 阶段 | 数据量 | 计算量 | 目标 | 类比 |
|------|--------|--------|------|------|
| Pretrain | TB 级 | 极大（GPU 月） | 语言统计规律 | 读万卷书 |
| SFT | 万~十万条 | 小（小时级） | 指令跟随 | 学会考试 |
| RLHF/DPO | 万级偏好对 | 小 | 人类偏好对齐 | 学会做人 |

## 关键认知

1. **LLM 本质是概率模型**：输出是词表上的概率分布，选概率最高的 token（贪心）或采样（temperature > 0）
2. **没有真正的"理解"**：只有统计相关性，但规模大到一定程度后，行为上等价于理解
3. **知识存在参数里**：训练数据的信息被压缩到模型权重中，不在任何数据库里
4. **每次生成都是独立的**：模型本身无记忆，对话历史靠拼在输入里重新预测
5. **涌现能力**：某些能力在小模型上不存在，只在参数量超过阈值后突然出现（如思维链推理）

### 第一层：一句话定义（先声夺人）

> LLM 的核心原理是**根据前文预测下一个 token**，所有智能表现都来自海量数据上学到的统计规律在足够规模下的涌现。

### 第二层：展开核心原理

> 模型输入一段文本，输出词表上的概率分布，选概率最高的 token。为了预测得准，模型被迫学会推理、翻译、代码等能力——这就是规模涌现。模型不是真正"理解"，但行为上等价于理解。

关键词命中：**概率分布、下一个 token、规模涌现、统计规律**

### 第三层：训练三阶段

> Pretrain 用海量文本学语言规律 → SFT 用指令数据教对话格式 → RLHF/DPO 用人类偏好对齐安全有用。类比："读万卷书→学会考试→学会做人"。

| 追问 | 回答要点 |

## 面试高频问题

**Q：LLM 的基本原理是什么？**
A：核心是下一个 token 预测——根据前文计算词表上的概率分布，选概率最高的 token 作为输出。所有智能表现都是从海量数据中学到的统计规律在足够规模下涌现的结果。

**Q：预训练、SFT、RLHF 三阶段分别做什么？**
A：Pretrain 用海量文本学语言规律，产出只会续写的基座模型；SFT 用指令数据教模型"提问→作答"格式；RLHF/DPO 用人类偏好数据对齐，让回答安全有用。

**Q：为什么基座模型不能直接对话？**
A：基座模型只学了续写，给它"你好"会续写成"你好世界"而非回答。SFT 阶段才教它识别指令并作答。

**Q：RLHF 和 DPO 的区别？**
A：RLHF 分三步（训练奖励模型 → PPO 强化学习），流程复杂、训练不稳定；DPO 直接用偏好对优化策略，跳过奖励模型，更简单稳定，当前主流倾向 DPO。

**Q：LLM 的知识从哪来？存在哪？**
A：来自预训练的海量文本数据，存在模型参数（权重）里。模型不查询任何外部数据库，所有知识都是训练时压缩进参数的统计规律。这也是 LLM 会"幻觉"的根本原因——参数化知识无法精确回忆。

## 八股速记

### Q1. 大模型 / Transformer / 注意力 ⭐⭐

**答（要点式）**：
- **大模型（LLM）**：基于海量文本、用自监督预训练出来的超大参数量语言模型，核心能力是"给定上文预测下一个 token"。
- **Transformer**：主流架构，抛弃 RNN 的串行，用**自注意力（Self-Attention）**并行处理整个序列，能捕捉长距离依赖。
- **注意力机制**：每个 token 通过 Q（查询）、K（键）、V（值）算出对其他 token 的关注权重，加权求和得到新表示——"看句子里哪些词更相关"。

**⭐ 加分/易错**：
- 主流对话大模型是 **Decoder-only**（GPT 系）：自回归、单向、逐 token 生成；BERT 是 Encoder-only（双向、擅理解不擅生成）。
- 自注意力复杂度是序列长度的 **O(n²)**，这是长上下文成本高的根因。

---

## 一句话总结

LLM 本质是"预测下一个 token"的概率模型，Pretrain 学语言规律、SFT 学指令跟随、RLHF 学人类偏好，智能从规模涌现而非真正的理解。
