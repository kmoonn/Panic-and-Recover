# 创建线程的方式

## 四种创建线程的方式

### 1. 继承 Thread 类

```java
class MyThread extends Thread {
    @Override
    public void run() {
        System.out.println("线程运行: " + Thread.currentThread().getName());
    }
}

// 使用
MyThread thread = new MyThread();
thread.start();
```

- 继承 `Thread` 类，重写 `run()` 方法
- Java 单继承，继承了 Thread 就不能再继承其他类
- 无返回值

### 2. 实现 Runnable 接口

```java
class MyRunnable implements Runnable {
    @Override
    public void run() {
        System.out.println("线程运行: " + Thread.currentThread().getName());
    }
}

// 使用方式一
Thread thread = new Thread(new MyRunnable());
thread.start();

// 使用方式二：Lambda 表达式
new Thread(() -> {
    System.out.println("线程运行: " + Thread.currentThread().getName());
}).start();
```

- 实现 `Runnable` 接口，实现 `run()` 方法
- 可以继续继承其他类
- 无返回值
- **最基本的方式**，Thread 类本身就实现了 Runnable

### 3. 实现 Callable 接口 + FutureTask

```java
class MyCallable implements Callable<String> {
    @Override
    public String call() throws Exception {
        return "线程返回结果: " + Thread.currentThread().getName();
    }
}

// 使用 FutureTask 包装
FutureTask<String> futureTask = new FutureTask<>(new MyCallable());
Thread thread = new Thread(futureTask);
thread.start();

// 获取结果（阻塞等待）
String result = futureTask.get();
System.out.println(result);
```

- 实现 `Callable<V>` 接口，实现 `call()` 方法
- `call()` 有返回值，可以抛出异常
- 通过 `FutureTask` 包装后交给 Thread 执行
- 通过 `Future.get()` 获取返回值（阻塞等待）

**FutureTask 的作用**：FutureTask 同时实现了 `Runnable` 和 `Future` 接口，是连接 Callable 和 Thread 的桥梁：

```
Callable --> FutureTask（包装为 Runnable）--> Thread
                |
          Future.get() 获取结果
```

### 4. 线程池（ExecutorService）

```java
// 创建线程池
ExecutorService executor = Executors.newFixedThreadPool(3);

// 提交 Runnable（无返回值）
executor.execute(() -> {
    System.out.println("Runnable 任务");
});

// 提交 Callable（有返回值）
Future<String> future = executor.submit(() -> {
    return "Callable 任务结果";
});
String result = future.get();

// 关闭线程池
executor.shutdown();
```

- 通过线程池统一管理和复用线程
- 避免频繁创建销毁线程的开销
- 可以控制最大并发数
- **实际开发中推荐的方式**

## 四种方式对比

| 对比维度 | 继承 Thread | 实现 Runnable | 实现 Callable | 线程池 |
|---|---|---|---|---|
| 返回值 | 无 | 无 | 有 | 可有可无 |
| 异常 | 不能抛出 checked 异常 | 不能抛出 checked 异常 | 可以抛出 | 依赖提交方式 |
| 可否继承其他类 | 不可（单继承） | 可以 | 可以 | 可以 |
| 复用性 | 低 | 高 | 高 | 最高 |
| 是否推荐 | 不推荐 | 推荐 | 推荐 | 最推荐 |

## 面试高频：本质上只有一种方式

**面试答案**：创建线程本质上只有一种方式——**实现 Runnable 接口**。

理由：
1. 继承 Thread 类：Thread 本身实现了 Runnable，重写 run() 本质上也是实现 Runnable
2. 实现 Callable：Callable 通过 FutureTask 包装，而 FutureTask 实现了 RunnableFuture（继承自 Runnable）
3. 线程池：底层也是将任务封装为 Runnable/Callable 提交给 Worker 线程执行

```
继承 Thread --- Thread 实现 Runnable ---------|
实现 Runnable -------------------------------|--> 本质都是 Runnable
实现 Callable --- FutureTask 实现 Runnable ---|
线程池 --- 任务封装为 Runnable ----------------|
```

> 更准确地说，创建线程只有 `new Thread()` 这一种方式，其他都是定义任务（Runnable/Callable）的方式。

## start() vs run() 的区别

| 对比维度 | start() | run() |
|---|---|---|
| 作用 | 启动新线程，由新线程执行 run() | 在当前线程中执行 run() 方法体 |
| 是否创建新线程 | 是 | 否 |
| 调用次数 | 只能调用一次（重复调用抛 IllegalThreadStateException） | 可以反复调用 |
| 是否多线程 | 是 | 否（普通方法调用） |

```java
Thread t = new Thread(() -> System.out.println(Thread.currentThread().getName()));

t.start();  // 输出: Thread-0（新线程执行）
t.run();    // 输出: main（当前线程执行，不会创建新线程）
```

> **注意**：直接调用 run() 不会创建新线程，这是初学者常见错误。

## 线程的状态转换

Java 线程有 6 种状态（`Thread.State` 枚举）：

```
                              +-----------------------+
                              |                       |
                              v                       |
  NEW --start()--> RUNNABLE --+--获取锁失败--> BLOCKED
                       |      |                       |
                       |      +--获取锁成功-----------+
                       |      |
                       |      +--wait()--------> WAITING --notify()/notifyAll()-->
                       |      +--join()--------> WAITING                            |
                       |      |                                                    |
                       |      +--sleep(t)----> TIMED_WAITING --超时/notify()------->
                       |      +--wait(t)-----> TIMED_WAITING                       |
                       |      +--join(t)-----> TIMED_WAITING                       |
                       |      |                                                    |
                       |      +--run() 执行完毕 --> TERMINATED                     |
                       |                                                          |
                       +----------------------------------------------------------+
```

| 状态 | 说明 | 触发条件 |
|---|---|---|
| **NEW** | 新建，尚未启动 | `new Thread()` 后 |
| **RUNNABLE** | 可运行（就绪 + 运行中） | `start()` 后 |
| **BLOCKED** | 阻塞，等待获取锁 | 等待进入 synchronized 块 |
| **WAITING** | 等待，不限时 | `wait()` / `join()` / `LockSupport.park()` |
| **TIMED_WAITING** | 计时等待 | `sleep(t)` / `wait(t)` / `join(t)` |
| **TERMINATED** | 终止 | `run()` 执行完毕或抛出未捕获异常 |

> **注意**：Java 线程状态中没有"就绪"和"运行"的区分，RUNNABLE 包含了操作系统层面的就绪（Ready）和运行（Running）两种状态。调用 `Thread.yield()` 只是建议线程让出 CPU，线程仍处于 RUNNABLE 状态。

## 一句话总结

创建线程有四种方式（继承 Thread、实现 Runnable、实现 Callable、线程池），但本质上都是通过 Runnable 定义任务交给 Thread 执行；实际开发中推荐使用线程池；`start()` 才会创建新线程，直接调用 `run()` 只是普通方法调用。
