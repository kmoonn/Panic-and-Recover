# 生成器

生成器是 Python 中使用 `yield` 实现惰性求值的迭代器，核心价值是省内存——一次只产出一个值，适用于大数据流式处理场景。

## yield 惰性产出

`yield` 让函数在每次调用时从上次暂停处继续执行，逐个产出值而非一次性生成全部结果。

- 调用生成器函数返回生成器对象，不执行函数体
- 每次 `next()` 或 `for` 迭代执行到 `yield` 暂停，返回 `yield` 后的值
- 再次迭代从暂停处继续，直到函数结束抛出 `StopIteration`

## 典型应用

大数据流式处理（呼应武理工 SAX 流式思想）——无需将全量数据加载到内存，逐条读取处理即可。

## 一句话总结
> 生成器用 yield 惰性产出，一次只生成一个值，省内存，适合大数据流式处理。
