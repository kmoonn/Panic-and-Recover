# is 与 == 的区别

`is` 比较对象身份（是否同一对象），`==` 比较对象值（是否相等），两者语义不同，小整数和短字符串缓存会导致 `is` "意外"为真。

## is：对象身份比较

`is` 比较的是两个变量是否指向**同一个对象**（即 `id()` 是否相同）。

## ==：值比较

`==` 比较的是两个对象的**值**是否相等，可通过 `__eq__` 方法自定义比较逻辑。

## 缓存陷阱

小整数（-5~256）和短字符串有缓存，`is` 可能"意外"为真：

```python
a = 256
b = 256
a is b   # True（缓存范围内）

c = 257
d = 257
c is d   # False（超出缓存范围，不同对象）
```

## 一句话总结
> is 比较是否同一对象（id），== 比较值；小整数和短字符串有缓存，is 可能"意外"为真。
