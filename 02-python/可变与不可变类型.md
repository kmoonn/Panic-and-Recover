# 可变与不可变类型

Python 中对象分为可变与不可变两类，理解其区别是掌握函数传参、深浅拷贝、默认参数陷阱的基础。

## 可变 vs 不可变

- 不可变 = int/float/str/tuple
- 可变 = list/dict/set

函数传参传的是**对象引用**，改可变对象会影响外部。

## 深浅拷贝

- 浅拷贝（`copy.copy`）只拷贝一层，嵌套对象仍共享
- 深拷贝（`copy.deepcopy`）递归全拷贝

**⭐ 易错**：可变对象作默认参数是坑（`def f(x, lst=[])` 会共享同一个 list）。

## 一句话总结
> 不可变类型（int/str/tuple）赋值即新对象，可变类型（list/dict/set）原地修改；浅拷贝只拷一层，深拷贝递归全拷，可变默认参数是经典坑。
