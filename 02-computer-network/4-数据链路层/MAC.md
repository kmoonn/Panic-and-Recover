# MAC 地址

## 什么是 MAC 地址？

MAC（Media Access Control）地址是**数据链路层**（网络接口层）的地址标识，用于在网络中唯一标识一个网络接口。也称为**物理地址**或**硬件地址**。

- 长度：**48 位**（6 字节），通常表示为 `AA:BB:CC:DD:EE:FF` 或 `AA-BB-CC-DD-EE-FF`
- 全球唯一性：由 IEEE 分配，理论上每个网卡都有唯一的 MAC 地址
- 烧录在网卡 ROM 中，但可通过软件修改

## MAC 地址格式

```
  OUI（厂商标识）    设备标识
┌───────────────┬───────────────┐
│  AA:BB:CC     │  DD:EE:FF     │
│  3 字节        │  3 字节       │
│  IEEE 分配     │  厂家自行分配  │
└───────────────┴───────────────┘
  共 48 位 = 6 字节
```

- **OUI（Organizationally Unique Identifier）**：前 3 字节，由 IEEE 分配给厂商，标识生产厂家
- **设备标识**：后 3 字节，由厂商自行分配，标识具体设备
- 第一字节的最低两位有特殊含义：
  - **I/G 位**（最低位）：0=单播地址，1=组播地址
  - **G/L 位**（次低位）：0=全局唯一（IEEE 分配），1=本地管理

## MAC 地址 vs IP 地址

| 对比维度 | MAC 地址 | IP 地址 |
|---------|---------|--------|
| 所在层次 | 数据链路层（第 2 层） | 网络层（第 3 层） |
| 长度 | 48 位（6 字节） | IPv4: 32 位 / IPv6: 128 位 |
| 表示方式 | 十六进制 `AA:BB:CC:DD:EE:FF` | 点分十进制 `192.168.1.1` |
| 分配方式 | 硬件烧录（可软件修改） | 网络配置或 DHCP 动态分配 |
| 唯一性 | 全局唯一（理论上） | 网络内唯一 |
| 是否随网络变化 | 不变（逻辑上） | 随网络变化 |
| 寻址范围 | 点到点（同一链路内） | 端到端（跨网络） |
| 类比 | 身份证号 | 邮寄地址 |

## 为什么需要两个地址？

这是一个经典问题——既然 MAC 地址已经唯一标识设备，为什么还需要 IP 地址？

**核心原因：两者负责不同范围的通信**

```
源主机 ──→ 路由器1 ──→ 路由器2 ──→ 目的主机
  │  链路1  │  链路2   │  链路3   │
  │← MAC →│← MAC →│← MAC →│    ← 每段链路 MAC 地址在变
  │←────────── IP 始终不变 ──────────→│    ← 端到端 IP 地址不变
```

- **IP 地址**：负责**端到端**通信，标识"谁是发送方、谁是接收方"，在整个传输过程中不变（类似收件人地址）
- **MAC 地址**：负责**点到点**通信，标识"下一跳是谁"，每经过一个路由器都会变化（类似快递员）

如果只有 MAC 地址：路由器需要知道全球所有设备的 MAC 地址，路由表将不可想象地庞大。

## ARP 协议：IP → MAC 的映射

ARP（Address Resolution Protocol）用于将 IP 地址解析为 MAC 地址：

```
主机A（IP: 192.168.1.1）要发数据给主机B（IP: 192.168.1.2）

1. A 查 ARP 缓存 → 没有 B 的 MAC
2. A 广播 ARP 请求："谁有 192.168.1.2？请告诉我你的 MAC"
3. B 单播 ARP 应答："192.168.1.2 的 MAC 是 AA:BB:CC:DD:EE:FF"
4. A 将映射存入 ARP 缓存，后续直接使用
```

## MAC 地址会变吗？

- **理论**：MAC 地址烧录在网卡 ROM 中，是固定的
- **实际**：可以通过软件修改（MAC 地址 spoofing）
  - Linux：`ifconfig eth0 hw ether AA:BB:CC:DD:EE:FF`
  - Windows：设备管理器 → 网络适配器 → 高级 → 网络地址
- **路由器/手机**：出于隐私保护，现代设备会使用随机 MAC 地址连接 WiFi（称为 MAC 地址随机化）
- **交换机**：看到的是实际使用的 MAC 地址，不关心是否为出厂值

## 面试高频：MAC 地址和 IP 地址的区别

| 问题要点 | 回答关键 |
|---------|---------|
| 层次不同 | MAC 是链路层，IP 是网络层 |
| 寻址范围不同 | MAC 点到点（同一链路），IP 端到端（跨网络） |
| 是否变化 | MAC 每跳变化，IP 端到端不变 |
| 为什么缺一不可 | 没有 IP 无法跨网络路由，没有 MAC 无法在同链路内找到目标 |
| 类比 | MAC = 身份证号（唯一标识），IP = 邮寄地址（路由寻址） |

## 一句话总结

MAC 地址是数据链路层的 48 位物理地址，负责同链路内的点到点通信；IP 地址是网络层的逻辑地址，负责跨网络的端到端通信；两者缺一不可，通过 ARP 协议完成映射。
