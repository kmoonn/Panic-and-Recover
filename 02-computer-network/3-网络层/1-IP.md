# IP 协议

## 什么是 IP 协议？

IP（Internet Protocol）是**网络层核心协议**，负责在互联网络中实现**寻址**和**路由**，使数据包能够从源主机跨越多个网络到达目的主机。它是整个 TCP/IP 协议栈的基石。

核心功能：
- **寻址**：为每个网络接口分配唯一 IP 地址
- **路由**：路由器根据目的 IP 地址选择转发路径
- **分片与重组**：数据包超过 MTU 时进行分片

## IPv4 地址

### 地址格式

- 长度：**32 位**（4 字节）
- 表示：**点分十进制**，如 `192.168.1.1`
- 每段范围：0~255（8 位）

### 分类编址

| 类别 | 首字节范围 | 网络位 | 主机位 | 默认子网掩码 | 可用主机数 | 适用场景 |
|------|-----------|--------|--------|-------------|-----------|---------|
| A | 1~126 | 8 位 | 24 位 | 255.0.0.0 | 2^24 - 2 | 大型网络 |
| B | 128~191 | 16 位 | 16 位 | 255.255.0.0 | 2^16 - 2 | 中型网络 |
| C | 192~223 | 24 位 | 8 位 | 255.255.255.0 | 2^8 - 2 | 小型网络 |
| D | 224~239 | — | — | — | — | 组播地址 |
| E | 240~255 | — | — | — | — | 保留/实验 |

> 注意：127.x.x.x 属于 A 类但保留为环回地址，0.x.x.x 保留为网络地址。

### 特殊 IP 地址

| 地址 | 含义 |
|------|------|
| `127.0.0.1` | 环回地址（localhost），指本机 |
| `0.0.0.0` | 所有网络 / 本机所有 IP（常用于服务监听） |
| `255.255.255.255` | 受限广播地址（本链路广播） |
| `10.0.0.0/8` | A 类私有地址（10.0.0.0 ~ 10.255.255.255） |
| `172.16.0.0/12` | B 类私有地址（172.16.0.0 ~ 172.31.255.255） |
| `192.168.0.0/16` | C 类私有地址（192.168.0.0 ~ 192.168.255.255） |
| `169.254.0.0/16` | 链路本地地址（DHCP 失败时自动分配） |

私有地址不会出现在公网上，通过 NAT 转换后访问公网。

## 子网掩码与 CIDR

### 子网掩码

子网掩码用于区分 IP 地址中的**网络位**和**主机位**：

```
IP 地址：   192.168.1.100
子网掩码：  255.255.255.0
网络地址：  192.168.1.0     ← IP & 掩码
广播地址：  192.168.1.255   ← 网络位不变，主机位全1
可用范围：  192.168.1.1 ~ 192.168.1.254
```

### CIDR（无类域间路由）

CIDR 摒弃了传统的 A/B/C 类划分，用 `/n` 表示网络前缀长度：

```
192.168.1.0/24  → 前 24 位是网络号，后 8 位是主机号（256 个地址）
10.0.0.0/8      → 前 8 位是网络号，后 24 位是主机号
172.16.0.0/12   → 前 12 位是网络号，后 20 位是主机号
```

**CIDR 的核心优势**：
- 支持可变长子网划分，减少地址浪费
- 支持路由聚合（supernetting），缩小路由表

## IPv4 vs IPv6 对比

| 对比维度 | IPv4 | IPv6 |
|---------|------|------|
| 地址长度 | 32 位（4 字节） | 128 位（16 字节） |
| 表示方式 | 点分十进制 `192.168.1.1` | 冒号十六进制 `2001:0db8::1` |
| 地址数量 | 约 43 亿（2^32） | 约 3.4×10^38（2^128） |
| 头部复杂度 | 可变长度，含选项字段 | 固定 40 字节，简化头部 |
| 配置方式 | 手动 / DHCP | SLAAC 自动配置 / DHCPv6 |
| 安全性 | IPSec 可选 | IPSec 内置支持 |
| NAT | 需要（地址不够） | 不需要（地址充足） |
| 分片 | 路由器和发送方均可分片 | 仅发送方分片，路由器不分片 |
| 广播 | 支持 | 取消广播，改用组播 |
| 头部校验 | 有（每跳重算） | 无（由数据链路层和传输层保证） |

## IP 分片与 MTU

### MTU（Maximum Transmission Unit）

- 每种链路层都有 MTU 限制，以太网 MTU = **1500 字节**
- 当 IP 数据报长度超过 MTU 时，需要进行**分片（Fragmentation）**

### 分片机制

```
原始 IP 数据报：4000 字节（含 20 字节 IP 头部）

经过 MTU=1500 的链路：
┌──────────────┐  ┌──────────────┐  ┌──────────────┐
│ 片1: 1500B   │  │ 片2: 1500B   │  │ 片3: 1040B   │
│ 偏移=0       │  │ 偏移=185     │  │ 偏移=370     │
│ MF=1         │  │ MF=1         │  │ MF=0         │
└──────────────┘  └──────────────┘  └──────────────┘
```

- **MF（More Fragments）**：1=后面还有分片，0=最后一个分片
- **片偏移**：以 8 字节为单位
- 分片在**目的主机**重组（IPv4），路由器不重组

> **避免分片的最佳实践**：使用路径 MTU 发现（PMTUD）确定路径最小 MTU，发送方直接按该大小发送。

## 面试高频：IPv4 和 IPv6 的区别

核心要点：
1. **地址空间**：IPv4 32 位 vs IPv6 128 位，IPv6 彻底解决地址耗尽问题
2. **头部简化**：IPv6 固定 40 字节头部，去掉了校验和、选项等字段，提升路由器处理效率
3. **自动配置**：IPv6 支持 SLAAC（无状态地址自动配置），无需 DHCP 即可获得地址
4. **安全内置**：IPv6 原生支持 IPSec，IPv4 的 IPSec 是可选的
5. **取消 NAT**：IPv6 地址充足，不再需要 NAT，恢复了端到端通信模型
6. **取消广播**：IPv6 用组播替代广播，减少不必要的处理开销

## 一句话总结

IP 协议是网络层的核心，负责寻址和路由；IPv4 采用 32 位地址并通过 CIDR 灵活划分子网，IPv6 用 128 位地址彻底解决地址耗尽问题，同时简化头部、内置安全、取消 NAT，是互联网的未来方向。
