# 进程调度算法

操作系统通过调度算法决定哪个就绪进程获得 CPU，目标是在响应时间、吞吐量、公平性之间取得平衡。

## 常见调度算法

| 算法 | 特点 | 优缺点 |
|---|---|---|
| **先来先服务（FCFS）** | 按到达顺序调度 | 简单公平，但短作业可能等很久（护航效应） |
| **短作业优先（SJF）** | 优先调度预计运行时间最短的 | 平均等待时间最短，但可能饿死长作业 |
| **时间片轮转（RR）** | 每个进程分配固定时间片，用完轮转 | 响应好、公平，时间片大小需权衡 |
| **优先级调度** | 按优先级选进程 | 可按需调优，低优先级可能饿死 |
| **多级反馈队列** | 多个优先级队列，时间片逐级增大，用完降级 | 兼顾响应和公平，实际 OS 常用 |

## 关键易错点

- **SJF 平均等待时间最短但可能饿死长作业**——没有抢占时尤其严重。
- **多级反馈队列**是实际操作系统最常用的策略：短作业在高层队列快速完成，长作业逐步降级但不会饿死，兼顾响应时间和公平性。

## 一句话总结

> FCFS 简单但不公平，SJF 等待最短但饿死长作业，RR 公平响应好，多级反馈队列综合最优是实际 OS 首选。
