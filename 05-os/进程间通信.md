# 进程间通信

进程间通信（IPC）是不同进程之间传递数据、协调执行的机制。由于进程有独立地址空间，必须通过内核提供的 IPC 机制才能通信。

## 通信方式一览

| 方式 | 特点 | 适用场景 |
|---|---|---|
| **管道（匿名 pipe）** | 半双工，父子进程间使用 | 父子进程简单通信 |
| **命名管道（FIFO）** | 可用于无亲缘关系进程 | 不相关进程间通信 |
| **消息队列** | 消息格式化，按类型读取 | 异步消息传递 |
| **共享内存** | 最快，无需内核/用户空间拷贝 | 大量数据高速交换 |
| **信号量** | 计数器，用于同步而非数据传输 | 配合共享内存保证互斥 |
| **信号（signal）** | 异步通知，如 kill、SIGTERM | 进程间事件通知 |
| **Socket** | 可跨机器通信 | 网络通信、分布式系统 |

## 共享内存为什么最快

共享内存直接映射到进程地址空间，数据不用在内核和用户空间来回拷贝，读写就是内存操作。但需要自己用信号量保证互斥访问。

## 跨机器通信

只有 Socket 支持跨机器通信，其他 IPC 机制都限于同一主机内。

## 一句话总结

> 进程间通信七大方式：管道/消息队列/共享内存/信号量/信号/Socket，共享内存最快但需配信号量同步，跨机器只能用 Socket。
