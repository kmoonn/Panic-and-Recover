# 进程、线程、协程的区别

## 一句话定义

- **进程**：资源分配的最小单位，独立内存空间
- **线程**：CPU 调度的最小单位，共享进程资源
- **协程**：用户态的轻量级线程，由程序自身调度

## 类比

```
进程 = 一个工厂        → 独立厂房、设备、仓库
线程 = 工厂里的工人    → 共享工厂资源，同一车间工作
协程 = 工人手里的多任务 → 一个工人"看似同时"做多件事，自己切换
```

## 核心对比

| 维度 | 进程 | 线程 | 协程 |
|---|---|---|---|
| **调度方** | 操作系统内核 | 操作系统内核 | 用户程序（协程库） |
| **切换开销** | 大（切换页表/TLB/寄存器） | 中（切换寄存器/栈） | 极小（只切换寄存器/栈，无内核态切换） |
| **内存** | 独立地址空间 | 共享进程地址空间 | 共享线程地址空间 |
| **通信** | IPC（管道/共享内存/Socket） | 共享变量（需加锁） | 共享变量（无需加锁，单线程内串行） |
| **并发数上限** | 百~千级 | 千~万级 | 万~百万级 |
| **创建开销** | 大（fork / CreateProcess） | 中（pthread_create） | 极小（几 KB 栈空间） |
| **稳定性** | 高（进程崩溃互不影响） | 低（线程崩溃拖垮进程） | 高（协程异常可控） |
| **多核利用** | ✅ 天然多核并行 | ✅ 多核并行（受 GIL 限制除外） | ❌ 单线程内并发，需多进程才能多核 |
| **适用场景** | 隔离性要求高 | IO 密集型 / 需要多核 | 高并发 IO（如百万连接） |

## 切换开销详解

| 操作 | 进程切换 | 线程切换 | 协程切换 |
|---|---|---|---|
| 用户态 → 内核态 | ✅ 必须 | ✅ 必须 | ❌ 不需要 |
| 切换页表 | ✅ | ❌ 同进程 | ❌ |
| 刷新 TLB | ✅ | ❌ | ❌ |
| 切换寄存器/栈 | ✅ | ✅ | ✅ |
| 典型耗时 | 1~10 μs | 0.5~5 μs | 0.1~0.5 μs |

## 通信方式对比

| | 进程间 | 线程间 | 协程间 |
|---|---|---|---|
| 共享内存 | 需 mmap | ✅ 直接共享 | ✅ 直接共享 |
| 加锁 | 不需要（隔离） | 需要（mutex/spinlock） | 不需要（单线程串行） |
| 消息传递 | 管道/Queue/Socket | Queue | Channel（Go）/ Queue |

## 线程同步机制

| 机制 | 特点 | 适用场景 |
|---|---|---|
| 互斥锁 | 独占访问，同一时刻只允许一个线程进入临界区 | 保护共享变量 |
| 读写锁 | 读共享、写独占 | 读多写少（如缓存） |
| 信号量 | 控制最多允许多少线程同时访问 | 并发限流 |
| 屏障 | 所有线程到达某点后一起继续 | 多线程阶段性同步 |
| 等待/通知 | 线程等待条件，其他线程唤醒 | 生产者-消费者 |

## 进程状态模型

```
New ──→ Ready ──→ Running ──→ Terminated
                   │    ↑
                   │    │（时间片用完）
                   ↓    │
                 Blocked/Waiting
                 （等待IO/锁/信号）
```

## 各语言实现

| 语言 | 进程 | 线程 | 协程 |
|---|---|---|---|
| Java | ProcessBuilder | Thread / VirtualThread | CompletableFuture / Loom |
| Python | multiprocessing | threading（受 GIL 限制） | asyncio / yield |
| Go | — | — | goroutine（语言原生） |
| C++ | fork / std::process | std::thread | 协程库（co_await, C++20） |
| Node.js | child_process | worker_threads | async/await（事件循环） |

## 选择策略

```
需要隔离？ → 多进程
需要多核 CPU 并行？ → 多线程
高并发 IO（>1万连接）？ → 协程
CPU 密集 + 高并发？ → 多进程 + 每进程内协程
```

## 八股速记

**问：进程 vs 线程 vs 协程？**

**答（要点式）**：
- **进程**：资源分配的基本单位，有独立地址空间；切换开销大、隔离性好。
- **线程**：CPU 调度的基本单位，同进程内线程**共享地址空间**（堆、全局），各自有栈和寄存器；切换比进程轻。
- **协程**：用户态轻量级"线程"，由程序自己调度（非内核），切换无内核开销，适合高并发 IO（如 Python asyncio、Go goroutine）。

**⭐ 加分/易错**：
- 进程通信要 IPC，线程通信直接读共享内存（但要加锁）。
- 协程呼应项目 RAG 的 asyncio 协程 + 线程池并行（见 `04-rag-ingestion`/`01-rag-retrieval`）——协程扛 IO 密集，线程池丢阻塞型调用。

## 总结一句话

> 进程重隔离、线程轻共享、协程极轻量。进程崩溃互不影响，线程共享但需加锁，协程单线程串行无需锁但无法多核并行。
