# 虚拟内存与分页

虚拟内存让每个进程拥有独立的连续虚拟地址空间，通过 MMU 映射到物理内存，实现隔离并突破物理内存限制。

## 核心概念

### 虚拟内存

- 给每个进程独立的连续虚拟地址空间，由 MMU 映射到物理内存
- 实现进程隔离 + 突破物理内存限制
- 进程只看到自己的地址空间，互不干扰

### 分页

- 把内存分成固定大小的页（如 4KB）
- 虚拟页通过**页表**映射到物理页帧
- **TLB**（Translation Lookaside Buffer）是页表缓存，加速虚拟地址到物理地址的转换

### 缺页中断

- 访问的页不在物理内存 → 触发缺页中断 → 从磁盘换入
- 内存满则按**页面置换算法**换出

## 页面置换算法

| 算法 | 特点 |
|---|---|
| **LRU** | 淘汰最近最久未使用的页，性能好但实现开销大 |
| **FIFO** | 淘汰最早进入内存的页，简单但可能换出常用页（Belady 异常） |
| **Clock** | LRU 的近似，用引用位+循环指针，实现简单 |

## 抖动（Thrashing）

频繁缺页换入换出，CPU 大量时间耗在换页而非执行 → 系统近乎假死。原因是进程的物理页帧不够，工作集远大于可用内存。

## 分页 vs 分段

| | 分页 | 分段 |
|---|---|---|
| **大小** | 固定（如 4KB） | 按逻辑大小可变 |
| **目的** | 管理内存，提高利用率 | 按逻辑划分（代码段/数据段/栈段） |
| **碎片** | 内部碎片（页未填满） | 外部碎片（段间空隙） |

## 一句话总结

> 虚拟内存通过页表映射+TLB缓存实现进程隔离与内存扩展，缺页时从磁盘换入，内存满靠页面置换算法淘汰，抖动是工作集大于可用内存的警告信号。
