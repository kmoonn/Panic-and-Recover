# NAT 网络地址转换

用于在不同网络之间转换IP地址

允许将私有IP地址（局域网）映射为公有IP地址（互联网）或者反向映射，实现局域网内多台设备共享单一公有IP地址访问互联网

NAT 的工作就是：

内网设备发请求 → 路由器替换源 IP 为公网 IP

外网响应回来 → 路由器根据端口映射转回内网 IP

## 为什么要分子网 IP

IPv4 公网地址严重不够用

NAT + 内网 IP = 一个公网 IP 带一堆设备上网，路由器通过 NAT 把它们映射到同一个公网 IP上网。


## 一句话总结

> NAT将内网IP映射为公网IP，解决IPv4地址不足问题，一个公网IP可带多设备上网。
