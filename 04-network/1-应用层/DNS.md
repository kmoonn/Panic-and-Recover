# DNS 域名系统

DNS（Domain Name System）将**域名解析为 IP 地址**。

## 四层结构

- 根域名服务器（Root）
- 顶级域服务器（如 `.com`）
- 权威域名服务器（Authoritative）
- 本地 DNS 服务器（LDNS）

## 缓存层级

浏览器缓存 → 系统缓存 → 路由器缓存 → LDNS → 根 → 顶级域 → 权威 → 返回 IP

## 完整解析流程（递归 + 迭代）

1. 浏览器查浏览器缓存
2. 查系统 hosts 文件
3. 查本地 DNS 服务器（LDNS）
4. LDNS 查根域名服务器（Root）
5. 根返回顶级域服务器（`.com`）
6. 顶级域返回权威域名服务器（Authoritative）
7. 权威服务器返回 IP
8. LDNS 缓存并返回给用户

## 查询方式

| 方式 | 路径 | 说明 |
|---|---|---|
| **递归查询** | 客户端 → LDNS | 客户端只发一次请求，LDNS 全权负责查到结果再返回（"我交给你，你帮我搞定"） |
| **迭代查询** | LDNS → 根 → 顶级域 → 权威 | 每次服务器只返回下一跳地址，不替你继续查（"你告诉我下一个问谁，我自己去问"） |

## 解析方式分类

- 递归解析
- 迭代解析
- 反向解析（IP → 域名）
- 缓存解析（浏览器、系统、LDNS、权威）

## 传输协议

DNS 同时使用两种协议：

- **UDP 53 端口**：绝大多数 DNS 查询（快、无连接、足够可靠）
- **TCP 53 端口**：主从域名服务器之间区域传送（Zone Transfer）、响应报文超过 512 字节时、DNSSEC 相关操作

> 一句话背诵：DNS 默认用 UDP 53，大数据 / 同步用 TCP 53。

## 一句话总结

> DNS将域名解析为IP地址，支持递归、迭代、反向、缓存四种解析方式，分层查询提高效率。
