# WebSocket

WebSocket 是一种在单个 TCP 连接上实现**全双工、长连接**的应用层通信协议，通过一次 HTTP 握手建立连接后，客户端与服务器可随时双向通信，允许服务器主动向客户端推送消息。

## 核心特点

- 基于 TCP、应用层协议、全双工通信
- 支持服务器主动推送
- 一次握手，持久连接，双向实时数据传输

## 对比 HTTP

| 维度 | HTTP | WebSocket |
|---|---|---|
| 方向 | 单向（客户端问一次，服务端答一次） | 双向，两边随时可发消息 |
| 连接 | 短连接 | 长连接 |
| 推送 | 无法主动推送 | 服务器可主动推送 |

它解决了 HTTP 单向、无状态、无法主动推送的问题，替代低效的轮询方式，实现**低延迟、高并发、轻量**的实时通信。

## 应用场景

视频弹幕、实时消息推送、实时游戏对战、多用户协同编辑、社交聊天。

## 一句话总结

> WebSocket基于TCP全双工长连接，一次HTTP握手后客户端与服务端可随时双向通信，替代低效轮询实现实时通信。
