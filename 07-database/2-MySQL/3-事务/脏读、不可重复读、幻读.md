# 脏读、不可重复读、幻读

并发事务产生的三种问题

> 脏读：读了没提交的
不可重复读：同一行变了
幻读：行数变了

- 脏读

读到了别人没提交的数据，别人一回滚，你就读到 “假数据”。

读了未提交的数据

- 不可重复读

同一个事务里，两次读同一行，结果不一样。

同一行数据，前后读不一样。

- 幻读

同一个事务里，两次查询，行数 / 结果集变了。

查询的行数变了。


## 一句话总结

> 脏读读到未提交数据、不可重复读同一字段值被改、幻读同一查询结果行数变化，三者严重程度递增。
