# MyISAM

## MyISAM 是什么？

MyISAM 是 MySQL 5.5 之前的**默认存储引擎**，是一个不支持事务、不支持外键、使用表级锁的存储引擎，适用于以读操作为主且不需要事务的场景。

## 核心特性

| 特性 | 说明 |
|---|---|
| 表级锁 | 写操作锁整张表，并发性能低 |
| 不支持事务 | 无法保证 ACID |
| 不支持外键 | 无法使用外键约束 |
| 全文索引 | 原生支持全文索引（InnoDB 5.6+ 才支持） |
| COUNT(*) 不扫表 | 存储了行数，直接返回 |

## 存储结构

MyISAM 的数据和索引存储在**独立的文件**中：

```
表名.MYD  → 数据文件（MyISAM Data）
表名.MYI  → 索引文件（MyISAM Index）
表名.frm  → 表结构定义文件
```

- 数据文件（.MYD）和索引文件（.MYI）分离
- 索引的叶子节点存储的是**数据行的地址指针**（非聚簇索引）
- 可以没有主键，索引与数据独立存储

## 优点

1. **查询速度快**：尤其是全表扫描和 COUNT(*) 操作
2. **存储紧凑**：数据文件占用空间小
3. **全文索引**：支持全文检索，适合搜索场景
4. **COUNT(*) 极快**：内部维护了行数计数器，无需扫描表

## 缺点

1. **表级锁**：写操作时锁整张表，并发写入性能差
2. **不支持事务**：无法回滚，数据一致性无保证
3. **崩溃后可能损坏**：没有 redo log，崩溃后数据可能丢失或损坏，需要 REPAIR TABLE 修复
4. **不支持外键**：无法建立外键约束
5. **不支持 MVCC**：读写互相阻塞

## MyISAM 与 InnoDB 对比

| 对比项 | MyISAM | InnoDB |
|---|---|---|
| 事务 | 不支持 | 支持 ACID |
| 锁粒度 | 表级锁 | 行级锁 |
| 外键 | 不支持 | 支持 |
| 崩溃恢复 | 不支持 | Crash-Safe |
| MVCC | 不支持 | 支持 |
| 索引类型 | 非聚簇索引 | 聚簇索引 |
| COUNT(*) | 直接返回 | 需要遍历 |
| 全文索引 | 原生支持 | 5.6+ 支持 |
| 存储文件 | .MYD + .MYI | .ibd |
| 压缩表 | 支持 | 不支持 |

## 适用场景

- **只读或读多写少**的表（如配置表、字典表）
- **不需要事务**的场景（如日志表、访问统计表）
- **需要全文索引**的搜索场景（旧版本时）
- 数据仓库中的**大表全表扫描**

## 一句话总结

MyISAM 是 MySQL 旧版默认的存储引擎，以表级锁、非聚簇索引、不支持事务为特征，适合只读或读多写少且不需要事务的场景，在需要数据一致性和高并发写入的场景下应优先选择 InnoDB。
