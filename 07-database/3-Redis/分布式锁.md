# 分布式锁

Redis 分布式锁是分布式系统下实现互斥访问的核心方案。

## 基本实现

`SET key value NX PX 30000`——`NX` 保证只有一个客户端能设置成功（互斥），`PX` 设过期防死锁。

## 释放锁

value 存唯一标识（如 UUID），释放前**校验是不是自己的锁**，用 **Lua 脚本**保证"判断+删除"原子。

## 续期

任务没跑完锁就过期怎么办 → **看门狗**自动续期（Redisson 提供）。

## ⭐ 加分/易错

- 释放锁必须"**判断归属 + 删除**"原子，否则可能误删别人的锁。
- 极端严谨场景（主从切换丢锁）有 **RedLock**，但争议大、实践少，一般单实例锁 + 兜底幂等就够。

## 一句话总结

> Redis 分布式锁：SET NX PX 加锁 + Lua 原子释放 + 看门狗续期；极端场景用 RedLock 但争议大，一般单实例锁 + 幂等兜底即可。
