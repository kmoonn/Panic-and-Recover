# 最左前缀匹配原则

MySQL 在使用联合索引时，会从索引的最左边的字段开始匹配，遇到范围查询（>、<、between、like 模糊匹配）就停止匹配，后面的字段无法使用索引。

必须从左开始连续匹配，不能跳过前面的字段直接用后面的字段。

联合索引是多字段组成的一个索引，遵循最左前缀原则：必须从索引最左列开始连续匹配，遇到范围查询则停止匹配，后面字段无法使用索引。


## 一句话总结

> 联合索引须从最左列开始连续匹配，遇范围查询(>、<、between、like)则停止匹配后续列。
