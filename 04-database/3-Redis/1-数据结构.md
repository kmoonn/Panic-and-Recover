# Redis 数据类型

## 基本 5 种

### 1. String

最基础的类型，可存字符串、整数、浮点数，最大 512MB。

| 命令 | 说明 |
|---|---|
| `SET key value` | 设置 |
| `GET key` | 获取 |
| `INCR key` | 自增（原子操作） |
| `SETNX key value` | 不存在才设置（分布式锁常用） |

**应用场景**：缓存、计数器、分布式锁、Session 存储

### 2. Hash

字段-值映射，类似 Python dict / Java HashMap。

```
key: user:1
  ├── name  → "张三"
  ├── age   → "25"
  └── email → "zhangsan@example.com"
```

| 命令 | 说明 |
|---|---|
| `HSET key field value` | 设置字段 |
| `HGET key field` | 获取字段 |
| `HMGET key f1 f2` | 批量获取 |
| `HGETALL key` | 获取所有字段 |

**应用场景**：对象存储（用户信息、商品属性）、购物车

### 3. List

有序字符串列表，按插入顺序排序，支持两端操作。

```
key: queue
  [a] → [b] → [c] → [d]
  左端push/pop      右端push/pop
```

| 命令 | 说明 |
|---|---|
| `LPUSH key value` | 左端插入 |
| `RPUSH key value` | 右端插入 |
| `LPOP key` | 左端弹出 |
| `LRANGE key 0 -1` | 获取所有元素 |

**应用场景**：消息队列（LPUSH + BRPOP）、最新列表（朋友圈时间线）、栈/队列

### 4. Set

无序不重复集合，自动去重。

| 命令 | 说明 |
|---|---|
| `SADD key member` | 添加元素 |
| `SISMEMBER key member` | 判断是否存在 |
| `SINTER k1 k2` | 交集 |
| `SUNION k1 k2` | 并集 |
| `SDIFF k1 k2` | 差集 |

**应用场景**：标签、共同关注（交集）、点赞/收藏去重、抽奖（SRANDMEMBER）

### 5. ZSet（Sorted Set）

有序不重复集合，每个元素关联一个 **score**，按 score 排序。

```
key: leaderboard
  ├── "张三"  score: 95
  ├── "李四"  score: 88
  └── "王五"  score: 72
```

| 命令 | 说明 |
|---|---|
| `ZADD key score member` | 添加元素 |
| `ZRANGE key 0 -1` | 按score升序返回 |
| `ZREVRANGE key 0 9` | 降序前10（排行榜） |
| `ZRANK key member` | 获取排名 |
| `ZRANGEBYSCORE key 80 100` | 按分数范围查询 |

**应用场景**：排行榜、延时队列（score=时间戳）、带权重的标签

## 扩展类型

| 类型 | 说明 | 应用场景 |
|---|---|---|
| **Bitmap** | 位操作，String 的位级扩展 | 签到打卡、用户在线状态、布隆过滤器 |
| **HyperLogLog** | 基数估算，12KB 内存算亿级去重 | UV 统计（允许误差） |
| **GEO** | 地理位置坐标，基于 ZSet | 附近的人、门店搜索 |
| **Stream** | 消息流，类似 Kafka | 消息队列（比 List 更强大：消费组、ACK、持久化） |

## 类型选择速查

| 需求 | 类型 | 示例 |
|---|---|---|
| 简单 key-value | String | `user:token → "abc123"` |
| 对象多字段 | Hash | `user:1 → {name, age, email}` |
| 有序队列/栈 | List | `msg:queue → [a, b, c]` |
| 去重集合 | Set | `article:1:likes → {uid1, uid2}` |
| 排序集合 | ZSet | `rank:score → {(张三,95), (李四,88)}` |
| 签到/状态位 | Bitmap | `sign:202401 → 1011011...` |
| UV 去重统计 | HyperLogLog | `uv:page:home → 125000` |
| 附近的人 | GEO | `stores → {(经度, 纬度)}` |

## 总结一句话

> 基本五类型：String 存值、Hash 存对象、List 存队列、Set 存去重、ZSet 存排序；扩展四类型：Bitmap 算位、HyperLogLog 算基数、GEO 算距离、Stream 算消息。
