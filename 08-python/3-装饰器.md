# 装饰器

## 是什么

装饰器是一个**接受函数作为参数并返回新函数**的高阶函数，用于在不修改原函数代码的前提下**增强或扩展**其行为。

语法上用 `@decorator` 糖衣语法，等价于 `func = decorator(func)`。

## 本质

装饰器的本质是**高阶函数 + 闭包**：

- **高阶函数**：接受函数作为参数，或返回函数作为结果
- **闭包**：内层函数引用了外层函数的变量，外层函数执行结束后这些变量依然存活

`@` 只是语法糖，Python 解释器在**函数定义时**就会执行这行赋值。

## 执行过程拆解

```python
def log(func):
    print(f"装饰 {func.__name__}")     # ← 第2步：装饰器函数体执行
    def wrapper(*args, **kwargs):
        print(f"调用 {func.__name__}")  # ← 第4步：每次调用 func 时执行
        return func(*args, **kwargs)
    return wrapper                      # ← 第3步：返回 wrapper 替换原函数

@log                                    # ← 第1步：函数定义时触发
def hello():
    print("hi")

hello()  # ← 第4步
```

**输出：**
```
装饰 hello    ← 定义时就执行，不是调用时
调用 hello    ← 每次调用 wrapper 时执行
hi
```

关键：**装饰器函数体在定义时执行一次**，wrapper 函数体在每次调用时执行。

## 闭包原理

wrapper 函数能访问 `func` 变量，是因为 Python 在函数对象上保存了对外层变量的引用：

```python
def log(func):
    def wrapper(*args, **kwargs):
        return func(*args, **kwargs)   # 引用外层的 func
    return wrapper

# wrapper 的闭包变量
print(wrapper.__closure__)        # (<cell at 0x...: function object at 0x...>,)
print(wrapper.__closure__[0].cell_contents)  # 原始 func 函数对象
```

`__closure__` 是一个 cell 对象元组，每个 cell 持有一个被闭包引用的外层变量。只要 wrapper 存在，`func` 就不会被垃圾回收。

## 基本用法

```python
def log(func):
    def wrapper(*args, **kwargs):
        print(f"调用 {func.__name__}")
        return func(*args, **kwargs)
    return wrapper

@log
def say_hello():
    print("hello")

say_hello()
# 输出:
# 调用 say_hello
# hello
```

等价于：

```python
say_hello = log(say_hello)
```

## 带参数的装饰器（三层嵌套原理）

需要再嵌套一层函数来接收装饰器自身的参数：

```python
def repeat(n):              # 第1层：接收装饰器参数
    def decorator(func):    # 第2层：接收被装饰函数
        def wrapper(*args, **kwargs):  # 第3层：闭包，持有 n 和 func
            for _ in range(n):
                result = func(*args, **kwargs)
            return result
        return wrapper
    return decorator

@repeat(3)
# 等价于: repeat(3) 返回 decorator → decorator(func) 返回 wrapper
def hello():
    print("hi")

hello()  # 输出 3 次 hi
```

调用 `@repeat(3)` 时：
1. `repeat(3)` 执行 → 返回 `decorator` 函数
2. `decorator(hello)` 执行 → 返回 `wrapper` 函数
3. `hello` 被替换为 `wrapper`

## functools.wraps

装饰器会覆盖原函数的 `__name__`、`__doc__` 等元信息，用 `@functools.wraps` 保留：

```python
import functools

def log(func):
    @functools.wraps(func)   # 复制 func 元信息到 wrapper
    def wrapper(*args, **kwargs):
        print(f"调用 {func.__name__}")
        return func(*args, **kwargs)
    return wrapper
```

`@functools.wraps(func)` 的原理：**把 func 的 `__name__`、`__doc__`、`__module__`、`__dict__` 等属性复制到 wrapper 上**，并更新 `__wrapped__` 指向原函数。

## 类装饰器

用类实现装饰器，利用 `__call__` 方法：

```python
class Timer:
    def __init__(self, func):   # 等同于装饰器接收 func
        self.func = func
        functools.update_wrapper(self, func)

    def __call__(self, *args, **kwargs):  # 等同于 wrapper
        import time
        start = time.time()
        result = self.func(*args, **kwargs)
        print(f"{self.func.__name__} 耗时 {time.time() - start:.4f}s")
        return result

@Timer   # 等价于 hello = Timer(hello)
def hello():
    pass

# hello 现在是 Timer 实例，hello() 触发 __call__
```

## 多个装饰器叠加

```python
@decorator_a
@decorator_b
def func():
    pass
```

等价于 `func = decorator_a(decorator_b(func))`，**自下而上装饰**。

调用时：`decorator_a.wrapper → decorator_b.wrapper → 原func`，**自外向内执行**。

## 常见应用场景

| 场景 | 示例 |
|---|---|
| 日志记录 | 记录函数调用、参数、返回值 |
| 性能计时 | 测量函数执行耗时 |
| 权限校验 | 检查用户是否登录/有权限 |
| 缓存 | `@functools.lru_cache` 自动缓存返回值 |
| 重试 | 函数失败时自动重试 N 次 |
| 事务管理 | 数据库操作自动 commit/rollback |

## 与 Java 注解的区别

两者 `@` 语法相似，但本质完全不同：

| | Python 装饰器 | Java 注解 |
|---|---|---|
| **语法** | `@decorator` | `@Annotation` |
| **运行时机** | **定义时立即执行**，改写/替换原函数 | **运行时通过反射读取**，注解本身不做任何事 |
| **本质** | 高阶函数，`func = decorator(func)` | 元数据标签，附加在类/方法/字段上的信息 |
| **谁做实事** | 装饰器自身 | 框架的 AOP / 反射逻辑（如 Spring） |

> Python 装饰器**自己就是逻辑**，定义时直接改写函数；Java 注解**只是标签**，逻辑由框架在运行时通过反射读取后执行。装饰器更接近 Java 的 **AOP 切面**而非注解本身。

## 总结

| 概念 | 原理 |
|---|---|
| `@decorator` | 语法糖，等价 `func = decorator(func)` |
| 装饰时机 | 函数**定义时**执行，非调用时 |
| 闭包 | `__closure__` cell 对象持有外层变量引用 |
| 多装饰器 | 自下而上装饰，自外向内执行 |
| 带参数 | 三层嵌套：参数层 → 装饰器层 → wrapper 层 |
| `functools.wraps` | 复制 `__name__`/`__doc__` 等元信息到 wrapper |
| 类装饰器 | `__init__` 接收 func，`__call__` 充当 wrapper |

## 一句话总结

> 装饰器 = 不改原函数代码 + 增强其行为的高阶函数，本质是 `func = decorator(func)` 的语法糖，底层依赖闭包机制保存外层变量引用。
