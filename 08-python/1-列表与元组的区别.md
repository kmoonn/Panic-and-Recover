# 列表和元组的区别

## 是否可变

| 特性 | list（列表） | tuple（元组） |
|---|---|---|
| 可变性 | 可变（mutable） | 不可变（immutable） |
| 语法 | `[1, 2, 3]` | `(1, 2, 3)` |
| 元素增删改 | 支持 `append`、`remove`、切片赋值等 | 不支持，只能整体替换 |

## 性能

- **创建速度**：tuple 快于 list（CPython 对 tuple 有优化，小元组会缓存复用）
- **内存占用**：tuple 更小（无需预留扩容空间）

```python
import sys
sys.getsizeof([1, 2, 3])   # 88 字节（64 位）
sys.getsizeof((1, 2, 3))   # 72 字节（64 位）
```

## 使用场景

- **list**：元素需要增删改，如动态收集数据、循环中逐步构建
- **tuple**：元素固定不变，如函数返回多个值、字典的 key（list 不可 hash，不能做 key）、常量配置

## 作为字典 key

```python
d = {(1, 2): "ok"}      # ✅ tuple 可 hash，可做 key
d = {[1, 2]: "error"}   # ❌ list 不可 hash，TypeError
```

## 方法差异

- list：`append`, `extend`, `insert`, `remove`, `pop`, `sort`, `reverse`, `clear` 等
- tuple：仅有 `count`, `index`（只读方法）

## 总结一句话

> 列表可变、功能多、开销大；元组不可变、轻量快、可哈希。数据不变用元组，需要修改用列表。
